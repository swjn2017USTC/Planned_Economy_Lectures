## 本讲最重要的20%

上一讲解释了计划经济为什么在苏联革命与工业化进程中形成。本讲接着询问：**“国家计划”究竟怎样从一个政治目标变成一份企业必须完成的生产任务？**

如果只记住五点，应当是：

1. **计划不是中央机关一次性算出全国需求，再让工厂机械照办。**真实过程包含政治优先顺序、经济统计、部门平衡、年度指标、部委分解、企业执行，以及来自企业、供应商、银行、商业系统和地方的连续反馈。它有一条从上到下的指令链，也有一条不那么畅通但始终存在的自下而上的信息链。
2. **五年计划、年度计划、季度计划并非同一种文件的三个长度版本。**五年计划体现社会资源的中期配置方向；年度计划试图把这个方向与当年的物资、投资、劳动力和财政协调起来；季度及更短周期的任务，则可能直接连到交货、工资基金、领导干部奖金与生产组织。科尔奈1957年发现，在他研究的匈牙利轻工业部门，真正支配企业行动的往往是季度指标，而非企业负责人参与甚少、预期必将修订的年度计划。[H1]
3. **企业既是被管理者，也是掌握局部知识的战略行动者。**部委需要企业报告能力、设备、库存和投入需求；企业则知道下期指标可能根据本期成绩抬高，因而未必愿意暴露全部潜力。这种“计划谈判”不是所有干部道德败坏，而是行政层级与激励机制共同产生的现象。[H1][T2]
4. **中央有能力动员资源，不等于中央有能力知道一切。**高度集中可以保证优先工程、基础工业或紧急物资获得资源，但当产品品种、质量、替代技术、运输与用户需求越来越复杂时，有限数量的可核查指标未必代表真实社会效益。
5. **1968年匈牙利改革不是取消国家计划，而是试图改变计划与企业之间的“传动机构”。**国家仍提出国民经济目标；变化在于不再把一大批具体产量和投入命令层层分解到企业，而更多使用价格、利润、税收、信贷等间接工具。这一对照反过来说明：传统体制的关键不是“有没有五年计划”，而是**哪一级有权决定什么、以何种规则约束企业**。[H2][H3]

这一讲的中心判断是：**传统社会主义计划经济应被理解为一种政治—统计—行政—企业组成的复杂协调机器，而不是一张全国生产表。**它的运转效果取决于目标是否适当、真实资源能否到位、指标是否反映需要，以及组织能否安全、及时地发现并纠正错误。

## 一、问题从哪里来？1955—1957年，一位匈牙利经济学家走进轻工业

### 1.1 先看真实的研究现场，而不是想象中的“国家大脑”

1955年春，匈牙利科学院经济研究机构的一批研究人员开始调查经济管理中的过度集中问题。参与这项研究的年轻经济学家亚诺什·科尔奈（János Kornai）后来将材料写成《经济管理中的过度集中》（*Overcentralization in Economic Administration*）。该研究的英文简报于1957年在布达佩斯形成；英文版图书则于1959年出版。我们可以直接看到科尔奈网站保存的1957年英文简报，以及牛津大学出版社的再版目录与原版前言摘录。[H1][H4]

科尔奈给自己设定的问题非常朴素：不能只读规定企业“应当如何管理”的教材，而必须弄清经济机制**实际怎样工作**。他的调查集中在轻工业——纺织、制鞋和与居民日常生活有关的产品——而不是只看国家宣传中最引人注目的钢铁、电站和大工程。这个选择很重要。钢铁总量增长容易统计，但一双鞋是否合脚、一块布的品种是否受欢迎、几种产品的尺寸和颜色是否合适，难以被同一个总量数字捕捉。[H1]

他记录了一个很耐人寻味的制度现象：**某些企业的年度计划主要由主管工业部的产业部门制定，厂长、总工程师和企业计划科负责人几乎没有参与编制。**年度计划常常比较概括，而企业又预期四个季度计划的合计最终不会与年度计划完全相同。与之不同，季度计划更直接影响负责人奖金，因此才真正成为日常经营的行为依据。[H1]

请注意这个现象中的三个行动者：

- **部委产业管理部门**有向企业下达任务的正式权力，却不能亲自进入每个生产环节观察技术细节。
- **厂长与总工程师**知道设备状态、技术人员能力、生产流程和哪些投入最紧缺，但能否调整任务受上级规定约束。
- **企业计划科与车间**必须把宏观产值、成本、工资基金指标翻译成每日可执行的排班、领料、加工与交货。

谁最懂生产，不一定谁就拥有最后决定权；谁拥有最后决定权，也不一定能得到最真实的信息。这不是一个抽象哲学难题，而是一项技术—组织设计难题。

### 1.2 科尔奈看见的并不只有弊病

这份同期简报并不支持把社会主义工业管理描绘成一无是处的“瞎指挥”。科尔奈明确承认，指令与激励的结合对**推动生产数量增长**产生了强烈作用，并取得真实成果；他的研究是在此基础上辨认体制的代价。[H1]

企业接受产量增长指标，可能确实促使管理者组织更多班次、修复设备、提高劳动利用率。然而，当工资和奖金紧密联系于产值、成本、季度完成率时，企业也可能优先做那些容易计量或容易得到奖励的事，忽略品种、质量、用户需求或长期设备维护。**同一种制度手段可以同时具有动员效果和扭曲效果。**

这就是本讲要始终保持的观察方法：不要用“计划经济一定僵化”取消它的组织能力，也不要用“工业产量确实增长”证明所有行政细节都是合理的。

### 1.3 一项明确标注的教学复原：一张棉布生产任务表怎样形成

下面是一个**制度机制教学案例**，并非某年某厂真实档案，不涉及虚构的领导人言语或精确历史数字。

设想1960年代中期，一家匈牙利国营纺织企业接到上级提出的下一季度生产任务。全国轻工业计划希望增加布匹供应；主管部门根据预计产能、棉纱供应和既有计划分解任务；工厂计划科发现某型号织机需要维修，部分纱线规格也不匹配。商业部门却反映消费者更需要另一种布料。企业报送困难，希望取得更多纱线或调整产品构成；部委担心企业故意夸大困难；最终批准的任务可能沿用容易核对的产量或产值目标。

季度末，企业完成了按旧标准统计的产值任务，但消费者真正需要的布匹品种未必同步增加。下一季度，主管部门又可能因为“该厂上季已经完成任务”，提高其预期能力指标。

以上每一步都可在科尔奈描述的真实制度机制中找到对应，但**案例中的具体产品选择、工厂行为顺序和管理对话属于分析性组合**，不能当成一条具体历史记录。[H1]

从这个故事引出的问题是：究竟谁有权把“增加人民的服装供应”翻译成“某厂本季完成多少产值”？又有没有制度保证这两项任务真正一致？

## 二、先把制度机器拆开：从党中央到工厂、从工厂到供应网络

### 2.1 至少有六类组织，不能全叫“国家”

研究1960年代匈牙利传统指令型计划经济，最好先建立一张职能图。下表是依据科尔奈对当时层级的描述、当时计划法律和后续历史研究综合出的**分析性职能图**；不是任何单一年份的完整组织编制表。[H1][H2][H5]

| 层级/组织 | 主要关切 | 能控制的典型对象 | 必须依赖谁提供信息 |
|---|---|---|---|
| 匈牙利社会主义工人党（MSZMP）领导机构 | 工业化、增长、就业、生活水平、对外政治与改革边界 | 国家发展方向、高层干部、重大制度改革 | 计划机关、政府、党内报告、统计与社会反馈 |
| 国民议会、部长会议等正式国家机关 | 批准和组织实施国民经济计划、政策与预算 | 五年/年度计划、政府决定、部门职责 | 国家计划机关、部委及财政统计系统 |
| 国家计划局/国家计划办公室（Országos Tervhivatal） | 汇总部门需求、设计国民经济比例、协调优先项目 | 经济计划建议、部门指标、综合平衡 | 统计机构、各部委、地方与企业报送 |
| 工业部委及产业管理机构 | 本行业完成任务、物资分配、企业考核 | 企业计划指标、投资和技术行政、干部监督 | 企业、供应部门、其他部委 |
| 国营企业及计划、财务、技术部门 | 完成任务、获得投入、维持生产与奖金 | 车间排产、材料使用、产品组合的剩余裁量 | 供应商、车间、上级、商业与运输部门 |
| 供应企业、商业流通机构、银行、运输和地方机关 | 交付物资、销售、结算、区域生产和公共服务 | 合同交付、账务、运输、地方配套 | 生产企业、政府部门、消费者、其他节点 |

还有工会、劳动者、合作社与家庭经济，不可被省略。它们未必直接决定中央计划，却通过劳动供给、生产实践、申诉、消费、缺勤、储蓄和需求改变经济实际结果。

这里有一个必须避免的误区：**党制定政治优先方向，不等于党的政治局亲自制定所有企业指标。**同样，国家计划机关进行综合协调，不等于它直接操作每台机床。现代政治经济学应特别关注制度中介的分工。

### 2.2 三种不同的“计划”，指向不同时间尺度

**五年计划**首先是中期结构安排：下一阶段应重点扩展哪些产业？电力和钢铁能力够不够？劳动人口如何分配？基本建设投入能否承担？居民生活水平应当怎样改善？它不只是把五个年度计划装订在一起。

**年度计划**更接近资源安排和执行约束：本年度能采购多少原料、建设多少项目、形成多少产量、需要多少投资和资金、各行业之间能否基本平衡？它要在期初存量、进口能力、现有设备、运输与新建设施投产时间之间寻找可能的组合。

**季度、月度和车间作业计划**则处理生产执行：本季生产什么品种，哪个车间先占用设备，何时完成维修，哪批原料能按时送到，怎样报告成本与进度。科尔奈的调查提醒我们，企业的实际注意力可能被季度考核与奖金制度锁定，因此“时间尺度越短，行为效果越直接”有时会成立；但它是一种具体制度后果，而非所有经济体的普遍定理。[H1]

这三者之间还有**投资建设的跨期性**：今年批准钢厂扩建，不等于今年就多出钢材。一个投资目标若没有考虑建设周期，年度计划就可能出现“纸面产能”。

### 2.3 竖直控制与横向协作：经济中永远有两个方向

科尔奈1957年用特别清楚的方式描述过一个企业面对的两个“平面”：

**纵向关系**：上级机关通过生产指令、投资管理、资金与信贷、价格、物资供应、外贸、工资基金以及任命管理人员影响企业。

**横向关系**：企业从其他企业取得材料、能源、工具，同时把自己的产品卖给另一些企业或商业部门。[H1]

可以画成一张简化机制图：

```text
       党中央提出发展与分配优先方向
                    │
          政府 / 国家计划机关
                    │  综合计划、部门任务
      ┌─────────────┼──────────────┐
   工业主管部       财政/银行        商业/运输部门
      │               │                 │
      ▼               ▼                 ▼
   纺织企业  ←────  支付和信用       零售/物流组织
      ▲                                  ▲
      │投入品                           │交货与需求信息
      └──────── 棉纱、能源、设备供应 ────┘

   信息既向上报告，也沿企业—企业渠道横向流动；
   但信息存在不等于上级一定会重视、相信或据此修订计划。
```

在传统体系里，企业横向联系虽然真实存在，**却往往被上级行政管理的分配权支配**。当企业之间因为原料短缺发生冲突时，双方未必能独立调整采购量、价格和产品组合，而常要把争议上交给主管部门协调。这会改变所谓买方、卖方以及合同的实际意义。

### 2.4 “条条—块块”概念如何准确使用

在中国经济行政史里，“条条”通常指工业、财政、交通等专业系统的纵向职能联系，“块块”指省、地、县等地域性领导结构。借这个概念理解匈牙利有启发，但不能把中国行政术语直接贴到匈牙利所有机构之上。

匈牙利需要同时观察行业部委、地方议会和地方行政、国营企业与合作社、商业网络和国家计划机关之间的交叉管理；**不同产业、不同年份及不同改革阶段的地方权限并不相同**。本讲主要分析工业部委—企业的纵向关系；地方制度的真实细节需要另用地区和企业档案核查，不能由P04模型的“regional”或“county”字段反推出历史行政层级。

## 三、关键历史过程：1950年代的形成、1960年代的运转与1968年的转折

### 3.1 1949年以后：为什么需要强大的综合计划机关

战后匈牙利在1949年后逐步采用苏联式中央计划管理体系。政府试图在相对短的时期里恢复生产、重建工业和扩大基础制造业。传统体制依靠中期计划、年度计划、实物分配和强制性企业指标组织这些目标。[H5]

这种制度有现实功能。一个资源稀缺、基础设施需要修复的工业化国家，若决定把钢材优先供应给电厂和大型机械厂，必须同时决定施工投资、煤电供应、设备与劳动力；没有跨部门的协调能力，许多关键项目根本不能按照统一战略推进。传统计划机关提供的正是一种**集中选择并贯彻优先顺序**的能力。

但问题随之产生：**如何避免“每个上级都认为自己的任务最重要”，而真实资源却不足以同时满足所有指标？**如果所有部委都要求多拿钢材、电力和机器，国家计划机关不仅需要加总申请，还必须核查生产和供给可能性，并在政治优先级之间作出艰难取舍。

### 3.2 1953—1957年：纠偏的尝试早于1968年改革

科尔奈原版前言说，1953—1954年前后匈牙利经济管理问题逐渐明显，他的研究起于1955年春。[H4]这意味着关于过度集中与企业主动性的争论，绝不是1968年才第一次被“发现”。

这种历史顺序非常关键：**传统计划经济在相当早的阶段就拥有自身批评者，而且批评者可以是深知实际企业运行的社会主义经济学家。**他们并不必然主张全部私有化或放弃国家计划，而往往首先主张减少僵硬的指标、改善反馈和允许企业根据真实生产条件调整决策。

科尔奈1957年谈到1954年前后缩减行政集中程度的尝试，并强调这些改动并未自动消除制度的内在矛盾。[H4]这提示我们，纠错困难的一部分来自**每个局部修正都受到整体制度的约束**：如果产值和奖金仍然支配行为，减少两个形式性报表未必改变企业的真实目标。

### 3.3 1961—1965年：第二个五年计划作为具体法律与行政任务

1961年匈牙利颁布第II号法律，规定1961年1月1日至1965年12月31日的第二个五年国民经济发展计划。匈牙利国家记忆委员会（NEB）公开的历史教学资料直接收录了该法摘录：首章就把完成社会主义基础建设与继续发展作为计划目标。[H6]

这一条史料价值不在于它能证明任何企业每天生产了多少，而在于它展示了宏观计划的**国家正式授权形式**：经济增长和工业化不是部委自行设定的一项孤立指标，而是政治目标、国家法令和行政计划联系起来的工程。

但也需要清楚：**法律中的发展目标不能直接当成完成结果**。要证明计划是否实现，需要实施报告、统计年鉴、实际交付量和消费者结果。政策文件告诉我们国家试图做到什么，不能单独告诉我们实际发生了什么。

从法律到企业，理论上需经过国家计划机关综合协调、主管部委分解、企业实施和统计反馈。科尔奈在1950年代轻工业研究中观察到的一些部门工作方式，为我们理解这一链条提供了直接线索；但我们不能不经档案检验就假定1957年的每项细节到1965年毫无变化。[H1][H6]

### 3.4 编制并不是每年一次的“交卷”，而是反复平衡

分析性地看，一份年度计划通常要完成以下相互依赖的工作：

1. 在既定战略下提出工业产量、农业供给、投资、消费、进出口和社会服务等目标；
2. 根据既有产能、劳动力、储备、运输和进口条件，估算可用资源；
3. 各专业部委提出本行业的任务与要求；
4. 综合机关比较各部门需求，识别钢材、电力、煤炭、设备、外汇等共同瓶颈；
5. 政治和政府领导机关确定目标排序、允许的成本及政策调整；
6. 部委将计划进一步转化为企业层面的约束与考核；
7. 企业接收任务并编排车间生产与交货；
8. 实际执行中出现差异，统计与报告反馈上行，随后产生计划变更、补充行政命令或重新分配。

这是依据多种制度研究重建的**概括性流程**，不是说所有匈牙利年度计划均以八个形式步骤依次发生。现实中步骤会重叠，多轮反复发生，有些政治决定在统计资料完备之前已经形成。

比“流程正确不正确”更重要的是：如果第四步发现资源不足，**哪个机关有权说某个计划目标暂时做不到？**如果坏消息意味着企业或地方“缺乏积极性”，真实信息还会顺畅上传吗？

### 3.5 1965—1968年：真正改变的是制度传动方式

匈牙利党内改革准备在1960年代中期加快。关于改革方向的党内文件在1965年形成初步纲领，1966年通过进一步指导方针，1967年进行实施准备，1968年1月1日新经济机制（NEM）开始实行。1965年11月与1966年5月的相关文件题名和章节，保存在1968年出版的匈牙利社会主义工人党中央文件汇编目录中；改革后法律体系的重建亦有后来的法律史研究。[H2][H7][T4]

NEM的要点并非“以后不需要国民经济计划”，而是计划机关不再如过去那样普遍把具体生产命令和投入分配向下逐一分解到企业；企业在更大范围内根据价格、利润、合同、税收和信贷作出微观决策，但国家保留战略目标、公有部门主导和大量宏观及行业调节权。[H2][T4]

这给我们一个非常清楚的制度对照：

| 核心问题 | 传统指令型计划理想型 | 1968年后NEM改革方向 |
|---|---|---|
| 国家目标怎样传到企业 | 部委层层分解强制性指标 | 主要通过经济规则、价格、税收、利润、信用与特定行政约束 |
| 企业对产量和产品组合的决定权 | 明显受行政计划限制 | 在规则限定下扩大自主决定 |
| 企业间交易 | 供应计划和行政分配影响很大 | 扩大企业间合同和交易联系 |
| 计划机关的职能 | 中观与微观指标协调均占重要地位 | 更突出国民经济总体比例和间接调节 |
| 国家所有制和政治制度 | 国家社会主义基本框架 | 基本框架保留，非“一夜资本主义化” |
| 现实问题 | 生产目标与微观需求错位 | 间接激励与国家保留控制之间也可能冲突 |

这里说的是**改革制度方向**，不是断言新制度立刻完全按设计运转。事实上，IMF的历史分析也强调，企业自主权扩大后，企业与中央间围绕计划指标的讨价还价部分转变为围绕经济调节规则的讨价还价，国家管理职能并没有消失。[H2]

因此真正值得追问的是：一个社会如果始终需要协调经济活动，改革怎样改变的是**协调机制内部的权利、激励与反馈关系**，而非消除协调本身？

## 四、经济学解释：真正决定制度表现的，是怎样连接目标、知识与行为

### 4.1 第一种机制：政治优先级为什么无法直接推出企业生产方案

假设党中央确定下一阶段要改善居民穿衣条件。这是**价值—政治目标**，在意义上并不等于“第17纺织厂下季度生产某类布料多少米”。两者之间至少缺少五种信息：

- **需求的构成**：居民需要多少童装、工作服、床上用品？对尺寸、颜色、耐用性有什么要求？
- **生产技术**：不同布料占用的设备、棉纱、化工染料和工时是否相同？
- **资源的稀缺程度**：扩大纺织品供应会不会挤占医疗纱布、工业帘布、出口纺织品的原料？
- **区域的差异**：物资生产地、流通地点与最终消费地是否一致？
- **反馈的可信性**：商业系统报告的缺货，是永久的真实需求，还是某种供应不稳定造成的临时抢购？

国家计划可以改变资源配置方向，却不能通过一条政治决议自动完成这些计算。**把政治目的译成操作性指标的中间过程，本身就是生产组织的一部分。**

马克思主义的“社会劳动按比例分配”命题要求一定的社会比例关系，但它并未预先回答这些比例怎样统计、谁来修订、参与者怎样报告真实状态。这正是我们理解20世纪计划管理实践的重点。

### 4.2 第二种机制：统计报表为什么不是现实经济的透明镜子

经济学中有个非常重要的区别：**真实状态**与**报告状态**。

工厂设备今天可以生产多少产品，取决于工人的技能、维修是否完成、关键零件能否送达、产品结构以及班次安排。这些实际条件不能简单归结为一项固定“设计产能”。企业报送的产能却往往需要是某个数字。

如果企业在完全诚实报告以后，自动面临更高指标、却不能保证获得足够投入和维修资源，那么它可能选择保守报告。一份“多要原料”的报表，也可能同时包含三种成分：真实生产需要、安全库存偏好，以及为了在上级压缩申请后仍然保有足量资源而故意多报。

因此，计划机关观察到的需求可写成一种概念性的关系：

> **报送需要量 = 真实预计需要 + 预防性缓冲 + 策略性申报。**

这不是可直接用来估计历史数字的统计方程，而是帮助我们**区分来源**的分析框架。实际工作中，这三部分往往互相缠绕，外部观察者也很难分开。

保守报送不一定纯粹是自私：在交货不可靠的体系里，企业储备更多材料有时是维持生产的合理反应。相反，如果所有企业同时这样做，汇总的物资申请又可能远超过实际可供应量。个体合理行为与总体协调之间，由此形成矛盾。

### 4.3 第三种机制：为什么指标体系会改变组织的真实目标

科尔奈1957年简报对“产值指标”的分析非常具体。用货币价值衡量的产品总量有利于考核增长，但企业可能偏向更费原料、却带来更高核算产值的商品；产品“质量指标”即使完成，也不能穷尽质量；成本降低也可能通过减少品种和牺牲某些质量实现。[H1]

考核指标并非毫无用处。没有任何统一指标时，上级难以判断企业是否履行义务。然而指标越是被直接连接到奖金、评优和干部前途，被考核者就越有动机研究：**怎样在制度允许的范围内，把数字做得更好？**

例如规定：“本季产值必须达到100万福林，否则企业负责人拿不到奖金。”这会强烈鼓励企业争取突破100万的门槛。但是如果某种产品比另一种产品消耗更多材料，单价又因行政定价而更高，生产前一种产品可能更容易完成产值任务，即使后一种才是居民真正需要的东西。

这里的批判不应粗糙化为“干部专门作假”。很多时候，企业生产的确是真实商品，账面产值也可能按规则计算；**问题是被优化的数字与社会希望优化的东西不完全一样**。组织经济学称之为目标替代或多任务考核问题。

在现实中，国家还可以设置产品实物数量、质量、成本、工资基金、劳动生产率等多个指标来补救。但科尔奈发现，不同指标之间存在冲突，获得强烈奖金激励的少数指标，可能在企业行为中压倒其他目标。[H1]

### 4.4 第四种机制：计划谈判为什么不等于企业拥有市场自主权

“讨价还价”一词听起来像市场交易，但传统计划体系中的谈判经常发生在**隶属关系内部**。

下级希望任务容易完成，因而倾向于争取较低指标、更多物资、更长建设期限；上级希望计划完成，并担心下级隐藏能力，于是倾向于压缩物资申请、提高任务或进行突击检查。双方都有信息，也都有权力，但两者分布不均。

设想某工厂按报告产能每季可以生产100件产品，实际在各种投入到位时可能做到115件。上级并不知道差额有多少。企业如果主动报告“我能做到115”，上级很可能将115作为下个季度的最低任务；如果未来煤、电、配件有一点短缺，企业完成指标就变得危险。因此企业可能只报告100或105，把少量未暴露的生产能力留作缓冲。

这种行为具有**动态性**：本期成绩改变下期目标，本期向上报告的方式又受下期奖惩预期影响。科尔奈的同期资料已经明确指出，完成任务以后新的完成水平可能被纳入下一期强制计划指标，从而抑制某些企业公开超额完成的积极性。[H1]

但这一机制不能无限推广。对社会声望、政治奖励、真实劳动成就感、职业晋升等高度敏感的管理者，可能愿意超额完成；新投资建设带来的真实产能扩张，也可能使提高指标完全合理。决定结果的不是“计划”一个词，而是**未来目标形成规则与奖励规则的组合**。

### 4.5 第五种机制：短缺为什么反而可能推动更多行政集中

如果原料短缺，上级通常会更想知道：谁拿了多少？哪家企业必须优先开工？谁有权调整计划？于是产生更多审批、配额和检查。

从局部看，这并不荒唐。如果只有100吨钢，却有多个重点厂抢购，政府为了保证医院、铁路或能源建设，自然会建立分配次序。然而更多审批又可能让正常替代、跨企业调剂和紧急采购变慢；企业因此更加担心未来拿不到原料，转而申请更大的安全库存。

于是可能形成以下反馈：

```text
生产与供应缺口
    ↓
企业储备与超额申报投入需要
    ↓
上级发现总申请超过可分配资源
    ↓
更严格的配额、审批、协调与检查
    ↓
企业的横向采购和及时替代更加受约束
    ↓
部分供给缺口继续存在 → 回到第一步
```

这不是声称所有行政集中都会造成更多短缺。恰恰相反，在极端短期危机中，统一配给可以压制投机性抢购并保障优先部门。**问题在于某一种紧急配给机制，若变成长期常态，能否同时维持企业的适应性与真实需求反馈？**

科尔奈1957年的分析正好触及这种双向关系：短缺要求更细的集中安排，而频繁的物资供应震荡又使这些细致计划难以执行。[H1]

### 4.6 第六种机制：“行政命令 vs 市场”并不是唯一选择

假设一家企业生产的铁轨不合格，另一家企业拒绝接受。可能采用的协调方式并不只有两个极端：

- 纯粹行政命令：由主管部门强制规定供应数量和去向；
- 完全开放的现货市场：买方自由向所有供应商询价采购；
- 企业长期合同：以质量、交货期和违约责任约束供应；
- 行业协调：由共同主管机构制定标准，再允许一定范围的企业协商；
- 国家保留战略物资配给，但允许非关键产品在规则内自由交易；
- 行政计划确定公共目标，具体产品选择由企业、用户和行业机构合作完成。

现实中的市场经济也广泛依靠企业内部计划、长期合同、政府采购和金融监管；社会主义经济内部也可能存在合同、价格和一定程度的市场交换。真正需要分析的是**决定权与风险由谁承担、不同组织如何获得信息、当规则冲突时谁有最后裁决权**。

计划机关面对的不仅是计算数量，而且是设计一种可持续运行的**组织秩序**。

## 五、一次能手算的经济实验：为什么“过度完成计划”反而可能是危险信号？

这是一个完全虚构的教学模型，使用件数而非真实匈牙利生产数据。它不为历史企业的行为系数提供估计，只证明某类激励结构**可能**带来何种反应。

### 5.1 先建立极简制度

一家工厂真实的季度最大产量是120件，条件是原料、设备和工人都正常。国家计划机关不能直接观察这个真实上限，只能看报表和上期完成量。

假设工厂本季得到任务100件，管理者只要达到任务就能获得一笔奖金；超过任务的额外奖励非常小。上级还有一条公开或不公开的调整规则：**本季实际完成的成绩有一部分会成为下季度的强制任务基础**。

假设两种决策：

| 策略 | 本季实际产量 | 本季是否完成任务 | 假设下季计划任务 |
|---|---:|---|---:|
| A：稳妥完成 | 102件 | 是 | 103件 |
| B：尽力增产 | 116件 | 是 | 110件 |

下季的任务数字是**教学设定**，不是某个具体时期匈牙利的制度公式。

如果两种策略本季都拿到几乎相同的奖金，B会付出更多组织努力，却让下季承受更高的最低完成门槛。在供应可靠、超额奖励很强的时候，B仍有吸引力；但供应不稳定、达不到100%会失去奖金的时候，A可能是企业管理者更稳妥的选择。

**于是我们得到第一条机制：**计划完成率本身并不能告诉上级企业的全部可用生产能力，更不意味着完成率最高者最有效率。

### 5.2 用一个算式说明跨期激励

设想工厂多生产一件的本期奖励相当于4个效用单位；如果这件额外产量导致下一期任务提高，由此形成的预期边际负担为6个效用单位。忽略其他因素，则：

\[
\text{本期额外生产的净激励}=4-6=-2
\]

净激励为负，并不表示多生产一件一定会破坏社会福利；只表示**在管理者所面对的奖励制度中**，该额外努力可能不划算。

如果国家改变制度，给真实创新和超额产量提供长期奖励，或者允许适当的能力缓冲，同时防止未来计划自动“吃掉”本期成果，那么这项净激励就可能由负转正。

请特别注意：社会真正关心的是新增产品带来的效用，以及其成本；管理者考量的却是自己承担的风险、奖励和未来指标。社会目标与代理人的私人或组织目标可能偏离。问题并不是管理者是否具备社会主义信仰，而是**制度是否把他的实际选择与社会结果联系起来**。

### 5.3 这个推导成立需要什么假设？

它至少依赖四项条件：

1. 上级无法完全直接观察真实产能；
2. 超额完成带来的即时边际奖励较小；
3. 本期完成量会抬高未来必须完成的目标；
4. 未完成未来任务的成本在管理者看来足够大。

只要这四个条件改变，结果就可能改变。比如某些战时工厂因为明确的政治动员、荣誉奖励与供应优先权愿意持续超额完成；另一些企业可能因为设备老旧，连保守指标也难以做到。我们不能从简单模型得出“计划经济企业必然少生产”的断言。

更重要的是，“瞒报产能”“要求松计划”不必总被解释为寻租。企业为了保护工人免于长期超负荷劳动、保留维修时间和预防生产事故，也可能合理地争取缓冲。这意味着行政考核应当同时记录**产量、可靠性、质量、设备安全与劳动条件**，而不是把所有缓冲简单视为怠工。

### 5.4 再加一个投入品约束，观察计划目标怎样互相冲突

同一季度，企业生产一件产品需消耗2单位纱线。上级给了120件的产能任务，却只批准180单位纱线。即使设备和劳动力允许120件，最多也只能生产90件——除非可以改变技术配方、从库存补足、获准向别处采购，或新投入到货。

这里我们在经济学上第一次明确区分：

- **任务约束**：行政目标要求生产120件；
- **技术约束**：一件产品需要2单位纱线；
- **物量约束**：本季可得纱线只有180单位。

在其他条件不变时，可行产量至多为 `180 ÷ 2 = 90` 件。

增加一条“必须生产120”的命令不会改变等式；增加30件产品的原料可能性，需要额外60单位纱线。如果主管部门又要求“确保达到100%完成率”，但没有同步解决物资缺口，上级可能得到一份更好看的计划书，却不一定得到更多布匹。

反过来，即使下拨60单位额外纱线，也不保证产品能送达居民手里，因为还可能受到染料、织机、运输和商业库存制约。后面的第03、07、08讲会进一步处理这些**相互耦合的真实资源约束**。

### 5.5 这里到底“证明”了什么？

只证明两件条件命题：第一，在特定跨期考核制度下，企业可能不愿向上级完全揭示自身的潜在能力；第二，在已知固定投入关系和有限材料条件下，仅提高任务目标不能提升物理可行的最大产量。

它**没有证明**：匈牙利1965年普遍瞒报多少产能、所有管理者都追求低目标、苏联或中国每个时期存在同样奖励结构、行政计划必然导致产出下降。

这类边界限定不是学术写作的繁文缛节，而是将机制直觉与历史证据区分开来的基本训练。

## 六、与HSM对应：模型能够表达哪一种“计划”，又缺少什么？

### 6.1 当前仓库的两个模型配置不是两幅可以直接对齐的历史照片

课程所用的HSM项目把物资、财政、家庭消费、供应网络与政治决策等放在可运行的季度系统中。根据2026年10月25日核对的 `README.md`，目前F1（`intermediate8_v1`）是八类商品的机制模型，承担部分P04政治政策分叉；F2（`f2_v1`）是十六类商品的历史复现尝试。两者总产量不能混合比较。[S1]

P04报告列出了政治—政策层的具体模块：

| 模块或路径 | 软件中的工作 | 与历史制度的相似处 | 不能由此推导的事 |
|---|---|---|---|
| `engine/politics.py` | 联盟权重和政策候选的规则更新 | 政治领导层不止一个目标 | 不等于历史政治局会议、真实派别力量或投票结果 |
| `engine/observation.py` | 企业报告偏差、独立观测噪声与状态观测 | 上级必须通过信息通道了解经济 | 未标定的偏差规则不等于真实企业瞒报比例 |
| `engine/policy.py` | 政策向物量、家庭参数和运行控制传导 | 政策应通过经济规则影响结果 | 政策参数不是某份真实部长会议决议 |
| `engine/material.py` | 中央/地方混合目标与生产物资运行 | 企业必须面对计划目标与资源条件 | 模型中的central/local混合不等于匈牙利真实行政权限分布 |
| `engine/political_run.py` | 按季度组织有政治模块的模拟运行 | 决策、执行、观测是连续过程 | 一个tick不等于真正一次计划会议或公报 |

以上文件路径来自 `docs/phases/P04_REPORT.md` 的实现说明。[S2]这里的“相似”仅是机制层面的类比，不是历史变量与模型字段的一一对应。

### 6.2 P04特别值得教学的设计：事件并不直接写进经济结果

P04报告明确写明外部事件须通过显式信号通道影响模型，不能凭“发生某一政治事件”就直接给社会支持率加一个常数。政策改变还需要经过相应参数与物资、家庭传导通道。[S2]

这对于理解历史计划经济很有意义：政治局发布工业调整方针，不意味着全国产量立即增加；政策只有经过部委任务、财政分配、物资供应、企业实际行动和后续反馈，才可能产生经济效应。

但是模型设计遵守“事件—通道—政策—经济”逻辑，并不证明这些通道的**历史数值**准确。根据仓库的P06最终报告，政治行为参数尚未识别，模型也未得到历史校准。[S3]

### 6.3 一个尤其值得讨论的零结果：改变政治参数却没有改变观察到的经济指标

P06的F1政治反事实实验，从共同的1967Q4 checkpoint分叉，记录了 `coalition-weights`、`soviet-constraint` 和 `cultural-openness` 等干预。三种情景均改变了内部重放身份，但报告的生产和家庭消费等指标与对照相同；文档明确保留了这一结果。[S4]

不能简单解释为“匈牙利政治联盟或文化开放对经济没有影响”。至少有四种不同可能：

1. 干预改变了内部状态，却没有充分进入经济政策的输出通道；
2. 相关传导在既定配置中存在阈值或饱和；
3. 报告指标不敏感，无法观测局部改变；
4. 在该特定模型和参数下，确实产生近似零的经济效应。

判断哪一种成立需要进一步审计模型通道和敏感性，不能用一份汇总表直接作政治经济史因果判断。

这一点恰好可以回扣历史材料：**有了政治决议，不等于企业立即改变行为；统计报表没有变化，也不等于政策在其他层面完全无效。**

### 6.4 F2目前的历史复现问题为何与本讲直接相关

根据 `P06_FINAL_REPORT.md`，F2在消费历史指数比较中没有复现出已登记目标的增长方向：模型1960年指数规范化为100，到1978年约为42.36，而目标指数为216。18个有信息量的年度全部超出预设容差；模型的出口支付路径还受到Treasury可支付资金约束。[S3]

这些都不能作为“历史匈牙利家庭消费持续下降”“匈牙利出口中断”的证据。相反，这是**模型结构与历史观测尚未对齐**的明显表现。

从第02讲的立场看，最值得研究的问题包括：模型是否充分表示了计划机关的长期结构调整、生产能力扩张和政策修订？企业对目标、资金和投入品的反应是否过度简单？家庭需求、生产和贸易之间的支付渠道是否封闭得过紧？这些都属于**待审查假说**，不能在讲义中偷换成已证实的原因。

### 6.5 把历史制度与模拟放在一起的正确次序

建议将来解读这个项目时始终遵循：

**历史制度**告诉我们实际存在了哪些组织、规则和权力边界；**经济理论**提出这些制度可能通过什么机制运转；**HSM模型**检验在一组明确假设下是否会出现某种响应；**独立历史资料**才能进一步约束模型参数和评价解释是否符合历史。

你可以把这当作一种跨学科的“从组织解剖到机制实验”方法，而不是试图从程序输出反推出当年国家计划局到底开过哪些会议。

## 七、与苏联、中国和匈牙利自身其他部门比较：哪些是共同机制，哪些不是？

### 7.1 苏联：国家计划委员会并不是所有企业的直接厂长

苏联传统体系常被描绘成莫斯科国家计委控制全国每一颗螺丝钉。这种形象抓住了中央协调的强度，却容易模糊实际权力分工。

保罗·格雷戈里（Paul R. Gregory）对苏联指令经济的概括更准确：党领导层提出经济优先方向；国家计划机关将方向转成面向工业部委的计划；部委制定企业操作计划并向下分配稀缺的物资；企业及部委的上级则根据产出表现考核下级。由于未来计划又与过去完成成绩有关，企业和部委具有隐瞒能力、夸大投入需求、回避风险技术的激励。[T2]

因此，苏联并非“单一计划者—千万被动执行者”结构，而是一套由**政治领导、综合计划机关、部门官僚与生产企业**连接起来的行政网络。

这种结构的主要优点是可以在跨行业优先建设与紧急动员上集中权力；其问题是：上级对于工业项目的掌握越依赖下级报告，下级又越可能根据上级考核方式调节报告行为。苏联不同年代有过多次工业管理改革，不能把1930年代、1960年代和1980年代视为完全相同的行政结构。这里比较的主要是传统指令经济的组织机制，而非每项具体机构编制。

### 7.2 中国“一五”计划：计划的制订经常与执行同时进行

中国1950年代提供了一个非常好的反例，帮助我们纠正“先有完整计划，然后全国照此执行”的线性想象。

国家发展改革委对当年计划工作的回顾指出，中国从1951年着手准备第一个五年计划，1952年国家计委成立，1953年开始执行“一五”，到1955年7月才正式经全国人大审议通过。在此过程中，计划经历多轮修改，还需要同中央部委、地方及苏联方面反复协调。[H8]

中国国家博物馆所藏《中华人民共和国第一个五年国民经济计划草案图表》（1953—1957年）特别有说明力：这是1955年3月国家计委印制的草案图表，而不是在1953年实施开始之前就已经完全定稿的最终文件。[H9]

这不是说中国那时完全没有计划，而是说**计划形成是一项渐进性的行政—政治知识生产过程**：工业项目的建设方案、苏联援建项目的进度、投资能力、国内原料供应和人才组织，需要在实践中不断重估。

这一过程反映了现代国家计划的实际困难——尤其在工业基础薄弱、统计与技术人员不足时，中央甚至很难在建厂以前准确知道每个项目的全部成本与时序。计划机关是一套逐渐学习的组织，而不是天然全知的经济计算器。

1955年7月30日全国人大关于“一五”计划的决议则展示了国家计划的正式政治和法定授权。李富春当时的报告和相关原始报刊，是进一步研究“一五”制度设计的重要入口。[H10]

### 7.3 匈牙利的地方与中央：一个信贷额度分配案例

为了看到“纵向部门”怎样与“地方现实”发生冲突，我们不妨跳出工业生产，观察住房建设。

一项依托匈牙利档案的研究讨论了1954—1956年个人自建住房项目的国家信贷安排。到1956年，一些地方当局发现，住房建设信贷额度被按行业和主管部委预先分配，导致某些符合贷款条件的当地工人无法得到资金；与此同时，某些被优先考虑行业的账户却留有未使用的额度。[T6]

研究举出的一个具体事件发生在1956年9月：杰尔—肖普朗郡（Győr-Sopron）的地方领导人在信中对按部门分配贷款提出批评，指出冶金和机器制造工业部（KGM）账户上仍有**150万福林**未使用，而其他行业的符合条件申请者却遭拒绝，并要求地方能够按照实际需要重新分配额度。[T6]

这一案例为何重要？因为它展示了一个与“总体有没有资金”不同的问题：**即使货币额度真实存在，行政授权与使用资格也可能造成资源无法转到更迫切的用途。**

不能由此断言国家当时所有住房贷款都是无效率的；也不能把地方提出批评等同于地方完全能够独立配置资源。它只是提供了一个罕见的、在地方与行业间具有可追踪证据的微观窗口。

这个例子也提示我们：部门协调中的失灵，不一定要等到整个社会发生严重短缺才出现。只要**预算、批准权、实际需要三者分属不同组织**，就可能出现“某处有钱却花不出去，另一处急需资源却得不到”的状况。

### 7.4 三种经验之间的真正相似性

苏联的工业部委与企业，中国的一五计划和中央地方协调，匈牙利的企业、住房和部门配额，看起来是不同历史事件，但可以抽出共同的比较维度：

| 比较维度 | 苏联经典指令体系 | 中国1950年代 | 匈牙利传统计划管理 |
|---|---|---|---|
| 中央协调目标 | 重工业、战略投资、生产计划 | 恢复后工业化与重点建设 | 战后工业化与国民经济比例 |
| 主要中介组织 | 国家计委、工业部委、企业 | 计委、工业部委、地方及企业 | 国家计划局、部委、地方、企业 |
| 典型信息困难 | 产能、材料申请、未来指标 | 项目规划、技术人员、统计与地方条件 | 产值指标、品种质量、企业报送与部门配额 |
| 关键政治经济问题 | 上级与企业激励不一致 | 建设任务、资源与国家能力如何磨合 | 指令体系如何容纳企业主动性与需求信息 |
| 历史差异 | 时段很长，管理体制多次调整 | 庞大农业人口、区域差异、建设起步条件 | 小型开放经济，对外贸易约束与企业改革条件不同 |

这张表只能提供**比较研究问题**，不能替代不同国家具体年度的历史材料。比如中国1958年以后大规模下放若干经济管理权限，说明“政治集中”与“企业归谁管理”并不会始终以固定比例对应。

## 八、学界争论、反例与尚未解决的问题

### 8.1 争论一：问题首先是“中央知道得不够”，还是“下级没有说实话的激励”？

第一种解释强调**信息与计算负担**。国家要决定多少种商品、投入和运输计划，生产与消费关系越复杂，中央就越难及时拥有充分信息。因而即便所有人员都诚实、专业而善意，仍会因为产品质量变化、地方差异和技术替代性而发生误差。

第二种解释强调**组织激励**。如果考核制度鼓励多要物资、少报能力、追求季度产值，即使有很先进的统计处理系统，也会源源不断输入带有策略偏差的数据。它更关注谁提供信息、信息真伪怎样验证，以及说真话是否会被惩罚。

科尔奈1957年已经把实际企业行为、指标与激励联系起来；格雷戈里强调苏联部委—企业的考核与讨价还价；而后来的经济计算争论则从不同角度强调协调复杂性。它们不必二选一。[H1][T2]

**什么证据有助于区分？**同一行业如果增加独立产能审计而不改变奖惩，报表是否显著变得真实？如果更换考核规则而不增加信息技术投入，库存和计划完成质量是否改善？如果两个措施一起实施，效果是否显著大于单独实施？这些问题比问“中央集权好不好”更加接近可检验的社会科学。

### 8.2 争论二：行政集中为什么能够创造工业化成果，又可能成为后来的限制？

一种解释突出**发展阶段**。在工业基础薄弱、资源集中到少数重大项目就可以扩大钢铁、电力和机器制造能力时，中央投资计划具有显著作用。随着产品种类增多、技术不断更新、消费者开始要求品质、服务和多样化，持续通过少数行政指标管理企业会越来越困难。

另一种解释强调**制度本身的协调能力并非自动递减**。即便经济很复杂，某些基础设施、电网、铁路、战略工业的长期投资仍可能需要中央协调；真正有问题的不是有无公共规划，而是微观经营是否缺少有效反馈、是否存在不可纠正的行政命令和不合理激励。

科尔奈1957年的简报并没有否认产量扩张的成绩。他批评的是将这个成绩组织起来的制度，在某些方面开始扭曲产品组合、材料使用和真实需要。[H1]因此历史研究应当把**工业建设能力与消费适应能力**分开测量。

### 8.3 争论三：1968年改革改掉了“错误”，还是换了一种矛盾？

1968年减少强制性的企业生产指令，原则上能扩大企业根据本地信息和用户需要调整行为的空间。但是，如果国家还保留广泛的价格控制、重要投资审批、财政补贴和对主要企业的救助预期，那么企业拥有一定经营自主权并不等于拥有完整的利润、风险与破产约束。

IMF的历史研究指出，匈牙利企业在新机制下的一些行政谈判关系并没有消失，而是转向对调节制度本身的谈判。[H2]贝拉·巴拉萨（Béla Balassa）等学者又强调，改革也确实在商品供应、企业关系和经济组合方面创造了一些积极成效，应当结合不同时期的改革推进与回撤来评价。[T3]

因此有两个应该同时成立的命题：

1. 传统行政指标可能确实造成了具体问题；
2. 废除部分指标本身，不会自动产生一套没有内在矛盾的新制度。

真正需要研究的是制度改革是否重组了整个中介结构：价格如何形成、预算如何硬化、谁有权投资、企业能否退出、居民需求怎样进入生产决策。这将在第14—16讲系统展开。

### 8.4 反例：为什么国家计划在一些任务上可能比地方自主协调更有效？

请想象一次突发洪水，国家必须紧急调拨铁路运力、钢材、救灾食品和工程机械。此时，用统一指挥确定时间优先级可能比让每个企业单独谈判更快、更清楚。再如全国电网、铁路干线和大型水利系统的建设，常常需要长期的跨地区投资协调。

**集中协调在目标清楚、技术路线相对确定、跨部门外部性较大、执行需要统一时，具有特别明显的优势。**即使在市场经济中也存在公共投资计划、国家储备体系和应急配给。

所以本讲反对的不是所有行政计划，而是**把所有不同性质的任务都交给同一种高度细化的行政指标体系，且缺少可纠错机制**。

更有价值的比较不是“中央或市场谁永远优胜”，而是：不同任务需要多强的集中度、多大范围的基层裁量、何种质量反馈与退出纠错渠道？

### 8.5 尚未解决的档案问题

若希望把本讲从高质量教学文本推进为可发表的匈牙利计划管理研究，仍需要取得至少四组更细的材料：

- **某一具体行业、同一年度**的国民经济指标、部委分解方案、企业最终收到的任务与季度修改文书；
- **实际生产报表**及其与设备状态、原料供给、质量、商业需求的相互核对；
- **企业向上申诉、物资追加申请和部委答复**，以区分真实瓶颈与策略性申报；
- **干部奖惩和企业奖金制度**，验证何种指标在行为上权重最大。

匈牙利国家档案馆明确介绍，国家计划局（OT）的档案材料覆盖工业、农业和商业企业计划，是研究1968年改革的重要史料基础。这为将来的深入研究提供了明确方向，但**档案馆证明有此类馆藏，不意味着本讲已经逐卷读取**。[H11]

## 九、本讲结论：国家计划是一种不断生产、压缩和反馈信息的组织关系

第一，传统国家计划的生命史比任何五年计划文件都复杂。政治优先目标经国家计划机关、部委、企业、资金和物资网络反复转换，最后才成为社会实际生产与消费。**不能把提出计划与真正实现计划混为一谈。**

第二，中央协调不是虚构的强制形式。它能够在资源紧张时为工业建设、战略项目和社会保障形成统一优先次序，特别适合有明确目标和强关联性的长期工程。但协调能力需要实物供给、专业行政和可信反馈，而不是只靠宣示意志。

第三，企业并非没有主体性的“执行零件”。即使在高度集中的体制里，企业也能够争取指标、解释困难、要求物资、调整工作节奏，并通过自己的报告反过来影响上级认识。研究这种微观主动性，是理解计划经济的必要条件。

第四，统计指标同时是认知工具与行为干预。上级通过数字看见企业，企业也会为了获得奖金、资源和职业安全而改变数字背后的真实行动。**信息不对称与激励结构相互作用**，通常比单独谴责某个干部“官僚主义”更有解释力。

第五，生产链横向依赖与行政层级纵向权力并存。国家越想保证物资优先分配，就越需要制度化协调供应；但只强化审批、不改善企业间交货和用户信息，也可能把局部瓶颈带入更多环节。

第六，匈牙利1968年改革的意义，首先是改变国家与企业之间的决策接口，而不是宣布人类社会不再需要经济计划。评价改革必须看它是否真正改变资源配置、企业风险、生产适应与居民生活，而不是只看命令条款数量减少了多少。

第七，从历史研究方法来说，计划制度有三种必须分别观察的东西：**正式规则、组织在规则下形成的实际行为，以及行为的真实经济结果**。企业计划有一百项指标，是正式规则；企业特别看重季度奖金，是行为；居民是否买到合适的商品，是结果。三者间存在因果联系，但绝不天然一致。

下一讲将进入这一组织机器的物理核心：即使所有领导和企业都诚实而合作，煤、电、钢材、机器、运输和消费品之间的投入结构仍然必须可行。**第03讲将用物资平衡与投入产出分析回答：全国计划为何不能只靠加总各部门的愿望形成。**

## 十、概念速查与思考题

### 10.1 十个核心概念

| 概念 | 本讲精确定义 | 最容易发生的误解 |
|---|---|---|
| 国家计划（national economic plan） | 国家授权的经济发展目标及资源协调安排，可含中长期、年度与操作性层次 | 误以为每项计划都是逐厂逐品种的命令 |
| 指令性指标（compulsory plan target） | 上级规定、下级承担实现责任的特定数量或财务任务 | 误以为所有统计数值都有相同强制力 |
| 物资分配（material allocation） | 对有限实物投入品规定供应、使用和优先次序 | 误以为纸面预算有钱就一定买得到投入品 |
| 纵向管理（vertical hierarchy） | 上级对下级行使计划、考核与行政控制 | 误以为它意味着上级掌握全部局部知识 |
| 横向联系（horizontal coordination） | 企业、供应商、商业机构之间的物资和信息关系 | 误以为只有市场经济才存在横向合作 |
| 计划谈判（plan bargaining） | 企业和上级围绕目标、资源与调整进行的组织性博弈 | 误以为等同企业在市场上自由定价交易 |
| 委托—代理（principal–agent） | 目标设定者与行动执行者的信息、利益与监督关系 | 误以为所有问题皆因个人道德低下 |
| 目标替代（goal displacement） | 可测量考核指标取代更复杂的真实任务 | 误以为改善指标就一定改善社会福利 |
| 跨期“棘轮”效应（ratchet effect） | 当前的较好表现提高未来目标，从而改变当前激励 | 误以为提高未来目标永远是不合理的 |
| 制度中介（institutional mediation） | 将政治目标转成社会经济行为的组织、规则、信息与执行链 | 误以为只要中央价值目标正确，结果自然正确 |

### 10.2 五个研究型思考题

**问题1｜年度与季度的悖论。**假设某企业不太关心年度计划，却非常关心季度完成率。你会优先修改年度计划的测算精度，还是季度奖金规则？能否设计一个反事实来区分两者效果？

**问题2｜计划谈判是真实信息还是策略行为？**一家企业连续三年要求提高钢材配额，每年又都能完成生产。你应当首先怀疑其故意多报，还是怀疑物资供给不稳定？需要哪三种独立数据才能判断？

**问题3｜“计划完成100%”究竟代表什么？**如果一家布厂完成110%的产值，但居民抱怨所需布料短缺，你将怎样重新设计至少三个彼此不可互相替代的绩效指标？

**问题4｜地方与部门利益。**回到1956年的匈牙利住房信贷案例：如果提高地方自由调剂额度，是否必然更公平？哪些全国性公共目标可能因地方调整而受到损害？

**问题5｜HSM的零效应。**一个政治干预改变了内部状态，却未改变模型生产指标。你会怎样判断是没有实际政策传导、已有约束饱和、报告指标遗漏，还是干预真实无效？请设计一次最小的对照实验。

### 10.3 建议的阅读顺序

第一步读科尔奈1957年同期英文研究摘要，重点关注年度和季度计划、生产指标、奖金、计划谈判、企业关系部分；第二步读1961年匈牙利第二个五年计划的法律摘录和国家计划局档案目录；第三步读1966年改革文件的研究介绍与1968年后制度回顾；最后才把这些历史机制映射到HSM的P04规则。[H1][H6][H11][H2]

## 附录A｜读一份国家计划，应该建立什么“证据卡”

如果以后得到某一年匈牙利国家计划局文件，可先不急着作出“计划失败/成功”的评价，而为每条重要指标填写：

| 字段 | 应记录的信息 | 为什么必须记录 |
|---|---|---|
| 来源身份 | 档案馆、全宗、档号、文件日期与发布机构 | 确认这是决议、草案、执行报表还是回忆 |
| 目标对象 | 钢铁、农业、运输、某行业或某企业 | 防止把宏观与企业指标混用 |
| 指标性质 | 有法律效力的任务、行政指导、预测、统计口径 | 不是每个数字都具有同等约束力 |
| 责任主体 | 国家计划机关、部委、企业、地方机构 | 确定谁有能力改变执行结果 |
| 资源条件 | 设备、劳动力、材料、资金、进口、运输 | 判断计划是否物理上可行 |
| 计划更改 | 修改日期、提出修改者、批准者、原因 | 找到反馈与纠错的实际位置 |
| 执行资料 | 真实产量、交付率、质量、成本、库存 | 避免把完成率当成全部绩效 |
| 社会结果 | 谁实际得到商品、改善了什么、产生何种代价 | 重新连接政治目标与人的生活 |
| 可比性 | 商品分类、币值口径、统计制度变化 | 防止跨年份或跨模型错误比较 |

**这份表既适合读社会主义计划档案，也适合审查今天任何大型公共项目。**它最重要的作用，是把宏观结构判断拆成可核对的制度环节：当中央、地方、企业及劳动者之间出现矛盾时，我们究竟知道哪个环节出了问题？

## 附录B｜一个不用编程的“计划传导检查”

任选一项现实公共目标，比如“未来三年增加某地区医院的医疗设备”，尝试把它分成以下六个步骤：

1. 目标：哪类患者的诊疗机会需要改善？
2. 资源：设备、专业人员、财政和持续运维分别需要多少？
3. 中介：哪些组织有采购权、人员编制权、审批权？
4. 指标：如何知道医院确实提升了服务能力，而不仅仅买了设备？
5. 反馈：医生、患者、财务人员提出问题以后，谁必须回应并修订方案？
6. 证伪：出现什么结果时，应承认原来的方案不适合？

然后把这六步套回1960年代的布匹、钢材或电力计划。你就会发现：**理解计划经济的真正关键不是学会崇拜或憎恨计划，而是学会看清现代社会的协调中介怎样运行。**
