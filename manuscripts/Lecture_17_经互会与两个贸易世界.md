## 本讲最重要的20%

**第一，国家计划经济并不意味着对外经济关系可以直接照搬国内的行政计划。** 在一国内部，政府可以通过计划、财权和物资调拨，将同一法权体系下的不同生产单位组织起来；但即便都是社会主义国家，两个政府也不能仅凭各自的计划命令对方交付钢材、石油或机器。它们必须谈判品种、数量、质量、价格、交期、运输和结算。**国际间的实物承诺与支付清算，是不同于一国内部计划命令的制度关系**。这正是经互会（Council for Mutual Economic Assistance，CMEA／Comecon）自1949年成立之后长期试图处理的问题。[A1][A2][H1]

**第二，经互会不是一个覆盖成员国所有企业的“超国家戈斯普兰”，更不是一个不用钱的巨大物物交换集市。** 成员国在双边贸易协定和五年贸易安排下形成供货承诺，再通过年度议定书、外贸机构合同、银行账户和国际清算履约。1963年成立的国际经济合作银行（IBEC）于1964年引入**转账卢布**（transferable ruble）和多边清算，确实是一次制度创新；但转账卢布主要是一种特定体系内的记账和清算单位，并未获得美元那样的自由可兑换性，也未完全摆脱双边实物贸易安排。货币账户的贷方余额与真正可买到的商品之间，始终存在一道制度屏障。[A1][A2][T1]

**第三，“两个贸易世界”不是简单的地理划分，而是两种支付约束。** 匈牙利可以用计划内出口的工业品和农产品，换取苏联的能源、原材料及其他伙伴国的商品；它还需要用**可兑换货币**购买国际市场上的某些设备、技术和原料。前者的困难往往是对方能否依贸易协议交付所需实物，后者则进一步受出口赚汇、外汇储备、信贷与到期债务制约。反过来，社会主义国家之间也可能使用美元等可兑换货币结算，不能把贸易伙伴的政治属性直接等同于支付币种。[A3][A4]

**第四，匈牙利不是被动依附两套市场的旁观者，而是不断探索改革国际社会主义分工规则的参与者。** 1969年的匈牙利方案尝试扩大无具体配额贸易、提高转账卢布的实际使用价值，并提出逐步建立与可兑换货币的联系。1971年经互会综合合作纲领提出更深入的协调目标，但成员国并未因宣布“社会主义经济一体化”就让渡所有投资、产业和贸易自主权。匈牙利在对经互会深化合作感到失望的同时，加强了对西欧和全球南方的经贸联系；这种双向策略既有利益，也逐渐带来新的外部支付风险。[A5][H1][H2]

**第五，历史的实际贸易增长与当前HSM的失败结果恰好构成一项鲜明对照。** 匈牙利中央统计局的长期贸易量指数（1960年＝100）显示，**出口由1960年的100上升至1978年的524、1985年的770，进口同期由100上升至503和508**。而HSM P06模型的出口指数早在1962年就已归零，之后又受到国库可支付资金的限制。模型虽然能分别处理经互会／可兑换货币渠道并通过账本检查，却没有准确复现历史中的出口持续增长。这是应当定位、修复并重新检验的**历史复现失败**，不能改写成有关经互会或匈牙利的现实结论。[A6][S1]

## 一、历史现场：一批匈牙利机器，为什么未必能换回所需要的西方设备？

### 1.1 从一家工厂的“可完成计划”出发

先设想1970年代初布达佩斯附近的一家匈牙利机械制造企业。它生产的某类机床已经列入向社会主义伙伴国交货的贸易安排。国内主管部门希望它依约供货，因为伙伴国订购的机床与匈牙利向该国争取的能源、材料或别的设备相联系。但与此同时，这家企业的总工程师希望引进一套新的西欧精密加工设备，用以提高机床精度、改善质量。企业在国内账面上并非没有收入，国家甚至可能对它有明确的投资计划；问题是它的计划内贸易收益，**并不自动等于有一笔可以直接交给西欧厂商的德国马克或美元**。

这里的工厂是**教学场景，不是某一家真实工厂的档案重建**。我们没有据此发明某位厂长的谈话、外贸合同或金额。但是场景所呈现的制度矛盾，可以从1976年的同期IMF研究、1982年的匈牙利经济调查以及改革研究得到明确支持：经互会结算收入的可用性、商品配额和国家外汇支配权，确实是不同层级的约束。[A3][A4][H3]

工厂面临的不是一道“市场好、计划坏”的选择题。西欧设备也可能受出口许可证、资金、质量认证、贸易保护和政治限制；即便拥有可兑换外汇，也不保证买得到全部技术。另一方面，经互会长期供货协议可能保障它在西方景气变化时仍有市场，也可能以有利条件获得某些能源与原料。**真正的问题是：不同支付区的账目和实物能否被相互调剂，代价由谁承担。**

### 1.2 1969年匈牙利的一份改革设想

这不是后来经济学家站在1989年的终点回望时才发现的困难。1976年《IMF Staff Papers》刊载的一项系统研究专门概述了**1969年的匈牙利转账卢布改革建议**：逐渐扩大不依赖逐项实物限额的贸易，在贸易协定中增加只约定总价值而不逐项规定数量的安排；促使成员国获得的转账卢布更加能够购买所需商品；在此基础上，再谋求一定程度的可兑换性。[A3]

这里要严守史料层级：本讲核对的是**1976年研究者对1969年方案的同时代概述**，并非已查阅匈牙利该提案的每份原件，也不声称其内容一字不差。这份资料已经足以证明一件事：当时的决策者并不满足于“贸易账面能够平衡”，他们已经意识到**结算单位的可支配性**会反过来影响企业出口动机、商品质量要求和跨国分工效率。

1976年的研究还记载了1965年波兰经济学家提出的类似讨论：部分转账卢布顺差应当在一定条件下可兑换为硬通货。两种设想的共同逻辑并非“放弃社会主义阵营”，而是让一笔出口收益变得真正有价值，避免国家为了完成配额而出口难以获得有用回报的商品。[A3]

### 1.3 三个不同的人，会怎样看待同一笔出口？

同一笔机床出口，可以在三个层级上得到完全不同的评价。**厂长**关心是否完成生产任务、获得价格与奖励、维持原材料供应；**外贸机构与银行**关心出口合同、清算币种、对方付款是否进入规定账户；**国家领导层**还要关心同苏联的能源供货关系、可兑换外汇的长期缺口，以及居民生活所依赖的进口是否得到保障。

如果对外出口的机床仅在账面上形成一笔转账卢布顺差，却不能据此进口企业急需的特殊钢材，那么对厂长而言“完成国家出口任务”和“改善下一年生产能力”之间就可能出现矛盾。如果政府允许企业自由持有全部外汇，则国家的进口优先序与外债支付又可能受影响。社会主义国际贸易困难不是因为其中某一位行动者必定愚蠢，而是**多套目标和约束通过不同账户叠加在一起**。

这段叙事也为第18讲预留了问题：国家能否通过向西方银行借款，在短期内暂时跨过这种外汇约束？如果能，随后怎样偿还？

## 二、先把制度机器拆开：经互会贸易到底由谁决定？

### 2.1 成立经互会：协调各国计划，而非把国家合并成一家企业

经互会于1949年成立，早期成员包括苏联和数个东欧社会主义国家。其出现既有战后国际政治阵营形成的背景，也有更实在的经济问题：东欧各国战争破坏程度、工业结构、能源资源和对苏关系不同，一国生产计划要长期运行，就需要在跨国层面协调可获得的钢、油、机器和食品。与其仅在商品短缺发生后临时采购，事前达成多年供货协议有明显的稳定性价值。[H1][H4]

但这里不能跳过一个政治经济学事实：**苏联与匈牙利是两个国家，并不共享同一国家预算、同一工业部和同一套所有权登记。** 即便政党同属社会主义阵营，匈牙利计划机关也无法像给本国工业部下达命令一样，要求苏联某炼油设施自动转产，或让捷克斯洛伐克铁路优先为匈牙利服务。因此跨国协调必须诉诸国家间同意、互换条件以及执行安排。

1971年经互会通过正式的《进一步扩大和改进合作及发展社会主义经济一体化综合纲领》（通常简称**综合纲领**）。它要求加强长期计划协调、生产专业化、技术合作、联合投资以及货币金融合作。但纲领的雄心与各国真正愿意共享的信息、让渡的决策权并不相同；后来的联合国研究将这种落差视为社会主义一体化始终难以彻底解决的制度问题。[A5][H4]

### 2.2 从国家领导机关到货车：五个衔接层次

以典型的计划内贸易为例，贸易的运行可以依次拆成五层。

**第一层：国家之间谈“要什么、能给什么”。** 计划机关、主管部委、外贸机构以及必要时最高领导层围绕五年计划时期的进出口品种与总量展开谈判。产业结构与政治关系会影响谈判起点：苏联在能源和原材料方面往往处于供应关键位置，部分东欧国家则试图以机器、运输工具、工业制成品和食品换得所需投入。[A3][A4]

**第二层：双边中长期协定。** 一国与另一国约定一定期间的供货框架。这既是一种贸易承诺，也成为国内计划编制的前提：某钢厂预期得到的矿石、某炼油厂预期得到的原油，可能已经被列入未来数年的生产计划。

**第三层：年度协议与具体合同。** 年度议定书使框架逐年具体化。由国家许可的外贸组织签订合同，处理型号、品质、数量、交货期限及运输等细节。合同并非可以忽略的“小事”：一台机械的技术规格不合用，账面上再平衡也无法让下游工厂正常运转。[A4]

**第四层：实物交付。** 货物必须经过生产、铁路或管道、边境、仓储、进口验收，并进入国内物资分配和生产环节。只有写在计划中、没有完成运输或验收的原材料，不能用于本季度的生产。

**第五层：国内支付与国际清算。** 本国出口生产者一般在国内货币和国内制度下获得相应款项，外贸机构及银行再按贸易协议办理跨国货币结算；进口企业的国内支付和跨国结算也未必是同一货币与同一价格。这一点最容易被“两个国家互换一批货物”的简单讲法掩盖。[A3][A4]

### 2.3 为什么五年双边协定并不自动等于真实的多边分工？

请想象三个国家：匈牙利善于提供一类机床，波兰愿意购买它；波兰有另一类设备可供苏联；苏联则能向匈牙利供油。三个国家加起来可能恰好满足各自需要，但如果每对国家都坚持贸易必须分别相抵，匈牙利与波兰的顺差、匈牙利与苏联的逆差就可能不能顺畅地跨国抵消。

这是**双边主义**（bilateralism）与**真正多边结算**（multilateral clearing）的区别。经互会显然理解多边主义的潜在收益，所以才建立专门的清算银行。但是，银行在总账上开出跨国账户，不等于每个国家都接受用本国急需物资去兑付另一个国家从第三国获得的余额。**实物供货的政治经济约束，可以使形式上的多边清算继续表现为实际的双边贸易平衡。**[A3][T1]

### 2.4 国际投资银行与国际经济合作银行不是一回事

还需要区分两家容易混淆的机构。1963年成立、1964年开始运行转账卢布清算体系的是**国际经济合作银行（IBEC）**；1970年另行成立的**国际投资银行（IIB）**主要面向较长期的共同投资和相关融资安排。前者的核心问题是贸易清算及短期信贷，后者牵涉共同投资、收益分配和项目实施。因此，不能看见“经互会银行”便假定它能够像现代资本市场一样，把成员国居民的全部储蓄自动转化为跨国最优投资。[A1][A7]

## 三、历史过程之一：从战后双边清算到1964年的转账卢布

### 3.1 为什么战后首先流行双边清算？

战争结束后的欧洲面临外汇短缺、运输受损、物资供应不足以及政治秩序重组。对于计划经济政府来说，贸易安排经常首先要回答的不是“汇率市场今天报什么价”，而是“这五万吨钢能不能保证到货；这批机器能不能换到石油”。双边清算账户因此很有吸引力：双方在商定的记账单位中记录进口与出口，尽可能通过后续实物交付清理差额。它可以减少对稀缺美元储备的即时需求。[H4][A8]

但成本同样存在。如果甲国能够生产的主要商品不是乙国想要的，而乙国又握有甲国所需原料，双边协议就难以达成物量和金额同时可接受的交易。若为了让账面相平衡而被迫接受不够有用的商品，贸易规模增加也未必改善整个经济体系的效率。

这并不是社会主义国家独有的支付问题。战后资本主义国家也曾广泛使用贸易与支付协定、双边清算和外汇管制。社会主义体系的特征在于：**其与国内国家计划、物资供货协议、国营外贸垄断和行政价格的结合更加深入**。因此不能从“存在清算账户”这一个共同点，就断言各体系在激励和权利安排上没有区别。[A8]

### 3.2 1963—1964年的改革究竟创新了什么？

国际经济合作银行自己的历史资料将关键时间列得很明确：**1963年10月22日**，包括匈牙利、苏联、民主德国、波兰、捷克斯洛伐克等在内的八个成员国签署设立该行的国际协定；**1964年**，转账卢布及通过IBEC进行的多边清算制度投入运行。[A1]

这项创新值得认真评价：成员国不必只在两国中央银行间逐笔平掉所有账务，国际银行可以维护统一的记账和清算框架，并为成员国之间的贸易融资创造制度通道。从技术上看，这是将庞大的双边记账网络进行部分集中化，是一种真正存在的社会主义国际金融基础设施，而非空洞宣传。[A1][T1]

但是，它并没有自动把转账卢布变成在市场上任意兑换的世界货币。1976年的研究强调，转账卢布余额主要由成员国的外贸银行及相关机构持有，不能像自由流通现金一样在普通企业或公众之间自由使用；1990—1991年对制度终结时的总结进一步指出，即便存在统一银行账簿，成员国仍需反复通过双边供货协商使贸易大体平衡。[A3][H5]

### 3.3 “转账卢布”：四个容易混淆的含义

**它是记账单位。** 两国要比较不同商品合同金额，需要用一个共同单位记账。这不意味着它具有普通银行存款的全部支付自由。

**它是清算单位。** 银行可以借记、贷记成员国的规定账户。这不意味着账户持有人可以未经对方同意购买任何商品。

**它有国家间信用安排。** 清算体系可以记录余额、提供一定信贷或允许后期调剂，但这些余额受到合同、额度、供货能力等限制。

**它不是美元、也不是可以在苏联普通商店使用的国内卢布。** “卢布”这个共同名称非常容易误导初学者。转账卢布、苏联国内货币和匈牙利福林属于不同制度账户，并不因官方公布了某个折算比率就自动相互可兑换。[A3][H5]

用一句话概括：**记账上的可转移性、付款时的可兑现性和交易时的商品可获得性，是三种不同能力。**

### 3.4 用一个同时代反例检验“转账卢布完全解决贸易协调”

如果转账卢布真的使成员国出口所得具有近似通用货币的购买力，就无需在其实施之后持续讨论如何提高可用性。事实上，波兰经济学家1965年的方案和匈牙利1969年的方案，都直接指向这个缺口：持有顺差的人希望能购买所需的紧缺商品；不能购买时，至少希望部分余额可以兑换成更有用途的货币。[A3]

这不是证明当时所有清算安排都没有成效。它证明制度改进存在**不完全性**：既减少了一些结算摩擦，又没有消除实物契约、行政许可及国际供求的根本制约。

## 四、历史过程之二：1971年综合纲领和匈牙利的改革愿望

### 4.1 1971年不是从零开始的“社会主义经济一体化”

1971年经互会第25届会议通过一份雄心很大的纲领，正式名称为《进一步扩大和改进经互会成员国合作与发展社会主义经济一体化综合纲领》。经互会秘书处当年出版的英文版本有99页，可从该正式出版记录确认其存在与框架；但**本讲没有把目录记录冒充已经逐页精读原件**。[A5]

纲领试图推进更长期的生产专业化、合作投资、共同科研和技术协调，并在维持各国计划制度的前提下增强跨国合作。如果一国集中制造一种设备，其他国家无需都为相同产品建设完整生产线，的确可能节约投资、改善专业化。这种思想并非经济学上不可理解，相反，它回应了上一编讨论的规模经济、投资重复和创新成本。

然而，经济一体化必然要回答政治经济学问题：谁决定某国不再制造某种机器？停止生产后形成的失业与地方损失由谁承担？对另一国的长期供应依赖是否安全？没有得到这些问题的制度性回答，专业化收益再明显也不一定转化为可执行的合作协议。[H4][T2]

### 4.2 匈牙利为什么既推动经互会改革，又试图向西方开放？

帕尔·格尔穆什卡（Pál Germuska）利用匈牙利国家机关、政党及高级经济领导人的档案研究指出：匈牙利在1968—1982年间始终倾向于推进更深的经互会合作；但当一体化实际停留在较多双边商品交换和有限部门合作时，布达佩斯也逐渐加强同经互会以外世界的联系。研究者特别将1977年视为经济政策认识转折的时间点。[H2]

这揭示一个看似矛盾却很自然的选择逻辑：**一个想改善社会主义计划效率的政府，可能一边尝试改良社会主义国际结算与技术分工，一边进口西方设备、技术和管理知识。** 改革者不一定认为这两个方向必然冲突；只是二者在外汇、政治关系、产业保护和投资项目上可能争夺有限资源。

从事后来看，匈牙利后来形成严重外债压力，很容易把1970年代的对外开放概括为“错误”。但以1970年的信息条件判断，获得国外技术、开辟出口市场、在经互会之外分散供应风险，都有可以理解的理由。必须进一步追问**项目是否增加了可出口竞争力、贷款期限是否与产出形成时间匹配、进口是否真正提高了未来偿债能力**，而不能从最终危机反推此前所有开放都不合理。这些问题将在第18—19讲详述。

### 4.3 两条制度轴线，不能压扁成东西方阵营

把对外贸易画成“社会主义国家间贸易”和“对资本主义国家贸易”两列，固然比毫无分类好，但远远不够。**第一条轴线是贸易伙伴所属国家，第二条轴线是合同以什么币种和清算规则结算。**

例如，向苏联出口机器可能列入转账卢布安排，也可能属于另行签订并以可兑换货币支付的交易；向某个非社会主义国家出口农产品，通常又必须考虑国际金融支付条款、进口许可、汇率和关税。不同合同的支付条件不应被国家政治名称覆盖。1982年IMF调查实际将这两条轴线分别统计，这一点有量化证据支持。[A4]

同理，不能把“从资本主义国家进口”当成“直接在自由市场上由每一家社会主义企业自行购买”。匈牙利的外贸许可、外汇分配、国内价格和银行控制直到1980年代仍发生着复杂变化。外部市场存在，并不等于国内企业已获得自由买卖外汇的权利。[A4][H3]

## 五、价格、能源和商品质量：为什么国际计划也逃不开机会成本？

### 5.1 国际价格怎么定？“行政价格”不等于毫无国际参照

第04讲已经讨论过行政价格与影子价格的区别；这里遇到的是另一种情形：两个政府必须给跨国交付的商品确定价值。如果完全按各自国内行政价格计算，一国的计划成本制度、补贴和汇率安排就可能直接影响另一国的采购决定。因此经互会贸易长期尝试使用**经调整的世界市场价格**作为谈判依据，而不是简单把成员国内部的零售价格加总。[A3][H5]

1958年前后形成的“布加勒斯特原则”（Bucharest principle/formula）是其中的重要框架。按照较早的做法，某个五年计划期间的部分合同价格参考此前一段时期的世界市场价格平均值，经过调整并通过谈判固定在一定时期内。这样能够减少世界市场短期波动对长期供货合同的冲击，也符合计划机关希望保持跨期价格稳定的要求。[A3][H4]

但**谈判价格不等于单纯输入一条公式的客观数值**：原料、燃料相对容易寻找国际可比价格；规格复杂的设备、具有质量差异的机床或专用技术服务则难以建立同质化比较。交易一方可能用西方同类设备报价进行谈判，另一方则强调运输、成套服务或特别工艺。即便名义上采用相同定价原则，实际交货价格仍可能因为质量、技术规格、政治谈判和合同细节而不同。[A3][H5]

### 5.2 为什么经互会内部也会出现“硬货”和“软货”？

1976年的同期IMF研究使用了两个值得辨析的术语。**“硬货”（hard goods）**通常指那些在社会主义贸易体系中供给紧张、并且比较容易在西方市场换取可兑换货币的原材料、某些半成品和高技术设备；**“软货”（soft goods）**则指在相应合同价格和质量条件下更难在西方获得买家的商品，某些消费品和一般机器可能属于这一类。[A3]

这不是把“硬货”定义为客观上有用、把“软货”定义为客观上没用。它描述的是特定国际交易环境中的**稀缺性和出口变现能力**。某种机械对波兰企业完全有用，但若其工艺、可靠性或售后保障达不到西方采购商要求，就可能只能在经互会内部出售。反过来，苏联原油无论供应到哪里都具有直接的能源用途，并且更容易找到以可兑换货币支付的潜在买主。

由此可以推出一个重要的制度问题：如果某成员国大量出口内部难以销售的商品，却要求另一成员国提供稀缺的石油与特殊钢材，双方即便按合同金额“等价”，**并不意味着实际机会成本相同**。卖方愿不愿意继续提供稀缺品、愿以何种配额提供、能否保证质量，就成为比账面汇率更有约束力的条件。[T1]

### 5.3 能源价格如何把世界市场传进经互会？

1973—1974年世界石油价格发生显著跳升后，长期固定的经互会合同价格与新的市场价格出现明显差距。苏联作为主要油气出口国，面对的外部机会成本发生变化；东欧进口国则希望避免突然大幅提高能源支付额而扰乱国内计划。[A3][H6]

从**1975年**起，经互会改变价格形成方式，逐步采用每年调整、参考此前五年世界市场价格移动平均值的做法。研究资料对1975年作为过渡年所用的基期与正式实施细节有不同表述，但共同说明了这样一种时间结构：此前大体按五年固定区间决定价格，后来改为逐年重估、仍保留五年平均的平滑机制。它使世界价格冲击**延后、分期**进入社会主义贸易，并没有永久将成员国隔离在世界市场之外。[A3][H5][H6]

这意味着：在世界油价上涨时，较低的历史平均价格对进口国可能是一种过渡性优惠；但在世界价格下跌时，移动平均中的较早高价会使合同价格下降得较慢。所谓“稳定”，既可能是缓冲机制，也可能在价格趋势反转时变成滞后成本。第18讲会进一步计算其对外债和经济增长的影响。

### 5.4 不能把有利价格与“真实补贴”不经核对地等同

有的经济史解释强调，苏联低于即期世界市场价的能源供给，事实上向东欧提供了巨大支持；另一些解释则指出，若没有可自由出售的出口通道、运输成本、质量差异和双边配套出口义务，直接按国际现货价格乘以数量估算“补贴”，可能夸大可以兑现的收益。[T2][H6]

一个审慎的测算至少需要四张表：**合同油价和质量、可比世界价及运费、实际输送数量、对方要求的设备或商品的真实机会成本**。如果按世界市场价给油，却要求以高于国际可替代成本的价格购买难销售机器，贸易双方的净利益就不能只看石油这一项。反过来，如果这些机器是进口国可靠的生产必需品，价值也不能简单按西方低价替代品计算。

因此，本讲不在没有完整数据的情况下凭一个数字宣布“经互会对某国净补贴了多少亿美元”。这类计算在下一讲可以作为待验证的反事实，而不应被写成天然确证的账本。

## 六、历史过程之三：1960—1985年匈牙利外贸究竟发生了什么？

### 6.1 先看实物贸易的长期扩张

匈牙利中央统计局KSH公布的长期《货物对外贸易》表，提供了以**1960年＝100**为基期的进口量与出口量指数。精选年份如下：[A6]

| 年份 | 进口量指数（1960=100） | 出口量指数（1960=100） | 历史解释的最低限度 |
|---|---:|---:|---|
| 1960 | 100 | 100 | 基期，本身不表示当年贸易规模大小 |
| 1965 | 158 | 170 | 外贸实物量相对基期已有明显扩大 |
| 1968 | 203 | 216 | NEM实施年份，不等于增量全由NEM造成 |
| 1970 | 274 | 266 | 进口量扩张速度在这一基期比较中较快 |
| 1973 | 318 | 394 | 石油冲击前后的外贸已经具有较大规模 |
| 1975 | 398 | 427 | 世界价格变化不能从本表直接读出 |
| 1978 | 503 | 524 | 进口量约为1960年5.03倍，出口量约5.24倍 |
| 1980 | 473 | 588 | 进口量指数低于1978，出口量仍高于1978 |
| 1982 | 463 | 642 | 实物进口压缩与出口扩大可并存 |
| 1985 | 508 | 770 | 两类实物量指数都明显高于1960年 |

**资料**：KSH, *3.3. External trade in goods (1960–)*，长期表，2021年3月4日更新，原表以1960=100记录各年货物进口与出口量指数。表内年份和数值直接摘自该长序列；没有将其换算成国内生产总值或当年美元。原表链接见[A6]。

这些数值说明匈牙利是一个不断深化国际商品交换的社会主义经济，而不是一个在1968年改革前“根本不与世界进行贸易”的封闭社会。不过，本表不能直接回答四个问题：每年总贸易额多少福林或美元？究竟向哪个国家出口？货物结构是否升级？这些商品值不值得出口？**数量增长不等于贸易条件改善，更不等于出口增加必然带来净外汇收益。**

要研究这些问题，需要另一组统计：国家与货币的双重分类，以及国际收支表。

### 6.2 真正重要的口径：贸易伙伴与结算货币交叉分类

1982年发表的IMF匈牙利经济调查在附表中引用匈牙利官方外贸统计，区分以卢布结算和以可兑换货币结算的贸易份额。下面摘录其中两年：[A4]

| 指标 | 1977年 | 1981年 |
|---|---:|---:|
| 出口：以卢布结算的份额 | 50.4% | 44.0% |
| 出口：以可兑换货币结算的份额 | 49.6% | 56.0% |
| 进口：以卢布结算的份额 | 46.2% | 45.7% |
| 进口：以可兑换货币结算的份额 | 53.8% | 54.3% |

**资料**：IMF，*Hungary: An Economic Survey*（1982），表41，依据Hungarian Central Statistical Office *Statistical Yearbook of Foreign Trade*；这里的百分比为相应年份**出口或进口总量按该研究采用的贸易金额口径划分的结算货币份额**，不是外贸实物量指数，更不是贸易伙伴的政治制度占比。

为什么“匈牙利对社会主义国家出口占比”会与“卢布结算占比”不同？因为**贸易伙伴是社会主义国家，合同仍然可能以美元等可兑换货币支付**。IMF特意提醒读者，这个差异不能略去。1977—1981年匈牙利向社会主义国家出口货物并取得可兑换货币，并非偶然的统计误差，而是已被同期调查单列的重要交易类型。[A4]

另一组具体数字尤其直观：在该研究的表33中，**对社会主义国家、但以卢布以外货币结算的贸易**，1977年出口581百万特别提款权（SDR），进口362百万SDR，商品贸易顺差219百万SDR；到1981年，对应出口1049百万SDR、进口450百万SDR，商品贸易顺差599百万SDR。[A4]

这意味着，把“社会主义国家之间贸易”与“无法赚取任何外汇的贸易”视为同一件事，是错误的。反过来，把“可兑换货币结算贸易占比上升”直接当成“匈牙利已脱离经互会”也同样错误：两组交易可以交叠。

### 6.3 一张国际收支表反驳“货物出口顺差就是国家赚到了钱”

1982年IMF调查列出的可兑换货币国际收支数据（单位：**百万SDR**），在1978年与1981年分别呈现出很有教学价值的对照：[A4]

| 可兑换货币国际收支的精选项目 | 1978年 | 1981年 |
|---|---:|---:|
| 商品出口 | 2539 | 4135 |
| 商品进口 | 3164 | 3758 |
| **商品贸易差额** | **−625** | **+377** |
| 净投资收入（含利息等） | −201 | −932 |
| **经常账户余额** | **−993** | **−618** |

**资料与口径**：IMF，*Hungary: An Economic Survey*（1982），表31，原资料为匈牙利国家银行及IMF职员估算；单位百万SDR。为便于教学仅摘录部分项目，**所列项目不能直接逐项加总得到经常账户余额**，因为仍有运输保险、旅游、政府支出、转移及其他项目。

请特别注意1981年：**商品贸易已经出现377百万SDR顺差，经常账户却仍逆差618百万SDR。** 单看货物贸易，很容易写出一句“匈牙利已扭转对外收支困难”；但把利息等投资收入净流出放回来，就会发现货物贸易的改善不足以覆盖其他经常账户负担。

这正是第18讲讨论债务时必须保留的区分：**进口少于出口、经常账户有盈余、外债本金减少、外汇储备增加，是四件不同的事。**

### 6.4 为什么石油、化工原料、机床和电子设备不能混成一个“进口需求”？

1982年IMF调查认为，来自社会主义国家的进口中，燃料占重要部分，而制造品、化工与机器设备则来自不同来源；1970年代初以来世界能源与原材料价格变动，加重了进口支付压力。[A4]

能源进口的约束是持续性的：如果一个国家为工厂和家庭供电供热依赖进口燃料，短期内很难简单停止购买。先进机械的进口则可能与未来产能、工艺更新直接相关，但其经济效益要经过安装、人员培训、零件供应和最终产品出口才能实现。消费品进口又可能直接改善当期生活水平和政治信心。

这些进口具有不同的时间结构：**能源关乎本期产量，机器关乎未来产量，消费品关乎本期福利；外汇贷款则把部分支付推到了未来。** 一国在外部收支紧张时究竟压缩哪一类进口，不只是抽象的“效率最大化”，还涉及社会契约、工人就业、重工业投资、技术赶超与政权对经济风险的判断。

### 6.5 1973年加入GATT说明了什么？

匈牙利并非直到1989年后才与西方制度体系发生正式经贸联系。IMF对匈牙利贸易自由化的回顾记载：匈牙利**1973年加入关税与贸易总协定（GATT）**，1974年与芬兰签署自由贸易区安排，且面向发展中国家采取了部分关税优惠。[H3]

这些举措说明，在一党国家和社会主义所有制仍然存在时，国际贸易规则的接触和有限融入已经发生。但GATT成员资格并没有自动消除本国外贸许可、外汇分配、国内价格控制，也没有让社会主义国营企业立即等同于西方私人公司。因此，把国际制度参与与国内制度完全市场化划上等号，仍是错误的。

## 七、经济学解释：把三个约束严格分开

### 7.1 约束一：真实生产与交付

一国想进口十万台机器，贸易伙伴必须能生产、愿意卖出，机器规格必须匹配，并且铁路、港口、海运、管道或公路必须能交付。如果可用的生产设备或运力有限，双方就需要调整数量、分期交货或另寻供应源。

这与第03讲和第08讲的物资平衡、运输网络问题在数学结构上相通。但**国际性**增加了一层：关键生产能力可能掌握在外国政府或外国企业手中，本国计划机关无法直接调整对方生产任务。

### 7.2 约束二：合同清算余额的使用范围

假设匈牙利在经互会贸易中取得100单位转账卢布顺差。其账本上有一项对外交易的权益，但能否购买100单位相应商品，取决于交易伙伴能否、愿否交货，既有配额是否允许调整，以及相应清算规则是否允许将余额调剂到第三国。

因此，**一国的对外记账财富**与**它能够立即调入国内生产网络的实物**不完全同义。转账卢布改革的关键，是提高前者向后者转化的可靠性。[A3][H5]

### 7.3 约束三：可兑换货币与到期债务

对来自西德、日本或其他国际市场的机器和材料，合同可能需要以可兑换货币支付。即便国家通过国内银行向企业拨出足够福林，仍不能因此创造出另一国会接受的美元、德国马克或瑞士法郎。

一个简化的外汇现金流恒等式是：

\[
R_{t+1}=R_t+X_t+L_t-M_t-DS_t.
\]

其中，\(R_t\)为期初可动用外汇储备，\(X_t\)为本期实际收到的可兑换外汇出口净收入，\(L_t\)为本期新增外部借款，\(M_t\)为本期用可兑换外汇支付的进口，\(DS_t\)为本期到期需支付的债务利息和本金。为了手算，这里暂时省略旅游、运输保险、外汇估值、其他转移和资本项目，因此**它是教学用的简化现金流式，不是完整国际收支表**。

将它变形：若国家必须留出最低期末储备 \(R_{\min}\)，那么本期进口支付额不能超过

\[
M_t\leq R_t+X_t+L_t-DS_t-R_{\min}.
\]

这是**流动性约束**，并不自动等于国家整个经济体的长期偿债能力：后者取决于未来可以获得多少外汇净收入，以及新债务能否续借和偿还。

### 7.4 对外贸易的“货币幻觉”和“物量幻觉”

计划机关可能说：“我们出口了一百套机器，所以有资格换回价值相等的进口货物。”然而若这批机器质量、规格不合适，或买方无法按期供货，实际购买力就低于账面金额。这叫**物量可用性的问题**。

另一个部门可能说：“我们已经有足够福林支付进口机器。”但需要付的是德国马克，国内福林金额不能自动兑换成足额外汇。这是**国际支付约束**。

最后，某一笔货物进口虽然已经得到批准、外币也已支付，却因为运输、验收、交货延误未到企业生产线上。这是**物流和时间约束**。

所以，国际贸易中至少要同时问三个问题：货物是否存在且可得？清算余额能否依法兑现？外币付款能否按时到位？一个问题的肯定回答不代表另外两个问题也解决了。

### 7.5 国家的政策目标不只一种

一国可能为确保石油供应接受不那么有利的机器出口价格，也可能为维护大国间政治关系、战略自主权、长期技术合作作出让步。比较经济制度的分析不应因此取消机会成本，而应把政治和安全收益列入政策目标，明确其衡量困难。

同时，我们不应把所有优惠价格都说成“没有代价的援助”，也不应把所有国家间不等价交换都归结为“剥削”。需要具体测量：价格、运输、技术、政治风险、替代供应渠道、融资成本以及中长期供货稳定性。没有这些比较，就只能提出解释假说，不能宣告净收益。

## 八、三组可以手算的实验：货、钱与时间的约束

> **教学说明**：以下三个实验中的国家简称、商品、资金与价格均为为了推理而构造的数字，**不是1949—1985年匈牙利、波兰或苏联的历史统计或任何真实合同**。它们的目的，是在假设透明的条件下检验机制。

### 8.1 实验一：真正的多边清算可以省掉多少双边交换？

**问题。** 有三个国家：匈牙利H、波兰P、苏联S。每笔交易都值10单位共同记账货币，货物和合同已经双方同意。

| 出口方 | 进口方 | 商品 | 金额 |
|---|---|---|---:|
| H | P | 机床 | 10 |
| P | S | 工业设备 | 10 |
| S | H | 石油 | 10 |

**第一步：分别计算每对国家。** H从P取得10单位贸易顺差，却在与S的贸易中有10单位逆差。P对S顺差10，对H逆差10。S对H顺差10，对P逆差10。如果双边之间要求分别等额结清，这三个国家仍需达成更多双边配货、延迟清算或取得额外的付款安排。

**第二步：计算三国的总收支。** H：出口10，进口10，净额0；P：出口10，进口10，净额0；S：出口10，进口10，净额0。若真正允许多边净额结算，三国的**净金融支付可以为0**，而实物贸易照常完成。

**第三步：说明它何时失败。** 如果S坚持只向H供油、但拒绝用P出口的工业设备来清偿H与P之间的余额，或者H与S的进口合同根本尚未商定，净额结算的“理论优势”就无法完全兑现。银行拥有统一账本，不会强迫各国接受没有合同保证的商品。[T1]

**推论。** 多边结算能减少重复的双边平衡成本；但想实现这一潜在效率收益，必须同时解决**交货保障、信用风险、可支配余额和跨国准入**。这正是转账卢布制度改进希望解决但未能彻底完成的难题。

### 8.2 实验二：国库有钱，也未必能进口西欧机器

**问题。** 一国期初有100百万美元可动用外汇，计划本期收到30百万美元出口货款，能够得到20百万美元新增借款；同时有25百万美元到期债务支出，财政金融当局要求期末至少保留10百万美元储备。

**第一步：能支付多少进口？** 先把全部可用美元算清：\(100+30+20=150\)百万美元。扣掉到期债务和最低储备：\(150-25-10=115\)百万美元。**最大可支付进口额是115百万美元**。

**第二步：如果工厂提出130百万美元进口申请？** 缺口是15百万美元。政府有几个选择：延期一部分设备；提高可兑换货币出口；借更多债；动用最低储备；争取另一种支付方式；或重新决定进口优先顺序。选择并非没有代价：例如再借15百万美元可能解决今年问题，却会增加未来偿付义务。

**第三步：如果经互会账户另有200单位转账卢布顺差，能否直接补上15百万美元？** **不能自动如此推断**。除非存在可执行的兑换、转移或其他交易安排，并且有人愿意兑付所需美元，账户余额不等于外汇现金。假定宣布“1单位转账卢布＝若干美元”，也不意味着美元实际到手。

**第四步：改变一个条件。** 若通过出口扩张本期多收到15百万美元，在其他条件不变时可支付进口上限变成130百万美元；但如果这些出口必须额外占用本期紧缺能源或粮食，社会成本还应另计。**获得外汇并不必然意味着净福利增加。**

### 8.3 实验三：世界油价上涨后，五年移动平均为什么只能缓冲、不能隔绝冲击？

假设世界油价（单位：虚构价格单位/桶）依次为：1971年10、1972年10、1973年10、1974年30、1975年30、1976年30。请不要将这些数字当作实际油价；这里只研究平均规则。

若1976年合同参考**此前五年（1971—1975）的简单平均**，则：

\[
P_{1976}=(10+10+10+30+30)/5=18.
\]

1977年参考1972—1976年，则：

\[
P_{1977}=(10+10+30+30+30)/5=22.
\]

世界即期价仍为30时，合同价格从18升至22，**每年都在吸收较早发生的冲击**；进口国没有在第一年承担全部涨幅，但也没有永久豁免。倘若随后世界油价下降而平均窗口保留了过去的高价，合同价格还可能在某些年份高于新的即期价。

**现实边界：** 经互会的合同价格是谈判与调整规则共同作用的结果，不能保证每一笔机器、食品或燃料进口都严格遵循这个简单算术平均；历史上1975年还有过渡安排，某些原料和产品质量、运输条件也需要单独处理。本实验说明**滞后传导的方向**，而不是重建某一份真实石油合同。[A3][H6]

### 8.4 将三个实验放在一起

- 实验一：**总账可以相抵，具体商品却可能无法取得**。
- 实验二：**国内货币或不可兑换清算余额不等于可支付进口的硬通货**。
- 实验三：**国际定价规则可以改变冲击到达的速度，却不能让资源机会成本消失**。

这也告诉我们，第17讲不是第09讲“银行和预算”的重复。国内银行可以为企业提供福林贷款，但跨国支付必须进一步面对**外国供货方的权利、国际银行资产和货币可接受性的边界**。对外贸易本身不是一个可以任意抽象成“进出口变量”的简单开关。

## 九、与HSM对照：一个能运行的双贸易渠道，究竟说明了什么？

### 9.1 先区分模型里有什么、现实历史里有什么

HSM的物量网络不是简单写一个“贸易净额”。`src/hsm_lab/engine/trade.py`说明它区分**CMEA渠道**与**convertible（可兑换货币）渠道**；进口通过不同价格、信用和储备约束进入模型的国库进口池；出口则必须由真实商品库存和财务支付条件支撑。模型在账本中分别记录不同币种的交易，官方汇率报价主要用作诊断，不是可以把两种账户任意相加的魔法兑换按钮。[S1][S2]

标准贸易过程的主要顺序包括：先处理外债到期利息和应付本金，再计算必要的新借款；依据经互会与可兑换货币渠道分别决定能够支付的进口数量；为出口建立相应的物资需求；通过运输、库存和买方资金约束形成实际交付；最后结算出口收入。**当季出口款不自动成为同一季进口可用资金**，其时序被明确规定，避免把尚未收到的收入提前花掉。[S2]

研究者在代码中还增加了更细化的**经互会多方清算**与**出口应收账款**可选制度层，对应`CmeaClearingPolicy`、`ExportReceivablePolicy`等接口。这个“有可选接口”的事实并不意味着所有历史F2基准情景都启用了该实验层，也不意味着这些接口的合同参数已经从1957—1985年匈牙利官方资料中识别出来。[S2]

### 9.2 将模型执行过程翻译成普通人能够理解的财务程序

设模型某一季度打算从外部购入能源与机器。

1. **提出希望进口的数量。** 需求来自冻结配置或明确定义的外部情景，而不是从KSH统计结果直接倒灌生成。
2. **检查经互会账户。** 标准路径根据声明的经互会信用额度与结算余额，计算这一渠道能支付多少进口。
3. **检查可兑换货币账户。** 先支付到期外债，再判断现有储备与可用借款还能支付多少进口。
4. **取得货物。** 实际批准的进口落在专门的商品存货单元中，仍需依国内网络的供货、运输和生产规则才能用于居民或工厂。
5. **交付出口并记收入。** 交付不能凭空增加；销售收入依既定会计顺序在期末入账。

这一过程具有教学价值，因为它强制读者区分**想进口、付得起、实际进口、实际到达生产者**四个变量。即便货物总量充足，外部支付或国内交付也可能成为瓶颈。模型采用不同账户不是多此一举，而是避免把国家外部约束抽象成一个没有内容的“开放程度”指标。[S2]

### 9.3 F2究竟是16种真实商品，还是16种模型商品？

配置`config/ontology/f2_v1.json`定义了16个粗粒度商品组，包括固体燃料、油气燃料、电力、金属材料、化工和化肥、机械资本、农业原料、基本食品、畜产品及其他消费品服务；`config/scenarios/historical_f2_trade_scenario.json`包含两条贸易渠道的需求、价格、贷款限额与初始账户的**模型配置**。[S3]

这里必须坚持此前讲义已经建立的口径：这些是**模型商品单位及结构假设**，不能直接说成历史上进口多少吨苏联原油、多少马克的西德设备。把不同种商品的模型总量直接加总再叫作“美元贸易额”或“GDP”，也不成立。若要比较历史统计，需要单独建立合格的单位、时间和品种crosswalk。

### 9.4 最重要的负结果：模型的出口路径出了什么问题？

HSM现阶段P06报告写得非常明确。其标准历史复现研究未进行实质参数校准（`calibrated = 0`），贸易情景的进口渠道能够部分传递既定需求，但**出口渠道受到国库（Treasury）可支付国内现金的约束**。在报告的这次运行中，出口年度指数早在**1962年**已归零，1964年以后又受到国库现金配给性的限制。[S1]

将这一结果与本讲第六部分的KSH统计相比较，矛盾十分明显：KSH显示匈牙利1962年出口量指数已经达到130，之后长期上升，而模型在同一时期却已走向零。此时唯一有证据支持的判断是：**至少在报告采用的相应历史复现范围及量纲中，出口实现机制存在严重的历史再现问题。**

这里还需分辨两种“外汇不足”：

- 如果现实中的一国缺乏美元，可能无法立即付款购入西方机器——这是可以在历史史料中调查的外部约束。
- 如果某个合成模型因为它自己构造的**国库本币现金支付路径**，让原本应发生的出口在1962年归零——这首先是模型内部的支付实现和结构参数问题，不能直接写成“历史上的匈牙利因为外汇不足无法出口”。

两种机制并不相同。**出口既可能赚取外汇，也可能由于信用结算、运力或内部支付规则而受限；识别具体哪一环真的构成历史约束，需要独立观测。**[S1][A6]

### 9.5 P06贸易情景为什么不是“给贸易改革打分”？

P06的报告说明：贸易情景的消费指数历史拟合误差并未改善，且关键出口通道在模型内受到资金限制，导致若干出口比较无有效历史对应项。同时，消费指标历史目标自身还有统计口径需要复审的疑点（第12讲已指出KSH收入与消费长期表可能被混用），更不应把表上的一个“误差”当成可靠的政策效果估计。[S1]

还应当注意**同一仓库不同阶段报告的crosswalk口径变化**：早期P06总述曾记载14项比较变量为“2 mapped、1 blocked、11 no counterpart”；随后同一报告中的widened crosswalk又出现“1 normalized_index、13 no counterpart”的整理状态。本讲不替仓库擅自消除两个阶段或摘要之间的差异；使用每个指标前，应核对其**当前表、审查版本、是否真的同口径**。对出口而言，当前最重要的事实仍是**缺少可信的历史可比复现结果**，而不是把“比较项被阻断”理解为历史贸易不存在。

### 9.6 1973年政策分叉能讲什么，不能讲什么？

`docs/phases/P06_1973_SHOCK.md`记录的是**F1八商品模型**在1972Q4共同检查点分叉、下一季开始施加各情景的合成实验。它展示借款平滑、投资约束、价格—工资补偿和预算硬化等策略在冻结规则下的不同反应。这能帮助研究者思考“哪一种支付与物资渠道对结果敏感”，但**不能直接当成1973年匈牙利实际的宏观政策试验结果**。[S4]

具体到当前H6B：M06“外债延长社会契约”仍因外债合约史料准入缺口处于**blocked / NOT_RUN / UNIDENTIFIED**；M10“外部补贴、贷款与贸易条件缓冲”没有可宣称完成的专项研究，亦未得到历史支持。M05改革制度联动也未完成。H6B的11张卡中只有3张实验包complete，没有任何历史`SUPPORTED`。[S5]

因此，模型在本讲应担当一个**清楚标出假设与失败的机制解剖台**，而不是能告诉我们“匈牙利本该进口多少”“转账卢布带来了多少增长”或“苏联援助净值多少”的历史计算器。

### 9.7 如果下一次要改进模型，最值得预先登记哪三组实验？

**实验A：清算账户可用性的对照。** 在相同商品供给、相同信用和相同外汇条件下，比较只有双边结算、允许有限第三国净额抵消以及部分可兑换三种规则。预设结果包括真实交付、未使用余额、对第三国的进口实现和违约风险。确保“形式上转账成功”不会被错当成“新增可用商品”。

**实验B：出口支付门槛的结构诊断。** 固定企业产能与外部需求，仅改变国库对出口先行支付的规则或信用桥接路径，观察出口何时由零恢复、是否出现真实的现金和存货守恒破坏。先确定出口归零是否来自算法或财务顺序，而不是直接调整参数让历史曲线好看。

**实验C：历史指标对照。** 先取得经许可的按币种、伙伴与商品分类的实际贸易序列，再预先登记可比较指标、单位转换、价格基期和期限；不能用“货物量指数”的历史序列去验证“模型价格加总后的货币收入”。保留1960—1978观测窗和1986—1988保留窗的研究纪律，不用保留期数据调参数。

这些都是**研究建议，并非HSM已执行的实验**。第25—27讲会进一步介绍怎样把它们转化为合格的识别与否证设计。

## 十、与苏联、中国及其他东欧国家比较：三种不同的外部经济位置

### 10.1 苏联：主要能源供给者，也有自己的贸易机会成本

在经互会成员中，苏联的经济规模、军事实力和资源禀赋与匈牙利、民主德国或保加利亚并不对称。对石油、天然气、铁矿石或其他原料的供应能力，使苏联在长期贸易谈判中拥有关键地位；东欧成员的工业品和技术装备则可能成为双方协商的交换条件。这种结构既给东欧提供稳定的供应来源，也可能形成较高的产业依赖。[H4][H6]

然而苏联也不是没有约束的“无限资源提供者”。如果世界市场价格上涨、苏联能够将部分原油以可兑换货币出口，其向经互会成员低价供货的机会成本就可能改变。反过来，苏联也需要考虑盟国工业化、政治稳定、军事与战略安全，并可能从专业化交换获得某些产品。只有把**资源收益、合同价格、战略目标与替代贸易选项**放在一起，才能评价它与东欧国家的关系，而不能简单使用单一形容词。[T2]

### 10.2 东德、波兰与匈牙利：工业结构不同，外部约束也不同

民主德国以较发达的工业技术和特定工业生产能力参与经互会分工，既依赖能源与原材料，也要处理西方技术与贸易关系；波兰拥有不同的煤炭和工业基础，并在国际价格与借贷条件变化中选择了自己的工业投资路径；匈牙利则在农业、食品加工、某些工业设备和服务的出口方面形成独特组合。不能把这些国家都当成“苏联周边一个只有消费的市场”。[H4][H7]

但三国有共通的问题：要进口西方技术就须获得可兑换货币，而部分传统经互会工业出口在西方市场变现能力有限。向西方借款可在短期内扩大进口，却把未来出口、利润和外汇支付纳入更紧的期限约束。**资本品进口今天可能提高未来生产率，也可能成为利润与偿债能力迟迟无法兑现的沉没投资。**

比较研究必须注意选择偏差：某一国家在某段时期外债增长较快，不必然意味着其社会主义贸易结构最差；其国际融资渠道、国内投资制度、价格补贴和政治改革也可能完全不同。第21—22讲会系统讨论这些差异。

### 10.3 中国：双边协定、苏联援建与后来的不同开放路径

新中国早期与苏联、东欧等社会主义国家建立了广泛经济联系，包括信贷、设备、专家和贸易；同时与其他国家的经济往来也受到国际政治、封锁、外汇和运输条件限制。但中国长期**不是经互会的欧洲成员国**，不能直接把经互会的转账卢布制度当作中国1950年代的日常清算制度。

一份具体的原始文件可以帮助我们把历史说清楚。1950年4月19日中苏贸易协定的英文译本明确规定：双方依据协议商品清单及具体合同交货；贸易组织要约定**数量、品种、价格、期限和交货地点**；两国通过苏联国家银行和中国人民银行的规定账户清算，原则上以卢布记账，亦允许在另有批准时以黄金、美元、英镑或易货方式结算；双方需定期核对支付等价性。[A9]

这份文件至少证明三件事：其一，国家计划下的社会主义跨国贸易仍然必须有合同和支付机构；其二，1950年中苏双边清算中的“卢布”**不是1964年后经互会多边制度中的转账卢布**；其三，双方明确意识到贸易合同的履行还需要运输与港口条件支持。与第08讲的物流机制可直接联系。

1950年2月14日的对华贷款协定又为中国从苏联进口设备和材料提供了制度基础，国务院条约资料及联合国早期经济调查均可用于核对其性质与数字。[A10][A11]

中国在1978年后逐步形成的对外开放和外汇管理制度，既有与经互会改革讨论相似的问题——怎样使企业出口收益与国际市场需求连接——也有非常不同的产业、人口、沿海区位与世界市场条件。**不能从“匈牙利也改革，后来却出现危机”直接推导“中国改革只是幸运地没有失败”，也不能从中国后来的增长反推匈牙利所有改革设计都不合理。** 第24讲会详细比较两国的实际机制。

### 10.4 “全球南方”也不是匈牙利贸易的注脚

1973年IMF《Finance & Development》讨论东欧国家与西方以及发展中世界的贸易时，列出了1970年东欧向发展中国家出口的规模，并把旅游、能源、粮食和不同市场分开考察。[A12]

经济学上，把可兑换外汇贸易只理解为“东欧与发达资本主义国家贸易”，会遮蔽与中东、非洲、拉丁美洲及亚洲许多国家的经济联系。发展中国家有时可以提供能源或初级产品市场，也可能成为工业设备、医药或农业技术的购买方。各国结算中可以有美元、英镑或特殊清算安排，不能仅由“第三世界”身份推断货币形式。将社会主义国际主义的政治语言转化为严肃经济史，需要观察**具体项目、合同条件、实际货物和双方收益**，而不是先给它贴上援助或剥削的标签。

## 十一、学界争论、反例与未解决的问题

### 11.1 争论一：经互会究竟是失败的一体化，还是部分成功的稳定贸易制度？

一种强调效率的解释认为，经互会始终无法形成真正统一的市场和有效的多边支付机制。名义上的转账卢布在现实中缺乏充分可支配性，双边供货约束、行政价格和工业品质量差异阻碍专业化，导致国家可能继续出口低价值商品来换取稀缺原料。这一解释可以从1976年的同期金融制度研究以及后来针对清算系统的反思得到支持。[A3][H5]

另一种更强调历史条件的解释则提醒我们：东欧确实从长期供货、工业分工、能源和原材料合同中获得了制度性稳定；国家间协作也支持了一批具体项目，并在一些领域减少了市场价格波动风险。若拿一个从来没有历史存在过的“完全可兑换、完全无摩擦的社会主义共同市场”当比较基准，那么经互会当然显得处处不足，但这种比较未必足以判断它相对当时真实替代选项的净收益。[H4][T2]

更有力的研究应当区分两类命题：**经互会是否实现了自身宣布的宏大一体化目标**；**它在特定历史时期是否为成员国创造了净经济收益与安全利益**。前者与后者不能用同一组证据直接替代。

### 11.2 争论二：转账卢布是谁的计划——苏联霸权，还是东欧国家试图解决支付难题？

在较老的冷战叙事中，人们有时把转账卢布描绘为莫斯科企图建立封闭货币霸权的产物。但2026年波波夫（Aleksei A. Popov）与皮沃瓦罗夫（Nikita Yu. Pivovarov）发表的新研究利用俄罗斯档案材料，提出一个更复杂的起源解释：欧洲经互会成员对于解决积累的支付失衡有强烈需求，制度倡议并非简单自苏联单向下达；苏联也有管理国家间债务而不把本国国内卢布普遍强加给盟国的现实考虑。[H8]

这项研究值得认真阅读，原因不是“新文章必然比旧文章正确”，而是它提出了能改变机制解释的**行动者与起源证据**。不过本讲目前核验的是论文摘要、出版身份和结论概要，不能假装已经逐页复核其档案目录、每份会议记录和全部推论。下一阶段若要专题研究转账卢布制度起源，应首先核验文章全文、所引档案和其他国家档案的互证。

### 11.3 争论三：成员国贸易顺差增加，就代表更能摆脱对苏依赖吗？

未必。若一国对苏联出口增长，同时为了维持关键油气进口又必须接受长期的物资配套承诺，贸易额上升不等于替代供应能力扩大。相反，某国与西欧贸易额增加，也不自动提高自主权：其进口技术和外债支付可能使其依赖国际资本市场。

“依赖”至少有四种含义：**单一供应国集中度、无法迅速替代关键投入的技术依赖、结算和融资依赖、政治上受制于某种安全或同盟安排**。这四者相关，却不应合并为一条从0到1的抽象指标。历史材料如果只能说明一项集中度，就不应声称已经证明另一种政治依附关系。

### 11.4 争论四：为什么对外贸易不能成为国内改革的万能补丁？

第14讲说明匈牙利1968年改革希望让企业更敏感地回应价格、利润和市场需求。国外市场可能提供价格参照、竞争压力和先进工艺；但如果国内企业仍然预期被政府救助、投资审批不匹配、外贸收益被不透明地重新分配，外部价格信号也可能无法转化为有效的生产升级。

因此，国际开放与国内改革存在**制度互补性**：出口奖励、企业投资权、风险承担、银行偿付规则和外汇权利必须互相协调。不过，这不等于这些制度需要在某一年全部“一步到位”。当事人所面对的稳定就业、物资短缺、政治联盟和国际安全约束，决定了渐进改革可能有实际必要；渐进改革的成本也需要审查。

### 11.5 哪些历史材料最能真正解决这些争论？

优先建立四类可比较的证据：第一类是各国按商品、伙伴、年度和结算币种拆开的贸易合同与统计；第二类是外贸机构与企业的实际合同履行、质量索赔和逾期交货记录；第三类是政府制定进口与汇率政策的同期会议记录；第四类是可核的替代选项，例如同类油气或设备从第三国采购的实际支付成本和运输能力。

这些资料并不总能公开获得，某些年代统计口径和政治分类也已多次变化。**研究中承认无法裁决的部分，不是退缩，而是让制度史解释保持可被新证据改变的能力。**

## 十二、本讲结论：社会主义国家参加世界经济，需要解决哪三道题？

**第一道题是实物。** 一国的国家计划可以决定本国希望制造多少机器，却无法凭命令创造外国的石油、原料或技术。国际社会主义分工因此需要合同、供货承诺、质量标准与运输网络。经互会长期协议具有稳定供应、支持跨国产业协作的价值，但也引入供应伙伴愿否交货的约束。

**第二道题是清算。** 1964年的转账卢布与IBEC体系，在减少部分双边结算摩擦方面是一项实在的制度创造。但有统一记账货币，不代表所有成员国都愿用稀缺商品无条件兑付任何余额。货币的可用性最终受到货物、生产能力、制度权利与国家间信用约束。

**第三道题是外汇。** 具有可兑换货币付款条件的进口涉及另一套储备、出口赚汇与借款约束。国家不能只靠国内福林拨款解决国际支付，也不能把经互会账面顺差自动当作可以购买西欧设备的资金。反过来，部分社会主义国家间贸易也能够取得硬通货，因此判断贸易性质，必须同时看**贸易对象与结算规则**。

由此我们终于理解，为什么社会主义工业化越成熟，国际经济问题有时越复杂。重工业发展需要原料和能源，产业升级需要先进设备，居民生活改善需要更丰富的消费品；但这些需求既受到国内生产结构限制，又要求外部贸易提供相应实物、货币和时间上的衔接。**世界市场不在国家计划之外；它通过商品价格、供货能力、汇率和债务进入计划经济的内部再生产。**

最后，匈牙利的真实外贸量增长与HSM的出口路径失败构成了一项方法论警告：合成模型里某个约束很强，不能证明历史中这个约束具有相同强度；只有找到真实的出口合同、账目和序列，机制推断才有可能上升为历史解释。

本讲结束于一个尚未解决的问题：**如果进口的能源和设备越来越贵，而政府又不愿迅速削减投资与消费，它能不能借钱维持既有经济生活？** 第18讲将围绕1973、1979年的外部冲击、经互会能源价格的滞后传导以及匈牙利的外债进行解剖。

## 十三、概念速查与研究型思考题

### 13.1 核心概念

| 概念 | 本讲使用的准确含义 |
|---|---|
| 经互会（CMEA／Comecon） | 1949年建立的社会主义国家经济合作组织，促成计划协调和经贸安排，不等于一个拥有所有成员国经济指挥权的超国家政府 |
| 双边贸易协定 | 两国对一定时期的交货、价格和支付等条件作出的政府层面安排；可由年度议定书和企业外贸合同细化 |
| 转账卢布（TR） | 经互会国际清算所用的特定记账单位，不是苏联国内卢布，也不具备自由兑换硬通货的能力 |
| IBEC | 国际经济合作银行，1963年成立、1964年开展转账卢布多边清算 |
| IIB | 国际投资银行，主要面向较长期国际投资及融资协作，不能与IBEC混为一谈 |
| 双边清算 | 对每一对贸易伙伴单独记录贸易收支并尽量相抵的制度 |
| 多边清算 | 允许多个参与方在共同框架中抵消净债权债务；实际价值取决于可兑付性和信用规则 |
| 可兑换货币 | 在相关国际交易中可以较广泛用于结算与兑换的货币；本讲常用美元、德国马克作为历史例子 |
| 硬货／软货 | 特定时期经互会贸易中商品对稀缺实物和可兑换市场的变现能力差异，非对产品的道德评价 |
| 布加勒斯特价格公式 | 国际社会主义贸易价格依据调整后的世界价格和一定时期平均值谈判确定的原则；1975年起采用逐年滚动调整 |
| 贸易条件（terms of trade） | 出口价格相对进口价格的变动；与贸易数量、结算货币和国际收支不是同一指标 |
| 国际收支／经常账户 | 一国与外国的综合经济交易记录；商品贸易顺差与经常账户顺差不能混为一谈 |
| 外汇流动性约束 | 当期可动用外汇、到款、借款与付款之间的时间和数量约束，不等于长期偿付能力 |
| 制度互补性 | 一项政策要奏效，往往依赖合同、价格、信贷、企业激励等其他规则共同配合 |

### 13.2 研究型思考题

1. 如果1964年IBEC已经能够进行多边清算，为什么1976年的同期经济研究和1991年的制度回顾仍然强调经互会的双边主义？请分别从银行账簿、成员国供货义务和紧缺品控制三方面回答。
2. 某国对社会主义伙伴国出口扩大，但其中大部分收入以不可兑换的记账单位取得。这个事实会在何种条件下促进技术升级？何种条件下会妨碍进口西方设备？需要哪些额外数据才可以判断？
3. 匈牙利1981年可兑换货币商品贸易有顺差，而经常账户仍有较大逆差。尝试根据本讲表格解释可能的财务机制，并说明为什么不能只看出口是否增长来评价外债风险。
4. 如果国家对进口油的定价采用五年移动平均，什么情况下该国相对于现货市场得到缓冲，什么情况下反而付出更多？请讨论世界价格上涨与下跌的两种路径，并加入运输和质量差异的限定。
5. 假设要使用HSM比较“转账卢布完全可兑换”和“维持历史有限清算”两种反事实，你会首先审计哪些模型参数和外部真实数据？为什么不能仅让两组模拟的账目守恒通过就宣布历史结论？

## 附录C｜课后延伸阅读顺序与第18讲衔接

**优先精读三项：**第一，Mark Allen（1976）第IV—V节，主要学习怎样区分货币名义、可支配商品和支付权限；第二，IMF（1982）匈牙利调查的外贸与附表31、33、41，训练同时读货物贸易和国际收支；第三，Germuska（2014）的匈牙利档案研究，尤其关注对经互会一体化预期与西方开放的并行关系。只有在这三项读通后，再研读Popov与Pivovarov（2026）关于转账卢布产生动因的史学修正，并尝试索引原始档案。

**第18讲的延伸问题**：在1973年后的一次油价上涨中，苏联经互会油价、匈牙利可兑换货币进口价格、国内能源行政价格、企业利润、居民消费和国家外债之间，需要经过多少步才能形成因果链？如果只看到1981年“商品出口大于进口”，能否推断债务危机已经解除？为何不能？

**本讲最后的研究纪律**：不要用价值判断代替合同核对；不要用出口统计代替支付能力；不要用模型假设代替真实历史；不要因为制度没有完成它的宏大目标，就否认它曾经产生具体的经济作用。
