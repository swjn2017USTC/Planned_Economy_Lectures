第04讲｜计划机关怎样知道什么东西值得生产？价格、影子价格与经济计算

《计划经济的运行、改革与历史命运》· 第一编：从革命理想到国家经济计划
版本：v1.0 · 2026年10月25日
历史重点：1920—1945年的社会主义经济计算论争；1938—1970年代苏联数学经济学的发展；1950—1980年代匈牙利行政价格制度与1968年新经济机制。
理论主线：稀缺与机会成本 → 货币和行政价格 → 理论上的经济计算 → 分散信息与激励 → 线性规划与影子价格 → 改革条件。

研究边界：米塞斯、哈耶克、兰格、勒纳和康托罗维奇讨论的是有联系却并不相同的问题；任何一位学者的模型都不等于苏联或匈牙利的实际制度。下文钢材分配案例为明确标注的教学虚构数据；HSM内设定的管理价格不是可直接对应历史匈牙利福林的市场价格。

本讲最重要的20%

第一，计划经济不仅需要算出“能生产多少”，还需要判断“值得生产什么、值得牺牲什么”。 第03讲的物资平衡表能够告诉我们：煤、电、钢材、机器与消费品之间是否存在实物比例矛盾。但即使每张物资平衡表都能闭合，国家仍必须在住宅、机床、医院、铁路、出口和军工之间作选择。钢材不是抽象地“不够”，而是同时有若干种互相排斥的用途。经济计算问题首先是识别这些用途的相对价值和机会成本。

第二，所谓“社会主义经济计算论争”不是数学家与反数学家的争吵。 1920年米塞斯提出：如果生产资料不能形成有意义的市场交换价格，怎样进行跨越异质生产资料与不同生产方案的货币核算？1930年代兰格和勒纳回答：即使生产资料的所有权归社会，企业仍可依据核算价格行动，价格可通过供求差额反复调整。1945年哈耶克进一步追问：不断变化、分散于生产者和消费者之间的知识，怎样被发现、表达并纳入行动？这些论证并非同一命题的相互否定。[T1][T2][T3][T4][T5]

第三，康托罗维奇使一种常被忽视的可能性成为严肃的科学事实：计划机关可以从明确的生产技术、资源约束和目标函数推导出“影子价格”。 一吨钢的社会机会成本，不一定等于生产它耗费的会计成本，更不一定等于政府规定的销售价格。优化问题中的影子价格回答的是：在其他条件保持不变的情况下，多获得一吨钢，能够使已定义的目标改善多少。关键限制也在这里：谁确定目标？技术系数可信吗？生产组织是否按解执行？价格能否反映新的技术和需求？[T6][T7][H1]

第四，匈牙利1968年改革不是“不要价格→有了价格”的开关。 改革前匈牙利已有工资、商品价格、企业会计和货币核算；问题在于价格往往由行政机关确定，与相对稀缺程度、世界市场价格和企业经营自主权之间存在断裂。1968年开始实行固定价、限幅浮动价和较自由的价格并存的三层结构，但后者也保留行政约束。价格制度改革必然牵连财政补贴、投资审批、企业盈亏、国际贸易与居民保障。[H2][H3][H4]

第五，价格提供的信息与价格实现的分配不是同一回事。 市场涨价可能准确传达某种投入更紧缺，却也可能使低收入居民先被排除；行政低价能够保障部分基本生活，也可能在未建立其他配给和供给机制时制造队列、寻租或预算压力。资源配置效率、社会公正、政治责任和长期发展，应分开评价再综合判断。由此，本讲的答案不可能是简单的“计算机战胜市场”或者“市场永远胜过计划”。

一、历史现场：有钢材，但究竟该给机床厂还是给住宅建设？

1.1 第03讲留下的最后一道问题

想象1960年代一个东欧社会主义国家的经济计划工作会议。国家计划机关已经汇集了今年的煤炭、钢材、电力和机器产量。各工业部送来了物资申请，运输机关说明铁路可承担的吨公里，财政机关列出了货币计划；一张张表终于差不多平了。

现在出现一个问题：还剩下能够重新安排的八吨特定规格钢材。 一家农业机械厂需要钢材制造耕作设备，另一家生产耐用消费品的工厂也在等待钢材。农业机械可以提高农业生产条件；家用设备可以改善居民生活。哪家工厂该优先？计划员并不缺少关于“每种产品需要多少钢材”的信息，真正缺少的是对多种用途作比较的准则。

这种会议并非来自某份具体的匈牙利会议记录，而是教学重构。下文所有产品价值与钢材用量都为方便计算设置的假设，不能引用来说明当年匈牙利机床厂实际使用了多少吨钢材。它的现实性仅在于：传统计划经济确实必须在部门之间配置有限生产资料，行政价格和物资配额不必然表达相同的稀缺信号。[H2][T8]

第03讲我们已经学过：钢材需求不是能够随便写在计划里的愿望数字。机器制造、建设和设备修理均有投入系数，增加一处计划产出会增加别处投入需求。但有多个物理上都可行的分配方案时，投入产出表本身不会告诉你选哪一个。

1.2 四张不同的“价格单”

计划员手里可能同时握有四种不同的数字：

  1. 会计成本：钢材按当年的原料、能源、工资、折旧和规定的分摊办法计算，生产一吨花费多少货币。
  2. 行政出厂价或批发价：国家授权的价格机关准许钢铁厂以什么价格出售给工业用户。
  3. 计划内部核算价：评估不同用途、比较投资或组织企业结算时，计划系统决定使用什么核算尺度。
  4. 资源稀缺的边际价值：在给定所有备选生产方案和社会目标的情况下，额外增加一吨钢能够改善多少目标。后者就是本讲要推导的影子价格的一种含义。

这四个数字可能碰巧相等，也可能相去很远。尤其不能默认一个国家对钢材的行政售价，就恰好等于一吨钢在其他行业的机会成本。

1.3 为什么计划经济不能只谈“满足需要”？

“满足人民需要”是目标，但只有说出更具体的条件才能变成可操作的计划。比如：

  • 一个城市更需要一千套住房，还是一批可以降低粮食运输损耗的货车？
  • 某地生产的机床技术先进，但成本极高，进口设备是否更合算？
  • 提高农用机械产量会改善未来粮食供给，但立即减少轻工业钢材供应，是否值得？
  • 进口石油便宜，却需要可兑换外汇；苏联原油名义价格更低，却有贸易协定和数量限制，应当如何估价？
  • 一辆用于救护的车和一辆用于高消费的车可能耗用相似资源，但其社会价值显然不能仅由购买者支付意愿决定。

同一种钢材同时进入生产、财政、对外贸易、劳动和分配问题。经济计算并不只有“技术上最省料”，还包括不同用途之间的价值比较。 价值比较既有客观约束，也有社会选择。

二、制度机器：传统计划经济中的价格究竟做什么？

2.1 “没有市场”并不意味着没有货币与价格

应当从一开始纠正一种误解。20世纪苏联和东欧传统计划经济中广泛存在货币、企业结算、工资、商品售价、零售商店、财政收入与银行账户。即使一个大型国营工业企业的主要生产任务由上级规定，仍可能按照行政出厂价计算销售额，以核算成本、利润、税费或补贴。居民也会拿工资在商店购买日常消费品。[H2][T9]

所以真正的制度区别不是“有价格”和“没有价格”，而是价格由谁形成、在什么边界内变化、价格改变后哪些行动者能够重新选择投入、产量、技术或投资，以及亏损结果由谁承担。

比如政府可以宣布某种煤炭价格每吨100单位货币，但对于受到硬性投入分配和固定产量任务约束的企业来说，100究竟产生什么效果？它可以决定账面采购成本，却未必赋予经理以节约煤炭后改购其他能源的权限，也未必容许煤矿根据需求增产、调整售价或扩大开采项目。相反，如果成本上升而国有企业总能获得价格补贴，那么价格上涨也未必足以约束投入需求。

价格的记账功能、资源配置功能、激励功能与收入分配功能，因而必须拆开。

2.2 行政价格、配给和补贴是一个共同体制，而不是三项独立政策

在典型的行政定价经济中，政府会同时运用：企业间批发价格、零售价格、营业税或周转税、补贴、物资分配指标、企业投资审批、工资制度、外贸结算和国家银行信用。若只抽出“价格被政府规定”，容易低估实际制度的复杂性。

假设供不应求的住房建设材料被低价分配给国营建设公司，但公司不能任意追加材料；政府实际上用实物配额代替价格承担筛选需求的任务。倘若价格较低、实际配额却不透明，企业又会通过上级关系、申报或调整工程计划争取更多材料。消费者面对低价耐用品却买不到时，则可能以排队、预订、非正式关系或二级市场价格承担隐性成本。下一步再出现财政补贴和企业亏损，便不是偶然的混乱，而可能与同一套组织结构相互联系。[T9][T10]

但不能倒过来说任何低价必然导致短缺。低价可以通过增加供给、公共预算、明确数量配给、采购制度和有针对性的补贴维持。某种基础公共服务免费或低价，也是有意识的分配选择。真正需要判断的是：数量配给是否有效、预算约束是否真实、供应能力和需求是否匹配、替代与纠错渠道是否存在。

还须分清影子价格不是“秘密市场价格”或“国家应该立即执行的官价”。其意义属于某个具体优化模型及其约束条件。同一个钢厂在两个不同社会目标下，可能得到不同的影子价值；同一个目标在钢材充足与钢材极端短缺时，也会给钢材不同的影子价值。

三、经济计算论争发生了什么：1920—1945年的五种问题意识

3.1 米塞斯（1920）：市场不存在时，生产资料的相对成本怎样计算？

奥地利经济学家路德维希·冯·米塞斯（Ludwig von Mises）1920年发表《社会主义共同体中的经济计算》（Die Wirtschaftsrechnung im sozialistischen Gemeinwesen），把讨论焦点放在生产资料经济计算，而不只是最终消费品分配。他承认可以在技术上比较投入实物、也可以知道某种工艺能够生产多少单位成品；但是当社会必须比较异质性很强的土地、机器、钢材、铁路运输和劳动时，仅用物量无法得到一个贯通不同用途的经济价值尺度。[T1]

一个铁路线方案耗费多少吨钢，与另一个方案耗费多少吨木材和多少小时劳动，二者不能直接加总。即使都能建成，如何判断哪个方案“比较节约社会资源”？米塞斯认为，若生产资料不存在真实交换，缺乏由其买卖形成的货币价格，就无法以正常经济意义进行可靠的成本收益比较。其核心命题针对的是生产资料和资本品的价格形成与经济核算，并非社会主义社会一夜之间不能生产面包或修建铁路。

米塞斯的论证具有很强的制度前提：有意义的生产资料市场、私人产权及资本经营者的盈亏核算之间存在内在联系。他的支持者认为，缺少这些条件，所谓会计价格只能是行政任意赋值，而不是独立的稀缺评价；其批评者则追问：若真实技术约束与需求可以获得，为什么必须依靠私人产权才能求得合理核算价格？不同立场正是从这个分叉点开始争论。[T1][T11]

我们应当保留其真正的发问，而不提前接受全部结论。 第03讲说明“物量表闭合”不等于“资源最有效配置”，米塞斯准确抓住这个差别；但这不能仅凭逻辑推导就证明所有社会所有制形式均不可能找到经济比较规则。后者需要进一步考察替代价格机制、组织行为与真实经验。

3.2 兰格（1936—1937）：社会所有制也可以有价格与竞争性规则

波兰经济学家奥斯卡·兰格（Oskar Lange）在《论社会主义的经济理论》（On the Economic Theory of Socialism，1936和1937分两部分发表）中，提出一种后来被称作“市场社会主义”的解决办法。[T3]

其中心思想并不是“中央委员会已经知道一切”，更不是“靠一台未来超级计算机取代市场”。兰格设想国家掌握主要生产资料所有权，中央计划委员会公布生产资料的核算价格，企业则在特定规则下选择投入组合、尽量降低成本；当某种商品需求大于供给时，提高其核算价格，供给超过需求时降低价格。这样通过试错式价格调整，在理论上可以逼近竞争均衡所要求的条件。[T3][T4]

这是一种很有意思的制度组合：产权仍属社会，生产经营的微观决策在一定范围内分散；中央不命令每家企业每一步工艺，而发布可变化的核算信号。 价格作为信息中介可以保留，私人资本对企业资产的最终所有权则并非逻辑上必须同时保留。

它的理论力量在于：指出资源价格并不只有一条可能的制度生成道路；其困难则在于：怎样真实记录盈余和短缺？如何保证企业服从成本最小化原则？若企业有政治任务而不能倒闭，怎样约束其投资需求？中央多久改价一次、调整幅度如何决定？价格发布以后，企业是否拥有替代投入和改变产品的实际权力？

这些问题在兰格的静态模型中被规则化，在真实经济中却需要建设机构、调整行为并承受改革风险。

3.3 勒纳（1936—1938）：比较的关键不是“按历史成本加成”，而是边际成本

阿巴·勒纳（Abba P. Lerner）1936年发表《社会主义经济学札记》（A Note on Socialist Economics），其后继续讨论社会主义经济中的静态与动态效率。[T4][T5]

理解这一支思想不必先学复杂微积分。假设一家厂每生产一台机器的平均成本是10元，但多生产最后一台只增加6元的劳动和材料消耗。在产能许可、没有其他外部性且目标是该类商品的有效配置时，决定应否继续生产的关键是多生产一单位的边际收益与边际成本，而不是已经支出的平均费用。反过来，如果增加一台机器会抢占其他工厂严重短缺的钢材，那么其真正的边际社会成本可能高于企业账面成本。

由此出现社会主义价格改革的另一个方向：让企业面对反映边际成本或稀缺程度的价格，而不是简单沿用行政成本加成。需要强调：这一套最优定价条件具有完备竞争、信息、约束和社会目标等前提；实际经济中存在固定成本、规模报酬、垄断、公共品和不完备市场，不能因此主张任何商品都直接以短期边际成本定价。[T4][T11]

3.4 哈耶克（1945）：信息不是摆在桌上的完整统计表

哈耶克（Friedrich A. Hayek）1945年在《美国经济评论》发表《知识在社会中的利用》（The Use of Knowledge in Society）。他承认：如果全部技术、资源和偏好都已经掌握，最优配置成为一个形式逻辑与数学计算问题；但他强调这恰恰不是现实社会面对的问题。经济活动所需要的知识分散于众多人那里，往往局部、暂时、未成文且不断变化。[T2]

厂长知道某批材料的真实损耗，维修工知道哪台设备已经快坏，零售店员知道当地某种鞋子忽然受到欢迎，运输人员知道某条铁路将检修。这些事实未必能够完整而及时地写成全国报表，甚至很多人事先也不知道自己的知识将在何时变得重要。市场价格变化可以在不传递全部原因的情况下，促使生产者和消费者调整行动。

这不等于市场价格完整表达每个事实，更不意味着价格机制在垄断、污染、战争或贫困分配问题上总是理想的。哈耶克的关键挑战是制度怎样不断发现并动员分散知识，而非单纯“计算量太大”。即使一台计算机算得很快，也要先问：它收到的数据是怎样生成的？有没有企业愿意准确报告？数据生成时，参与者是否已经根据规则改变了自己的行为？[T2][T12]

3.5 两边的争论并不能缩写成“市场有效、计划无效”

我们可以把不同作者真正研究的困难排列出来：

作者与节点 主问题 认为特别关键的制度条件 其论述没有自动解决什么
米塞斯，1920 无生产资料市场价格如何核算经济成本 生产资料交易、货币计算、企业家选择 市场价格是否衡量所有社会需要、外部性和不平等
兰格，1936—37 社会所有制能否建立可调整核算价格 中央价格调整、企业按规则行动、分散选择 真实企业的激励、投资决策、不断变化的知识

康托罗维奇在时间上早于哈耶克1945年文章，表格将其置于最后，是为了从理论争论自然过渡到本讲的手算优化，不意味着这一研究是对1945年论文的事后回应。

再强调一次：兰格证明的是一类理论上可设想的制度安排，米塞斯与哈耶克提出的则是必须检验的制度条件及知识问题；任何一方的模型都不能免除经验研究。 当后人评价论争时，也不应把东欧现实体制直接等同于兰格的理想市场社会主义，或者把所有市场经济直接等同于教科书的完全竞争市场。[T11][T12]

四、苏联历史的另一条道路：康托罗维奇与从工厂内部产生的影子价格

4.1 1938年的胶合板厂难题：为什么一家企业会求助于数学家？

1938年前后，列宁格勒胶合板行业的研究人员向列宁格勒大学年轻的数学家列昂尼德·康托罗维奇（Leonid V. Kantorovich）提出生产排程问题。不同机器加工不同品种木材的效率不一样，工厂又需要一定比例的多种成品；凭经验安排机器运转，可能形成非常复杂的资源浪费。康托罗维奇把问题转化为变量、生产能力及产品比例约束，并发展一套寻找最优方案的办法。1939年，他以俄文发表《生产组织与计划的数学方法》；1960年英文译文收入 Management Science。[H1][H5][T6]

史料里关于“几台机器”的叙述有一个有趣细节：通常概括为八台机器、五类产品；后来的数学史研究指出其中两台机器性质相同，建模时可以合并成七种异质设备类别。因此，如果不同文献说“七类机器”或“八台机器”，首先检查它们是否在说设备台数与不同设备类型，不必急于判定某份材料造假。[H5][H6]

故事的重要性不在于他找出某个神奇的精确产量，而在于改变了提问方式：

不是先规定每台机器应生产什么，再分别核算有没有完成，而是先明确生产目标和各种技术约束，然后联合寻找一种最好的机器分配。

对国家计划机关而言，这种数学思想有潜在的重大意义：如果许多部门之间的投入与产出可以用一组一致的约束表示，那么即使不改变生产资料所有权，也可能改进配置算法。1950年代以后苏联数学经济学、投入产出研究、电子计算和运筹学的发展，正是在这样的背景下获得日益广泛的关注。[H5][H7]

4.2 从“最佳生产方案”到“客观规定的评价”

康托罗维奇式优化中的核心发现之一，是资源在某个目标与约束体系内会产生自己的边际评价。如果有一种材料刚好是产量瓶颈，那么再增加一单位材料可以提高目标；如果该材料已经堆积、不再限制生产，它在这个特定问题中的额外边际价值就可能是零。

可以把这种核算评价理解为一份关于稀缺的诊断报告：

  • 它指出哪些资源真正卡住了目标；
  • 它允许比较“增加钢材”和“增加机器工时”哪一种更有效；
  • 它可以帮助发现某些行政定额与价格不符合资源的实际边际价值；
  • 如果企业在清楚的规则下使用核算价格，还可能支持一定程度的分散决策。

1975年瑞典皇家科学院在向康托罗维奇与美国经济学家库普曼斯（Tjalling C. Koopmans）共同颁授经济学奖的说明中，就特别强调了他们对最优资源配置的贡献，并指出合理核算价格及统一的资本计息尺度同分散化计划决策之间的联系。[T7]

这里有一个重要的历史反讽。米塞斯、哈耶克批评计划机关难以形成合理经济评价，而苏联体制内部确实出现了能够计算条件性稀缺评价的数学传统。它们并非同一问题的完美答案：数学解证明有可计算的配置价值，并没有证明社会主义国家已经获得全部真实数据、社会价值尺度和有效执行机制；市场价格有信息优势，也并不自动证明市场能够实现公共目的和公平结果。

4.3 技术的命运为何取决于制度？

康托罗维奇没有因为提出数学方法就立即让全苏联经济改用最优化程序。他的研究需要同经济学既有学术语言、不同部委的管理权限、统计体系和政治环境反复协商。Boldyrev与Düppe（2020）根据档案和口述材料指出，理解康托罗维奇不能只写成“天才数学家战胜教条官僚”的故事。他既与官方经济学机构发生冲突，也依靠科学院网络、改革讨论和制度内部结盟使数学经济学取得合法性。[H5]

这就把我们带回第02讲所讨论的中介问题。数学方法即使正确，也要被行政系统采纳；行政系统采纳以后，还要变成企业的日常工作规则；企业是否根据它行动，又取决于报告激励、预算约束、经营自主权和考核方式。

一张最优解表不会自动变成真实的最优经济。 这也是技术史和制度史必须合在一起研究的理由。

五、一次能手算的经济实验：八吨钢材怎样分给两家工厂？

这一节不要求微积分、不要求理解一般的线性规划算法。我们要回答一个严格而小的问题：当已知两种商品的生产技术、产能和社会评价时，能否证明某种资源分配最优？

5.1 给定条件：社会目标不是凭空出现的自然常数

假设某计划机关准备在下一季度为两类产品分配八吨标准化钢材。

  • 工厂A生产农业机械，每组产品用 2吨钢；每组对本次计划目标的贡献记作 8个社会评价单位；最多生产4组。
  • 工厂B生产家用设备，每组产品用 1吨钢；每组对本次计划目标的贡献记作 5个社会评价单位；最多生产6组。
  • 两厂都能使用规定的钢材，不存在其他投入、运输或质量瓶颈；产品可以在这个数学练习中连续分割，且每组收益线性相加。
  • 计划目标被预先定义为“总社会评价单位最大”。
项目 A：农业机械 B：家用设备
每组钢材用量 2吨 1吨
每组目标贡献 8单位 5单位
生产上限 4组 6组
每吨钢对应的目标贡献 4单位 5单位

注意：表中8与5是教学给定的社会评价权重，不是可观测的“客观价值”、真实市场售价或者国家政府必然赞同的价值排序。现实中究竟应该给农业机械还是家用设备更高权重，需要涉及农业发展、居民需求、贫困状况、未来回报以及政治社会选择。本节先固定目标，专门研究在这个目标下如何配置资源。

5.2 先用直觉求解，再写下约束

如果每吨钢投入B能够获得5单位目标贡献，投入A只能获得4单位，在B还没有达到生产上限时，先生产B似乎更合算。于是先为B安排6吨钢，生产6组产品；剩下2吨给A，生产1组。总目标贡献：

  • B：6组 × 5 = 30；
  • A：1组 × 8 = 8；
  • 合计38。

这种直觉至少比按照两厂申报的钢材需求等比例切分更有经济意义。但是我们还不能直接把“看起来不错”叫作“最优”，因为可能还有某种组合更好。

设A产品组数为 a，B产品组数为 b。本题的三个主要关系写成：

\[ \text{最大化 }W=8a+5b,\qquad 2a+b\leq 8,\qquad 0\leq a\leq4,\quad 0\leq b\leq6. \]

含义分别是：我们希望社会目标 W 尽可能高；两厂用钢合计不超过8吨；各厂不能超过自身产能，产量也不能为负。这就是一个最小规模的线性规划问题。

5.3 不枚举所有组合，也能证明38是最大值

下面的推导是本讲最重要的一段数学。对于任何满足上述约束的生产方案：

\[ W=8a+5b=4(2a+b)+b\ \leq\ 4\times8+6=38. \]

为什么这一步成立？因为2a+b就是实际耗用的钢材，最多8吨；b就是家用设备产量，最多6组。于是任何可行方案的总目标都不可能大于38。而我们刚刚找到了a=1、b=6这一方案，恰好达到38。因此它不是“比较好”，而是在这些已声明条件下严格最优。

你甚至不用知道“拉格朗日乘子”是什么意思，就已经完成了一次最优性证明。这段证明的结构是：先给所有可行方案设立共同的上界，再找一个实际方案达到上界。

需要提醒一个现实限制：本例允许“1.5组机器”这样的连续产量。在一些行业，生产线与大型机器必须整组、整台安排，就需要整数约束；资源价值可能出现跳跃，后文介绍的影子价格便不再像本例这样平滑。

5.4 现在再给一吨钢：为什么它的影子价格恰好是4？

设钢材从8吨增至9吨，其他条件不变。B已经达到6组产能，再多的钢只能给A，A便可以多生产0.5组。因此：

  • 原目标：38；
  • 新目标：8×1.5 + 5×6 = 42；
  • 多一吨钢使目标增加4单位。

在这个生产状态附近，一吨钢的影子价格（shadow price）或约束的边际价值就是4个社会评价单位/吨。它不是现实货币价格，不是历史出厂价，也不是随意指定的哲学价值，而是从这个具体最优化问题里算出来的。

更严格地说：从8吨增加到9吨、10吨等，只要B产量仍为6、A尚未达到4组上限，增加一吨钢就可以增加0.5组A、改善4个目标单位。到钢材达到14吨时，两厂都达到产能上限；再增加钢材而不增加其他产能，目标便无法改善，钢材在这一固定问题中的额外影子价值就变成0。

所以：影子价格是状态依赖的，不是钢材永恒的“价值标签”。 一吨钢在某个时点很宝贵，在另一个时点可能不构成瓶颈。

5.5 价格究竟怎样帮助两个工厂自行选择？

刚才我们是由中央计算得到最优解。现在假设计划机关公布一种“用钢内部核算价”：每吨钢按4个目标单位计价。

  • A每组目标贡献8，耗钢2吨，按钢材影子价核算刚好耗费2×4=8，对多生产A恰好无差别；
  • B每组目标贡献5，耗钢1吨，净差额为5−4=1，倾向于先扩产至6组；
  • B用钢6吨后，尚有2吨钢可给A，使A生产1组。

这只是一个高度简化的分散协调例子。对A而言“恰好无差别”，并不保证它会自动选择生产1组；中央仍须规定配额、设置结算机制或调整细小价格，以使资源市场清算。现实企业也不直接拿“社会评价单位”付钢款，实际还要有货币收入、生产成本、经营自主权以及制度性约束。

恰恰在这里我们可以理解兰格的用意：社会所有制与核算价格在形式逻辑上可以并存；但价格公式并不自行制造企业的执行意愿和市场结算组织。

5.6 这已经算解决计划经济问题了吗？远远没有

本题之所以容易，是因为我们一开始就慷慨地假定：

  1. 社会目标可以用一个统一且已知的W表示；
  2. 两种产品的“价值权重”已经得到社会认可；
  3. 技术系数、质量和产能完全清楚；
  4. 没有运输、金融、外贸、信息或工人激励的次级瓶颈；
  5. 产品连续可分，利润和效果线性相加；
  6. 计划实行以后，不会出现企业虚报投入、居民改变需求或新技术进入。

可是第02讲的企业报告问题、第03讲的跨行业投入约束，以及第06—09讲即将讨论的经营激励、短缺与财政，恰恰都在挑战这些假定。

一个非常重要的区分由此出现：求得一个正确的数学最优值，需要给定“问题”；判断真实世界中“问题”应当怎样定义，是更深的经济和政治任务。

六、为什么影子价格不能直接代替市场价格、成本价格或社会评议？

6.1 四种数字的单位和含义就不一样

先把本讲最容易混淆的概念摆在一起。假设某国行政规定钢材价格100福林/吨、会计成本90福林/吨、国外到岸成本相当于150福林/吨；而刚才教学模型给钢材算出4个社会评价单位/吨。最后的4并不与100、90、150直接处在同一货币尺度中。

只有在进一步给社会目标设定货币化评价、把外汇和运输成本纳入同一约束、明确各方案对福利的贡献后，才有讨论这些数字能否比较的基础。否则“4与100不一样”不能说明行政价格高估或低估了稀缺。

更进一步，即使所有价格都以同一货币为单位，会计成本记录已经消耗的某些可计量费用，市场成交价取决于买卖双方可交易的权利与支付能力，影子价格取决于某个优化目标和约束，政府补贴后的消费价格还承担再分配目的。它们不必重合，也不应强求全部重合。

6.2 “价格准确显示稀缺”不意味着“市场结果就是正义”

假设某日面包生产遭灾，市场价格从每个2元涨到10元。在某些条件下，涨价会减少部分购买量、刺激扩大生产、引导运输和替代供给，因而传递真实的短缺信息。但与此同时，如果收入分配极不平等，低收入者先退出购买，不能据此说他们“需要面包的程度更低”。

市场中的有效需求往往体现的是愿望和支付能力的结合，不是超越社会关系的纯粹需要排序。价格可以是协调工具，却不是社会目标本身。若国家要求每位居民获得最低生活面包，可以通过补贴、现金转移、公共供应、配给和价格管理改变最终分配。每一种方法都有成本和可能的副作用，但决策需要先承认价值目标与配置技术是两个层面。

这与第01讲的政治经济学出发点相呼应：对社会主义社会性质的判断，不能只看是否允许价格波动，还要看生产资料控制、剩余配置、劳动关系、公共服务和居民的实际参与。

6.3 同样，行政价格不必一概按“错误价格”看待

电力、铁路、住房、疫苗和教育的价格可能涉及网络外部性、自然垄断、公共投入与社会保障。公共企业可以有意识地在某些服务中采用低于短期商业成本的价格，并通过财政预算弥补差额。这样做不必然低效率；在公共卫生或基础教育领域，还可能产生难以由个体付费体现的长期社会收益。

但这种选择要有可核算的代价：财政资金从哪里来？补贴流向谁？排队与准入如何决定？低价是否导致产能维护不足？政府是否能看见真实需求？如果以“社会主义就是低价格”为理由拒绝这些问题，就等于用价值承诺取代经济判断。

6.4 价格不仅分配商品，也会改变国家和企业的相互关系

若行政低价使企业长期亏损，亏损究竟由企业自己承担，还是由财政、银行、其他企业和消费者共同承担？一旦补贴被视为理所当然的事前保证，经理在选择工艺、产量与投资时可能产生与硬预算企业完全不同的行为。科尔奈后来讨论的软预算约束，就意味着“某项财政损失将由外部救助吸收”的预期怎样改变企业的经济选择；它不等于每一家亏损企业实际得到补贴，更不等于一个年度的政府财政赤字。[T9][T10]

这里为第09讲埋下重要伏笔：价格信号、投资权、贷款规则和预算硬度，是一组需要协同设计的制度，而不只是单独改变一个数字。

七、匈牙利的真实制度实验：1968年新经济机制怎样改变价格？

7.1 改革以前：价格有账面功能，却不能充分反映稀缺

传统匈牙利计划体系中的价格，长期由行政机关决定，生产者价格与消费者价格之间又有周转税、补贴和其他财政安排。匈牙利国家机关希望通过它们完成核算、收入分配、工业积累和居民消费保障等不同目标。在这种情况下，一项商品的规定出厂价与其实际的边际供给成本、国际进口机会成本以及企业对该商品的迫切需求，可能明显不一致。[H2][H3]

IMF后来对匈牙利新经济机制的研究特别指出：1968年前的价格主要承担核算作用，资源相对稀缺性不能充分反映到价格中；国际市场价格对国内经济的影响，也常被特殊基金或财政转移隔开。这不是说匈牙利物价在所有时间和空间都完全不变，也不是说国家机关不了解某些物资短缺，而是说既有价格体系本身不足以成为各企业普遍自主调整投入和产出的协调机制。[H2]

这种制度在某些任务上具有实际优势。例如大规模优先建设重工业时，中央可以通过对钢、电、运输和机器的优先供给安排支持战略项目；政府还可以通过稳定消费价格减少居民面对的短期价格波动。但其代价是，相对稀缺程度的变化必须通过其他更沉重的行政渠道被发现和处理：统计报告、计划指标修订、部门之间协调、紧急物资调拨、地方企业的非正式采购和财政补贴。

这与我们在第02讲接触的科尔奈早期研究形成连续问题：当企业主要关注上级计划任务与管理机关关系时，价格即使出现在账本上，也未必是企业真正行动的决定性信号。[T9][T10]

7.2 为什么匈牙利领导层逐渐认为需要改革整套协调机制？

1950年代中后期起，匈牙利经济学界对过度集中、行政控制、企业绩效和价格失真进行了持续讨论。1956年政治危机后，政治稳定与改善生活水平更成为长期政策目标。1960年代，国家计划和部门管理的局限与对提高增长质量、扩大消费品供给的要求不断显现。[H4][H8]

1965年，匈牙利社会主义工人党领导层组织专家委员会起草更全面的经济改革方案；1966年5月7日中央委员会的相关决议确立了新经济机制的基本蓝图，1968年1月1日正式实施。IMF对改革纲领的回顾显示，其目标不是放弃社会主义所有制和党的政治领导，也不是取消国家经济计划，而是在政治制度和公有经济的既定边界内，以间接经济杠杆和较分散的企业决策改进计划的实现方式。[H4]

因而，1968年的历史行动者未必是在“选择资本主义”。更准确的说法是：他们试图解决一组具体而棘手的问题——如何使企业对市场需求作出反应，如何提高盈利与成本约束的重要性，如何缓和计划机关掌握全部微观信息的负担，又如何保存社会所有制、就业与居民生活稳定等目标。

7.3 固定价、限幅价与“自由价”：为什么三种价格并存？

匈牙利新经济机制采取一个有代表性的三类价格结构：

类型 形成方式 其主要意图 仍然存在的制度限制
固定价格（fixed prices） 政府直接规定 控制基础投入或重要民生商品的价格变化 价格未必随边际稀缺程度立即调整
限幅或弹性价格（flexible prices） 在批准的上下界或最高限价内波动 给供求与成本变化留出一定调整空间 行政上限、核准程序仍决定边界
所谓自由价格（free prices） 企业在规定规则下自主定价、谈判 扩大分散选择和供求调节 仍可能受成本计算、利润率、涨价申报和价格管理机关约束

三类名称及重要限制均见IMF对匈牙利改革价格制度的研究。[H2][H3] “自由价”这里应当加引号，因为它并不等于理论上无任何价格干预的完全竞争市场。即便商品销售价格比较灵活，企业在大型投资、外贸、资金调拨和组织重组方面仍可能受到很强约束。

为什么不一次性放开所有价格？其中至少有四个需要历史研究的理由。其一，居民长期形成的低物价预期关系到政治合法性；其二，重工业和基础能源的集中组织体系不可能瞬间改造为充分竞争结构；其三，企业经营行为、税收与银行融资还没有形成稳定的新配套；其四，决策者并不希望市场机制改变社会所有制与计划的核心地位。

但这四点不是说改革速度必然“正确”或“不够勇敢”。其后实际效果仍要看成本、供给、财政和社会反应，不能先用政治标签代替判断。

7.4 为什么能源价格与世界市场价格成为重大问题？

1973—1974年国际能源和原材料价格剧烈上升。假设一家匈牙利企业使用进口燃料，却仍按长期稳定的国内低价核算。那么对企业来说，继续使用旧技术、大量消耗能源似乎并不昂贵；对整个国家来说，取得同样燃料所需的外汇、贸易交换和补贴成本却正在增加。价格信号被隔开，节约能源的行为就可能缺少充分激励。

IMF的1980年代研究记载，匈牙利在1973—1974年外部价格冲击后重新加强部分行政控制；到1974年，超过三分之二的国际价格上涨影响通过进口补贴得到缓冲。随后1975—1976年又作出生产者价格调整。这表明外部价格冲击如何进入国内企业决策，本身就是国家有意识选择的制度通道。[H9]

有必要区分两种判断：一方面，补贴可以缓解真实的社会调整成本，使居民和企业不至于受到一次冲击立即打垮；另一方面，如果补贴没有清楚的财政约束、退出规则和投资调整机制，就可能推迟节能或技术替代，把当前代价转移到外债、未来财政及后续调整上。

还不能据此断言匈牙利所有外债困难都由“能源补贴太多”造成。经互会贸易安排、国内投资政策、汇率制度、国际利率和可兑换货币债务都很重要，必须留待第17—19讲结合具体年度资料分析。

7.5 1968年匈牙利改革为何既让市场变重要，又没有成为兰格模型？

兰格理论设想价格可以由中央发布并试错，企业根据成本和利润规则调整生产；匈牙利则面对一整套历史形成的行政机构和政治约束，必须同时改革企业管理、价格、银行融资、国家投资、居民生活保障和国际贸易。虽然二者都承认社会所有制下可以保留价格信号，匈牙利改革不是教科书中兰格模型的直接实施。[H4][H8][T3]

曾任匈牙利国家银行高级领导人的Imre Tarafás于1991年回顾改革时特别指出：1968年改革主要尝试建立商品与服务市场，而资本市场仍受到重要限制，许多大型投资依旧处于强烈的中央控制之下。他强调既有企业组织中的高度集中和垄断，以及改革措施之间的不一致性。这是一种具有当事人经验的回顾性解释，不能直接代替1968年同期决策档案，却非常适合提出要用什么材料检验改革内在互补性的问题。[H8]

由此产生一个值得以后两讲追踪的悖论：如果允许企业根据售价提高利润，却仍然主要由国家决定大型投资，并且企业相信亏损会被救助，那么利润指标所形成的行动激励，未必能够与全社会长期资源配置目标一致。

7.6 匈牙利价格改革的历史意义，不应提前写成“成功”或“失败”

有人可能会说：“1968年以后匈牙利没有发展出完全自由的生产资料市场，所以米塞斯赢了。”另一个人则可能说：“匈牙利居民生活改善、商品流通扩大，所以兰格赢了。”这两种事后判词都太快。

真正应该区分：哪些商品的可得性改善了？企业采用了哪些技术？工业投资效率如何？生产者和消费者价格之间的财政转移怎样变化？在外部冲击期间，政府通过什么财政与外汇机制维持生活水平？不同时间段是否发生制度回摆？如果某些方面表现改善，这种改善有多少来自价格改革，多少来自农业合作社、外贸、进口和其他制度改变？

一种制度能够部分成功，同时包含尚未解决的结构矛盾。 这比使用事后“改革成功／改革失败”的二分更接近真正的历史政治经济学。

八、HSM模型：它有价格、物量和金融，但目前还不能回答哪种价格制度更好

8.1 先辨认仓库里真实存在的价格对象

根据2026年10月25日核查的main分支，F2商品本体位于config/ontology/f2_v1.json，区分固体燃料、石油天然气、电力热力、金属材料、化工、机器、建设、农业原料、食品、纺织品、家庭用品、耐用品、车辆和服务等16类商品。[S1]

src/hsm_lab/engine/material.py中可核对_admin_price_vector、_cell_price_vector等内部函数。该模块的文档说明，季度核算同时处理物资订单、资金可支付能力、进口出口、物流交付、生产和家庭购买；accounting.py则审查物量与金融账户能否闭合。[S2]

这意味着价格确实进入引擎的账本与购买决策，模型不是“没有钱的纯物量机器”。但同时必须明确：

  • F2的商品计量单位是模型声明的标准化或工程单位，并非自然对应吨数、千瓦时、当年福林或GDP；
  • 代码中的admin_price首先是模型规则的管理价格向量，不能仅因变量叫price就宣称它来自匈牙利实测市场价格；
  • 家庭买得起、物理上有货、物流能够交付是不同门槛；
  • 会计守恒只能检查没有凭空创造或遗失所定义的物量和货币，不能证明价格规则符合历史；
  • 价格参数一旦进入模型，可能同时改变采购、消费、银行与财政指标，不能把某个结果简单归因于“资源真实稀缺性”。

第03讲的F2实物网络解决的是“怎样规定可以发生哪些流转”，本讲更关心“这些流转如何被评价与选择”。两者相关，却不是同一个验证层级。

8.2 一个重要的负面结果：改变条件未必改变观测经济指标

P06关于政治反事实的公开报告记录，coalition-weights、soviet-constraint和cultural-openness等政策或政治干预，能够改变内部状态和replay digest，但部分报告经济指标与对照组完全一致。报告明确把这种情况列作某些杠杆的无观测效应，而非历史因果证据。[S3]

这种现象可用于理解信息与价格机制的一个一般方法论问题：政策或价格输入已经变化，并不意味着它传递到经济主体的选择；也可能某个更硬的物量、运输或财务约束把它遮蔽了；还有可能输出指标没有涵盖真正发生变化的经济行为。没有改变某个终端指标，不等于历史上的这个政策没有影响。

这件事和哈耶克的知识问题并不是一回事。哈耶克强调知识分散与价格发现；上述HSM结果显示的则是给定程序中某条参数干预是否进入实际测量路径。二者可以形成类比，不能冒充彼此的经验验证。

8.3 当前不能拿HSM的价格模拟来验证兰格或米塞斯

仓库README及P06最终报告把模型证据边界说得相当清楚：F2历史复现尚未完成参数校准，calibrated=0，没有任何机制卡达到历史SUPPORTED；在已比较的年份里，模型消费指数与历史观测方向相反，出口支付通道亦出现资金约束阻断。[S1][S4]

在这样的情况下，不能说“模拟证明行政价格必然导致长期消费下降”，也不能说“模拟证明放开价格必然提高效率”。有些价格改革的理论效应可能被模型的初始化、零售供给、物资结算或其他结构错误所淹没。即使某次参数改动产生输出差异，那也是声明规则下的条件性结果，而不等于历史上的价格改革效应。

本讲也不把HSM现有价格向量强行称为康托罗维奇意义上的影子价格。要获得模型内生的影子价格，需要先明确优化目标和约束，再对相应优化问题求解或进行经检验的边际价值分析。 单纯有价格向量并不等于已经求过对偶问题。

8.4 如果将来用HSM专门研究价格，应怎样设计一张合格的机制卡？

本讲不要求修改仓库或启动新实验，但可以给出一个提议中的研究设计，明确区分它与当前已执行实验。

研究问题：在相同初始库存、企业能力、家庭需求、信贷规则和外部冲击下，价格调整规则变化是否改变资源配置？

  1. 固定起点：使用相同checkpoint与seed，记录物资和财务状态；单独登记政策规则。
  2. 处理臂：保持价格常数、价格根据超额需求缓慢调整、或使用特定影子价格近似；确保价格机制本身确实被程序调用。
  3. 首阶段检验：核对企业有效采购报价、批准的配额、家庭可负担需求与真实成交是否真的发生差异。
  4. 主要指标：生产与消费交付率、资源闲置率、短缺、质量可比的产出、银行/财政余额和不同家庭群体实际消费。
  5. 负对照：改变一个当前运行路径明确不使用的价格变量，检查结果是否保持不变；同时加入有理论预期的正对照。
  6. 识别边界：声明相关历史价格、企业利润与物资流是否有独立档案资料支持；无独立材料时只报告模型内结构比较。

这样设计的真正目的不是提前选出“市场价”胜者，而是让竞争性解释拥有可能被推翻的实验条件。

九、比较视野：苏联、中国和匈牙利怎样面对相同问题？

9.1 苏联：改革价格与改造企业管理的关系

苏联早期的工业批发价格体系多采用以平均成本为基础的计算方式，后来为反映成本和技术变化进行周期性调整。其运作仍嵌入中央计划、行政任务、企业组织和财政制度。经济史家Berliner关于苏联定价政策的研究特别讨论了平均成本定价与较长期价格稳定的制度传统。[H10]

1960年代围绕柯西金改革的讨论，亦不只是“提高售价”那么简单。1966年的IMF同期研究记录了苏联扩大企业经营空间、提高利润考核作用、强化企业间直接合同、引入资本计息等改革尝试，同时指出重要总产量和部分品类仍由中央计划决定。[H11]

苏联经验说明：即使价格改革在技术上可行，企业是否根据它选择投入、销售商品和更新技术，仍取决于管理权限与预算制度。 这不是某一国独有的问题，而是计划制度的一般组织约束。

9.2 中国：双轨制不是兰格试错，也不是匈牙利三层价格的简单复制

中国1978年以后逐渐发展出计划内行政价与计划外市场价并存的双轨安排。农业首先出现国家收购任务与超额生产交易并存，工业领域随后扩大计划外交易，直至1980年代中后期价格体系进一步改变。国家并未一下取消原有定量供应义务，市场机制首先在边际增量上扩张。[H12][H13]

从经济计算角度看，双轨制的积极机制是：原有计划义务提供一定稳定性，市场价格则可能在增量部分揭示相对供求和机会成本。但它同时产生两种价格之间的租金；如果干部或企业掌握低价配额而可以转售高价市场，便存在套利与腐败的制度可能。1987年吴敬琏、赵人伟的同期论文已经清楚分析了这一价格制度作为过渡安排的收益与问题。[H13]

与匈牙利1968年改革相比，中国存在不同的农业生产结构、地方政府财政激励、非国有经济增量、外贸开放路径以及国家政治组织背景。“都引入市场价格”不足以解释改革最终结果为何不同。 系统比较将留到第24讲；本讲的任务是先辨明它们在价格制度中分别改变了哪一个环节。

9.3 三种历史实践，对经济计算论争作出了什么回答？

  • 苏联证明：拥有价格、银行和庞大计划统计系统，不等于企业已经按照反映稀缺的价格分散决策。
  • 匈牙利证明：可以在社会主义政治与社会所有制的边界内扩大价格灵活性和企业自主权；但改革实施的范围、财政和投资的互补条件仍会限制结果。
  • 中国显示：旧有计划义务与新增市场交易可以阶段性并存；与此同时，两种价格之间的制度租金与宏观稳定问题也会真实出现。

这些比较并不能由一个静态模型统一裁决。它们反而要求我们把经济计算问题推进到政治权力、财政约束、企业行为、信息形成与分配结构的总体关系之中。

十、学界争论：究竟哪种制度拥有真正的“计算优势”？

10.1 第一种解释：核心障碍是生产资料市场不存在

米塞斯传统将生产资料的货币价格、真正交易和企业家承担盈亏看作可行经济计算的关键。其长处在于强迫研究者比较复杂替代用途的经济成本；如果一组系统中的核算价格完全脱离稀缺和生产选择，那么所谓“算账”很容易只在纸面上成立。[T1]

对它的严肃质疑是：是否只有私人资本市场才能生产经济上有用的价格信息？公有企业之间的交易、管理价格的试错、合作社网络和影子价格能否满足部分乃至大部分配置要求？这些制度可能在什么条件下有效？仅凭“产权归国家”这一事实，不能直接给出全部经验答案。

10.2 第二种解释：只要满足理论最优条件，社会所有制也可以实现效率

兰格—勒纳论证的力量来自将最优配置的形式条件与财产所有权制度作有限分离。在明确定义的技术和偏好假设下，集中资产所有权并不逻辑上排斥生产企业依据核算价格进行分散选择。[T3][T4]

批评集中在条件是否具备：计划机关能否认识超额需求与供给、正确调整价格？企业能否获得充分的经营自主权？成本信息与资本更新如何被发现？静态均衡中“假定已知的生产可能性”，在真实世界中需要不断由创新、投资与失败创造出来。后来的研究也指出，真正的争论具有动态竞争与资本市场维度，并非只关乎一次性算出一组均衡价格。[T12]

10.3 第三种解释：关键不是信息数量，而是信息产生与行动激励

哈耶克强调分散知识的形成与利用；科尔奈则从现实社会主义企业、官僚机制和短缺经验出发，进一步研究经营者与国家之间的激励结构。即使价格调整得更灵活，如果企业始终预期会获得外部救助，或必须完成与利润不一致的产量任务，价格未必产生经济学教科书预期的效果。[T2][T9][T10]

但这种看法也必须避免走向“国家决策必然劣于市场决策”的新教条。复杂市场经济也存在企业内部计划、财政和货币干预、垄断、信息造假、金融危机及公共品配置；一个拥有市场价格的经济也可能存在严重的错配。制度比较不能只拿计划经济的现实缺陷与市场经济的理论最优模型比较，反之亦然。

10.4 第四种解释：技术进步能够降低计算成本，但不自动取消制度问题

康托罗维奇和现代运筹学意味着：在大型工业网络中，利用线性规划优化调拨、产能与运输，可以取得真实的工程收益。后来计算机、传感器、实时物流系统和机器学习使更多优化问题具有可计算性。但更强的计算能力并不自动提供好的目标函数，也不会自动改善数据造假、财产控制、投资冒险和群众参与不足的问题。[H5][T7]

从另一个方向说，数字化技术也不能解决所有市场失灵；公共政策仍需要讨论分配正义、长期气候约束和社会共同目标。计算能力越强，越需要严肃区分“正确求解给定问题”与“为整个社会定义正确问题”。

10.5 怎样让不同理论接受历史反证？

如果要研究匈牙利1968年价格改革，应该寻找一组能够在不同解释之间构成区分力的资料：

十一、本讲结论：市场和计划都要回答“谁知道、谁决定、谁承担代价”

第一，经济计算是一切复杂经济共同面对的问题。 不管生产资料私有还是公有，不管协调主要通过商品价格还是国家计划，都必须在不同用途之间分配稀缺劳动、资本、材料、土地和时间。没有一种所有制能够取消现实资源约束。物资平衡关注实物是否一致，而经济计算继续询问在多个可行方案之间如何作选择。

第二，米塞斯、哈耶克、兰格、勒纳与康托罗维奇并非只能被安排在“谁赢了辩论”的竞技场上。 米塞斯提出生产资料成本核算，兰格设计社会所有制下的核算价格协调，勒纳强调边际规则，哈耶克追问分散知识的获得，康托罗维奇则揭示给定约束下优化与影子价格之间的数学关系。把这些贡献分别掌握，远比选一位“终极胜利者”更有解释力。

第三，优化算法之所以强大，恰恰因为它的结论具有清晰的前提。 我们可以严格证明：在本讲的教学设定中，八吨钢材最合理的分配是A一组、B六组，目标值为38，边际钢材影子价值为4。但如果居民对农业机械的优先程度提高、技术系数改变、生产上限出现误报，最优解与影子价格就会相应改变。模型不能逃离它的目标函数和数据来源。

第四，真实计划经济中的价格具有多重社会功能。 生产者价格、消费者价格、账面成本、贸易价格和影子价格并不相等，也不必在所有场合相等。价格既是信息，也会形成激励和分配结果。低价可以承载福利目标，市场价格可以帮助传导稀缺，但两者都需要匹配供给、财政、产权和监督制度。

第五，1968年的匈牙利证明改革不是把一个开关从计划拨向市场。 它选择扩大企业自主权和价格灵活性，同时保留社会主义所有制、国家计划和多重行政限制。这样一种制度组合必然面对新的协调难题：企业利润怎样与国家投资目标相协调？哪些商品价格能调整，哪些受到政治和社会约束？外部原材料价格上涨由谁承担？这些问题将一直延伸到第14—19讲。

第六，中国的双轨制提供一个不同的历史镜像。 它让一部分经济主体在完成旧有计划义务后，逐步利用市场价格处理新增生产和销售；这样可以保留一部分既有制度稳定性，却也制造价格差与租金。这提示我们，评价改革应当看到它真正改变了哪一段制度中介，而不只是统计“市场成分增加了多少”。

第七，HSM使这套思想得到方法论上的检验机会，但尚不是历史结论。 当前模型已具备价格、实物与金融通道，但还没有以独立观测支持对匈牙利价格制度的因果识别，历史消费复现仍明显偏离。我们应当继续用它检查机制规则、定位瓶颈和提出可证伪问题，而不以可复现的软件结果替代史学研究。[S1][S4]

回到历史唯物主义可以提出一个更强的问题：社会如何把分散知识、利益冲突、技术能力和共同目标转化为可信的经济中介？ 市场价格是其中一种中介，国家行政计划是一种中介，数学核算价格也是一种中介。它们的效果永远取决于其所处的具体社会关系和组织条件。

十二、概念速查与研究型思考题

12.1 重要概念

概念 准确含义 必须避免的误解
经济计算（economic calculation） 比较替代生产方案的成本、收益和资源机会成本 单纯进行算术加减或核对会计账
稀缺（scarcity） 相对多个可能用途，资源数量有限 必然意味着社会完全缺少该种物资
机会成本（opportunity cost） 选择某用途而放弃的最佳其他用途价值 仅指已付货币账面成本
行政价格（administered price） 依政府或授权机构规则形成的销售/核算价格 一概没有用或一概等于真实边际成本
影子价格（shadow price） 给定优化目标和约束时，资源数量边际增加可改善的目标值 社会真实市场售价、永恒价值或应立即执行的官价
线性规划（linear programming） 在线性目标与线性约束下求可行最优配置 自动知道正确社会目标的万能算法
对偶性（duality） 资源约束的价值界限与生产活动最优化之间的对应关系 不需假设便能求得真实市场价格
边际成本（marginal cost） 多生产一单位所增加的成本 平均生产成本或全部固定成本
供求试错（trial and error） 根据超额供求对核算价格进行连续修订 任何现实政府均可无成本即时准确调价
分散知识（dispersed knowledge） 分布于行动者之间、常随时间地点变化的具体知识 只是全国信息量太大、计算机跑不动
软预算约束（soft budget constraint） 经济主体预期困难时可能获得外部救助而影响行为 所有财政支出、补贴或亏损的同义词
制度互补性（institutional complementarity） 一种改革的效果依赖其他规则是否同时改变 改革越全面必然越成功

12.2 研究型思考题（不附标准答案）

问题一：影子价格的政治性。 本讲教学模型给A产品贡献8、B产品贡献5。如果劳动者代表大会认为农业机械有更重要的长期社会收益，从而把A的贡献重新赋值为12，最优解会发生什么变化？价格计算的技术正确性与目标决定的民主正当性之间有什么关系？

问题二：分散知识。 假设国家掌握所有工厂上季度产量、库存和报价，但企业知道下一季度某个关键设备可能故障，零售商知道当地居民消费偏好改变。哪一类信息难以由年度物资统计解决？应当怎样设计组织反馈，而不简单假设企业必须完全私有化？

问题三：匈牙利改革。 价格从固定转为有上下限的浮动价，而大型投资仍由中央决定、能源进口仍被补贴、企业仍可能被财政救助。请构造一条“价格变化→企业选择→银行和财政→消费供给”的因果链，并标出最可能中断的环节。

问题四：中国双轨制。 某企业计划内每吨原料可按100元购入，计划外价格200元。原料配额会怎样获得隐含租金？如果企业必须完成计划内供货义务，与能够转售配额的情形相比，其行为激励有什么不同？设计一项限制套利但保留增量市场信号的制度改进。

问题五：检验HSM。 模型设置管理价格，拥有投入产出网络和家庭预算，但消费指数与历史方向相反。为什么不能直接说“价格理论错了”？请区分价格规则未传导、出口或财政通道卡死、价格—商品口径不匹配，以及目标函数错误四种解释，并提出各自可以检验的变量。

附录A｜不用微积分，继续检查影子价格的三个边界

A1：如果钢材从8吨增到10吨。 保持B为6组，多出的两吨钢仍给A；A由1组变成2组，社会目标从38升为46。所以两吨钢增加8单位，平均每吨增加4；与第5节求得的局部影子价格吻合。

A2：如果钢材增加到14吨。 B最多6组，A最多4组，两厂都达到产能上限。此时总目标5×6+8×4=62，再给一吨钢也不提高目标。因此不能拿8吨短缺状态下的影子价格4，去预测16吨储备过剩时的资源边际价值。

A3：如果社会评价改变。 把A每组价值从8改为12，A的每吨钢收益从4上升到6，超过B的每吨钢收益5。八吨钢于是优先供A生产4组，B为0组；在新目标下总贡献是48。若另有“保障最低居民家电供应2组”的社会约束，解又不同。这说明目标权重与社会保障条件属于经济决策本身，不能被优化软件自动决定。

Python可选验证

以下代码只枚举教学模型的整数或半整数可行解，检验第5节的结果。它不是HSM代码，也不是历史史料：

best = None
for k in range(0, 9):      # A 以0.5组为步长，最多4组
    a = k / 2
    for j in range(0, 13): # B 以0.5组为步长，最多6组
        b = j / 2
        steel = 2*a + b
        if steel <= 8:
            welfare = 8*a + 5*b
            if best is None or welfare > best[0]:
                best = (welfare, a, b, steel)
print(best) # (38.0, 1.0, 6.0, 8.0)

网格枚举只是教学验证，不是一般线性规划的高效算法。真实大规模问题可使用线性规划求解器；算力越充沛，越应该首先检查目标、约束和数据是否定义准确。

附录B｜阅读经济计算论争时的一页核对卡

面对任何一句“某某证明社会主义不可能”或者“某某彻底解决社会主义计算”，先检查以下问题：

  1. 文献讨论的是生产资料所有制、市场交换、价格体系、计算能力、信息发现，还是企业激励？
  2. 它的结论是否依赖已知技术、已知偏好、竞争、企业成本最小化等强假设？
  3. 是否区分形式上的均衡存在性与动态历史过程中寻找均衡的困难？
  4. 论证以私人利润为目标，还是以居民福利、工业增长、分配平等和公共服务为目标？
  5. 文献是否真的检验了某个国家的实际经济数据，还是只提出概念推理？
  6. 如果讨论的是苏东历史，企业、部委、银行、国家价格局和居民实际拥有的权利及规则有没有被还原出来？
  7. 用什么反例或可观察事实能够让它的解释失败？
