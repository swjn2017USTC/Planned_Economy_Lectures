## 本讲最重要的20%

**第一，历史解释至少要跨过三道不同的门：干预是否真正改变了制度规则；被改变的规则是否通过明确的中介影响模型结果；历史资料能否独立支持这一中介在真实社会中存在并具有足够重要的作用。**第一道门叫**首阶段（first stage）**，第二道门是模型内的**机制识别**，第三道门才接近**历史因果识别**。只显示两条不同的模拟曲线，连第一道门都未必跨过。[T][C]

**第二，HSM目前最有教育意义的结果之一，是M02确实出现了“按照预先定义的标准反证自己的假说”。**它在8商品F1合成模型上进行3个seed×13个实验臂×4季度的对照。硬化预算与切断信用是一个**联合干预**；信贷首阶段真实起作用，而单独修改救助硬度的路径不生效。更重要的是，严格预算—信用组合没有在多个可比较短缺指标上呈现原假说所期待的普遍改善，触发了该卡预注册的反证条件。其结构判定是`REJECTED`，历史仍是`UNIDENTIFIED`。被否定的是**该模型、该条件、该可检验命题**，不是一举否定科尔奈有关软预算约束的全部理论。[S][^1]

**第三，M09展示了一种更隐蔽的失误：信息本身变好了，但经济决策没有变。**在该模型的合成信息实验中，报告延迟与预测方法的变化确实改变了输入信息及预测误差。然而预测值进入采购程序时受到100单位上限约束，各方案的实际申请均落在同一上限，所以下游经济结果在相同seed内一致。这个“零效应”有具体传导解释，不能说信息改善无用；与此同时，M09尚缺一条事先登记的专门负对照，不能因为后来发现一组结果相等，就把它追认成已完成的负对照设计。[S][^2]

**第四，参数敏感不是参数已被历史识别，固定随机种子也不是获得历史误差范围。**改变运力分配或工资系数使模拟产出变动，只能说明模型对这些输入敏感。若政治联盟、统计偏差、企业预期和外部贸易系数没有独立可比的史料，即使找到一组“拟合不错”的数字，也可能有很多完全不同的参数组合产生同样结果。这就是参数不可识别与等效性问题。[T][S][^3]

**第五，到当前H6B基线，11张机制卡只有M01、M02、M04完成全部11项研究包检查，8张仍受阻；历史`SUPPORTED=0`、`calibrated=0`。**其中“3张complete”只说明研究包的对照、首阶段、核算、负对照、指标、复现等合同齐全，并不说明三项历史假说获得支持。研究工作的价值，正在于把`PASS`、`REJECTED`、`BLOCKED`、`UNIDENTIFIED`和`NOT_RUN`严格分开，让未来的档案和数据有机会改变结论。[C][S][^4]

这正好接续前两讲：第25讲讨论把历史制度写成可执行规则，第26讲追问为何规则和账本正确仍无法复现历史；本讲更进一步——即使未来某条模型曲线终于贴近历史，我们还需要怎样证明**为什么**会这样？

## 一、问题从哪里来？1968年的匈牙利改革，究竟证明了哪一种理论？

### 1.1 改革者面对的是一个真实的制度选择，而不是控制变量实验

1966年5月7日，匈牙利社会主义工人党中央委员会通过有关新经济机制（New Economic Mechanism，NEM）的改革决议。1968年开始实施的改革试图降低一部分企业日常经营中强制性生产指标的地位，让价格、利润、税收、信贷和企业自主决定承担更多协调工作。但中央计划、社会所有制、政治制度框架依然保留。换言之，改革不是“计划制”瞬间切换为“自由市场制”；它改变了一组相互联动的决策权限和经济杠杆。[H][^5]

在改革者看来，一个难题很明确。旧体制可以集中决定钢材、能源、投资等战略资源的用途，却不容易从中央实时判断成千上万家企业的投入品组合、产品质量、用户需求以及地方市场变化。如果给予企业较多经营选择权，企业是否会更积极寻找需求、节约原料和改善产品？反过来，如果国家仍然不愿让重要企业破产，并继续掌握主要投资、价格和外贸资源，那么企业是不是会把所谓市场自主权转化成追加贷款、扩大投资和要求财政救助的权利？

这并不是某位改革者在头脑中清楚列出的二元选项，而是可以从已公布制度方案和后来研究中重建出的**竞争机制问题**。改革不只改变“自主权”，还改变价格环境、责任边界和供给渠道；外部贸易条件、国际信贷以及政治约束也并不静止。[H][T][^5][^6]

当时历史不存在一个平行匈牙利，能够在其他一切完全相同的情况下只保留旧计划指标。历史学家只能观察**实际采用的改革及其后续调整**。因此，若有人说“1968年改革使效率提高”，合理的下一问不是“改革好不好”，而是：“我们怎样将改革的作用同1970年代投资扩张、价格体系、外贸融资以及国际冲击的作用区分开？”

### 1.2 政策过程提供时间顺序，却不会自动提供因果答案

1972—1976年，匈牙利的改革出现一定程度的再集中；1980—1981年又试图恢复或加强某些间接调节和企业自主安排。1983年，经济学家贝拉·巴拉萨（Béla Balassa）已把改革—再集中—再改革视作一个需要分析的过程，而不是单向成功或失败的“开关”。[H][^6]

与此同时，国际环境改变了比较对象。根据国际货币基金组织后来的历史统计重建，匈牙利在1974—1978年经历贸易条件恶化，外部借款帮助缓冲进口和增长压力，却也积累债务脆弱性；匈牙利于1982年5月6日成为IMF成员。[H][^7][^8] 因此，如果1978年观察到居民消费、企业进口与债务同时增长，至少存在三条需要区分的因果路径：

1. **国内改革路径**：企业权力与利润激励改变资源使用、投资和产品供给；
2. **国家再分配路径**：价格补贴、财政或信贷支持缓冲了损失，让企业和家庭继续支出；
3. **外部融资路径**：进口与国际贷款把一部分当期资源约束推向未来。

三条路径可以同时成立，互相抵消，也可以只在某几个行业显著。它们不是三个总量指数就能自动区分开的。这种困境正是历史研究中的**识别问题**：历史已经发生了，我们却不能直接看到每一种机制单独造成多少后果。

### 1.3 从科尔奈的命题到一张可以反证的研究卡

科尔奈把**软预算约束（soft budget constraint）**定义为一种预期和制度关系：企业预期，即使自身收入不能覆盖支出，外部组织仍有相当可能提供补贴、优惠贷款、税收减免或其他救助，从而削弱支出必须受自身收入约束的力量。它关心的并不只是实际收到几笔救助，更是企业**事先预期会不会被救**，并据此采取何种行动。[T][^9][^10]

但从该概念直接跳到“它解释了东欧短缺”，跨度很大。我们至少需要知道：亏损企业是谁？谁实际救助？什么时候决定救助？企业能否预见这一决定？贷款进入了投资还是生产？申请更多钢材最终导致哪一类短缺？缺货是因为工业投入争抢、运输能力、价格不调整，还是因为家庭收入增长快于供给？

如果这些中介都找不到，所谓历史解释就可能退化成**观察到短缺，便推断存在软预算；观察到软预算，又反过来解释短缺**的循环论证。计算实验可以帮忙拆开这个循环，却不能单靠运行本身把它解决。

## 二、先把“证据机器”拆开：历史解释需要经过哪些组织和资料环节？

### 2.1 一条因果链不是一种相关性

试设研究命题为：“财政救助预期升高，使国有工业企业投资申请增加，并挤占消费品供应。”真正的可检验链条应当是：

**财政—银行—企业制度规定** → 企业获得关于救助的可信信息 → 企业修改预期 → 投资申请增加 → 审批和融资发生 → 钢材、机器与运力被转向投资项目 → 一部分其他需求的实际交付下降 → 企业和消费者改变订货、囤积或政治诉求 → 下一轮政策回应。

链条中只要有一个箭头未经测量，“整个命题成立”的判断就必须降格。举例说，企业追加投资申请并不等于投资完成：项目可能未获批，批准却没贷款，贷款到位却缺少机床。即使消费品供给下降，也不一定是投资挤出造成，可能同时出现进口缩减或流通瘫痪。

这条链条至少包含三类“观察者”：**历史行动者**（企业、银行、中央计划机关、家庭）、**史料生产者**（统计局、档案机关、会议记录者、会计人员）和**研究者**。历史行动者的行为影响生产，史料生产者决定哪些行为被记录，研究者再把记录与模型变量连接起来。如果企业为了获得更多资源而夸大需要、地方统计员按照上级考核调整报表，那么“观测值”本身就是制度作用的结果。这并非简单加上一个随机噪声即可消除的问题。[T][I]

### 2.2 从材料到结论的六个检查点

| 检查点 | 最基本的问题 | 没有通过会怎样？ |
|---|---|---|
| 理论命题 | 具体预测什么变化、什么事实会反驳？ | 不可证伪、只能事后解释 |
| 处理与对照 | 改了什么，其他条件是否一致？ | 不能归因于某项规则 |
| 首阶段 | 该规则真的改变了行动者能用的资源或信息吗？ | “干预”只改了标签 |
| 中介结果 | 申请、获批、执行、交付各自如何变化？ | 把意愿当成实际经济后果 |
| 历史观测 | 是否有独立、同口径、同时间范围的数据？ | 模型内效果冒充历史规律 |
| 竞争解释 | 另一个机制是否也能产生同样结果？ | 拟合好不等于解释对 |

例如“企业更自主”可被拆成采购权、销售权、资金留用权、投资审批权和用工权；改变其中一项，其他不变，才开始接近特定机制的对照。历史改革常常改变一整套制度，所以即使模型里完成了单项操作，历史证据也还要证明现实中存在类似的单项变化。

### 2.3 反事实是“一个世界里没有发生的事情”，不是任意讲一个故事

**反事实（counterfactual）**的含义是：在同一研究对象、相同前提下，假定某个具体条件不同，结果会怎样？在计算机里，可以从同一个已保存的期末状态（checkpoint）分成两个分支：A维持原信贷规则，B切断信贷；除该干预及其后续影响外，输入和随机实现保持相同。

模型内这样做很有力，因为我们能清楚地知道哪些条件被固定。但真实历史没有第二个独立运行的1968年匈牙利。**模型内条件因果效应**因此并不等于**历史反事实真实效应**。后者需要独立史料说明模型的主体、行为方程、政策适用范围和外部约束确实接近历史。

另一个不易察觉的陷阱是把“共同seed”视作“共同历史”。同一个seed只确保被该随机种子控制的抽样过程可比较；它不能让初始状态真实，也不能让未进入模型的政治决策自然发生。更不用说同一历史时期只有一次：三个seed并不意味着我们拥有三个彼此独立的匈牙利。

## 三、关键历史过程与认识论转换：1968、1973、1982不是三个互不相干的“处理”

### 3.1 1968年前后：制度在改变，而企业反应存在时滞

新经济机制追求由直接命令转向更多的间接调节，但社会所有制、国家投资及金融体系并没有同时变成完全竞争市场。[H][^5] 因而，企业在某一年表现出的增加利润、追加投入申请或者扩大销售，可能是一次新的政策激励的反应，也可能是旧制度下形成的预期继续存在，还可能是部门主管与企业经理重新谈判的结果。我们不能把“发生在1968年以后”直接等同于“1968改革造成”。

设想一位从旧制过渡到新制的工厂经理（此处是**教学性角色，不是档案中某个虚构的真实人物**）。他知道部分销售决定权扩大，却不清楚未来亏损企业是否真的会破产。他会先观察别的企业获得贷款的情况，再判断扩大投资是否安全。如果国家在某次计划会议上重新保证就业和重点生产，他的救助预期还可能增强。**制度的法律条文、组织的实际执行以及参与者对未来的预期，是三个不同变量**。

用史料检验这一机制，需要同一企业数年的预算、信贷申请、审批意见、亏损处理、材料配给及企业管理会议，而不只是一张全国投资率曲线。这正是为什么严肃的历史因果研究往往比宏观相关性分析更耗费档案工作。[I]

### 3.2 1970年代：外部融资成为必须控制的竞争解释

1970年代世界能源与原料价格、国际金融市场、经互会（CMEA）贸易条件和可兑换货币贸易的变化，都可能改变工业投入和国内消费的可得性。1974—1978年匈牙利贸易条件恶化、借款延缓调整的事实，意味着即使改革推动企业产出增加，国内进口支持也可能掩盖了一部分资源配置缺陷。[H][^7]

反过来，如果宏观增长转弱，也可能是外部融资约束趋紧，而不仅是企业自治引起投资无纪律。检验时必须分开国内福林预算、经互会结算和可兑换货币渠道。**同样的一吨化肥，国内有钱购买不代表国家有相应外汇进口；国内存在计划进口指标，也不保证交付和运输已经完成。**

因此，假如我们要用1973年的贸易冲击做“自然实验”，就必须先确认不同企业受到的外部能源依赖程度、库存缓冲、政策扶持和出口收入是否本来不同。这些差异可能同时影响改革表现。仅比较“1973年前后”便归因于冲击，是不充分的；而拿1980年代已经发生的转轨结果去判断1968年政策设计者本应做什么，又会落入后见之明。

### 3.3 1982年前后：新的制度选择不等于证实了旧理论

匈牙利1982年加入IMF这一事实，可以说明国际金融约束已经进入制度决策的显著位置，但**不能单靠这一日期证明1968年改革必然失败，也不能证明软预算是危机唯一原因**。[H][^8] 1982年以前发生的工业结构变化、价格调整、社会消费承诺和债务累积，每一项都可能影响危机的深度及政策选择。[H][I][^7]

这是历史研究与实验室试验的一个根本差异：在真实社会中，**处理、控制组和背景环境经常一起演化**。历史研究者真正需要做的，不是强行把这些变化压成一个“改革系数”，而是建立充分限定的机制问题，寻找可以区分彼此竞争解释的史料。

## 四、经济学与研究方法：从参数识别到负对照

### 4.1 参数“有值”并不等于“被识别”

历史模型必须先给参数赋值，才能开始运行。假设企业超额订货倾向是0.2、救助预期强度是0.6、报告误差比例是0.1，程序完全可以计算116季度；然而这些数字可能只是为编程选定的初值，既不是匈牙利历史的估计，也不是后来统计置信区间的中心。[T]

**参数识别（parameter identifiability）**问的是一个更严格的问题：给定模型结构与可获取观测，不同参数值是否能够被区分？若两组参数能够在所有可观测指标上产生同样结果，那么该参数组合就没有被这些数据识别。这里要区分：

- **结构不可识别**：即使有无限精确的同类观测，某些参数在模型结构内仍无法分开。例如只能观察到`a×b`，无论如何测量这个乘积，都无法分别知道`a`和`b`。
- **实践不可识别**：理论上参数可区别，但现实数据太少、噪声太大、观测时间太短、变量口径不准，导致估计范围仍非常宽。
- **历史外推不可识别**：模型局部参数可由合成数据反推，但缺乏理由证明该参数也是实际企业或干部的行为量。

关于前两者，现代动力系统研究同样明确区分结构识别与资料不足导致的实践识别；这并非东欧经济研究独有的问题。[T][^11]

例如HSM的P05报告记载，一些信息噪声由测量误差与观测缩放的乘积构成、某些偏差项只以比值进入下游报告机制。若没有独立重复的统计测量，单靠宏观最终产出，便很难把这些系数分别识别。项目报告当时的识别筛选结果是`NO_IDENTIFIABLE_PARAMETERS`、`identifiable_set=[]`、`linkage=[]`；六个行为块仍未识别。[C][S][^12]

### 4.2 敏感性分析回答“哪些输入能影响模型”，不是“哪些输入造成历史”

**单因素扰动（one-at-a-time，OAT）**的做法是：固定其他参数，改变一个输入，观察输出变化。如果运力份额由0.20升到0.24，模型消费品交付量改变，说明在这个起点附近运力配置是有作用的模型杠杆。它既不能告诉我们历史运力份额究竟是多少，也不能保证在另一个初始状态、另一套运输网络中方向相同。

**Morris筛选**通过若干不同起点的单因素“基本效应”探索哪些输入有较大影响，较适合作为初步筛查。原始方法论文明确将其定位于复杂计算模型的**因素筛选**，而非历史参数估计。[T][^13] HSM的P06报告曾用两个Morris轨迹和三组seed描述相应的模型敏感性，这个数目足以进行探索性排序，却不足以据此宣称精确的历史因果贡献。[S][^14]

一个容易犯的错误是：“参数X对产出最敏感，所以真实匈牙利的危机主要由X造成。”逻辑上缺少两步：X在真实历史中是否发生了对应幅度的变化？当时其他条件是否允许它把作用传到消费、贸易或政治？**敏感度很大但真实变量从未变动，也可能对历史变化毫无解释力。**

### 4.3 负对照与安慰剂：故意设计一个“不应有作用”的处理

负对照（negative control）的逻辑是：找一个根据研究设计**应当不影响目标**、但仍暴露于同类潜在偏差或实施路径的比较。如果它居然有影响，就提示我们存在混杂、泄漏、错误时间顺序或实验实现问题。负对照在观察性研究中的重要性，已由Lipsitch、Tchetgen Tchetgen和Cohen作出系统讨论。[T][^15]

在计算实验中，可以采用不同但相关的检查：

- **安慰剂标签**：仅改变实验臂名称，不更改实际参数；若输出却不同，说明实验实现、随机路径或记录处理有问题。
- **机制负对照**：改变一个理论上不进入选定路径的变量；若目标受影响，需检查是否有遗漏通道。
- **时间负对照**：在决策已经完成之后才引入的信息，不应逆向影响此前决策；若产生效应，怀疑未来信息泄漏。
- **预注册非干预臂**：保留与处理组相同的初始状态和外生序列，事先规定比较指标，不因结果出现才追认对照。

要注意，**所有负对照都依赖一个关于“理应没有效应”的理论假设**。它是检错工具，不是万能的真实性证明。尤其不能把研究中碰巧出现的相同结果自动叫作“做了负对照”。

### 4.4 复现、seed离散与参数不确定性是三种不同的东西

- **复现身份**：相同源代码、数据、参数、随机种子和环境能否产生同样的指标及digest？这是工程可复查性。
- **随机种子离散**：初始家庭抽样或代理随机决策换一个seed，模拟结果变动多少？这反映模型定义的随机过程所引入的差异。
- **参数不确定性**：真实行为参数未知，根据资料、先验和模型应允许哪些取值？这些取值带来多大输出差异？
- **结构不确定性**：另一种合理的生产、财政或信息机制，是否也能解释同一现象？它不能由同一程序多换几个seed解决。

这里还有两种更深的不确定性。其一是**测量误差**：历史统计来自变动中的分类、价格和报送体系；其二是**制度不确定性**：政策制度可能在研究窗口中改变，导致原本固定的行为规则不再适用。研究者不能把这两种不确定性全部塞进一个“误差项”。[I]

### 4.5 当没有可计算的似然时，ABC可以做什么、不能做什么？

**近似贝叶斯计算（approximate Bayesian computation，ABC）**适用于某些能够从给定参数模拟数据、却难以直接写出似然函数的模型。简化理解：提出参数的先验分布，用这些参数产生合成输出，比较预先指定的摘要统计与真实观测，只保留距离足够小的候选，再根据算法更新参数分布。其有效性依赖摘要统计、误差模型、先验、容差、结构合理性和可识别性，而不是算法名称本身。[T][^16]

HSM的P05有一个**合成目标的API smoke test**，例如利用同一个内核制造利用率参数已知的合成结果，再检查ABC接口能否向真值靠近。这能证明接口流程可运行，却不能证明匈牙利历史行为系数得到了估计。真实参数—目标linkage仍为空，正式历史ABC/pyABC没有运行。不能从“代码里有ABC”推出“研究已经校准”。[S][^12]

更严肃的问题是：当一个结构本身错误的模型通过许多参数组合逼近某条历史曲线时，ABC或任何优化器都有可能给出很漂亮但误导性的分布。统计精确度不是结构真实性的替代物。[T][I]

## 五、一次能手算的经济与数学实验：为什么“两条模拟曲线不同”还不是答案？

### 5.1 先用四个数字拆分“联合政策效应”

以下完全是**教学构造的数字**，不来自匈牙利或HSM。[E] 我们研究某地区工业中间品的缺口率（百分比，越低越好）。设置两类政策：能否发放额外信用（C=1或0），以及政府是否可能提供救助（R=1或0）。四个分支从同一库存状态开始，只改政策。

| 信用C | 救助R | 最终中间品缺口率 | 解释 |
|---:|---:|---:|---|
| 1 | 1 | 20% | 信用和救助都可用 |
| 1 | 0 | 20% | 只有信用，缺口仍20% |
| 0 | 1 | 34% | 无信用、但可救助 |
| 0 | 0 | 35% | 信用与救助均无 |

若只比较左上与右下，会发现“从软到硬”缺口由20%升到35%。但这不是**救助收紧的纯效应**。因为同时取消了信用。要拆解至少要保持信用不变再比较救助：在`C=1`时，救助从1变0，缺口从20%到20%，结果根本没变；在`C=0`时，救助从1变0，缺口从34%到35%，变化只有1个百分点。另一个更大的差异来自信用是否存在。

这提醒我们：联合干预的效果可以被度量，却不能不经拆分就为其中一项政策命名。反过来，也不能仅因为救助在`C=1`时不显效，就断言“救助制度毫无作用”；在有信用时，救助可能根本没有被请求，而在信用断供后它又成为关键通道。

### 5.2 再用同一表格理解差中差与交互作用

在这个教学实验中，救助政策效应在有信用时是`20−20=0`个百分点，在无信用时是`35−34=1`个百分点。两者的差，即一种最简化的二重差分：

\[
\Delta\Delta=(35-34)-(20-20)=1\text{ 个百分点}。
\]

这个1反映**救助与信用条件的交互**：救助的边际作用随着信用是否可用而改变。它不是“真实匈牙利救助效应等于1%”，更不能据此作统计显著性宣告，因为表中只有一组教学数字，没有独立历史观察、没有误差模型，也没有经济制度可比性证明。历史中的差中差还需要对照组趋势、干预外溢、政策同期变化等额外假设。

HSM的M02提供了更复杂的类似问题：把`soft`与`hard`做总体比较还不够，必须查看`credit_cut`、`rescue_cut`等拆分臂是否真的改变实际信用和救助。第六节将直接用它的报告解释这一点。[S]

### 5.3 两种参数组合产生同样输出：一眼看出“不可识别”

继续用一个极简的**合成例子**。[E] 假设报告中出现的某种“短缺焦虑分数”只由企业真实短缺程度`a`和统计报告放大系数`b`共同决定：

\[
S=a\times b。
\]

如果只观测到`S=12`，那么`a=3,b=4`和`a=6,b=2`完全无法区分。即使重复测量同一个乘积一百次、把测量精度提高一千倍，仍然不能知道真实短缺是3还是6。若能独立取得仓库库存缺口、实际停工次数或经第三方核实的供货单，我们才可能分别约束`a`和`b`。这就是**新的观察维度比重复拟合同一个宏观总量更有价值**的原因。

### 5.4 再加一个“小反证”：预先讲好什么会推翻命题

设假说为：“只要加大企业投资冲动，无论家庭需求高低，都会提高所有中间品的短缺指标。”设计者在运行前规定两种家庭需求状态、两个投资强度、三组seed，记录每个商品—流通阶段—用途的缺口比例，不能把单位不同的钢、煤和服务随意加成一个“全国总短缺”。

如果有若干预先指定的短缺指标在投资强化后没有增加，**究竟算不算反证**取决于研究者事先声明的是“所有指标都必须增加”“平均必须增加”还是“至少一项增加”。没有预注册，研究者就可以事后改变规则，让假说永远不输。M02的特殊价值正是在于它保留了一条明确的反证规则及其被触发后的`REJECTED`结果，而不是依照研究者偏好改判。[S][^1]

### 6.2 M02：严格预算为什么没有得到研究者原本希望的“短缺改善”？

M02的专项实验见[`studies/HIST_VNEXT/M02/REPORT.md`](https://github.com/swjn2017USTC/hungary-socialist-mechanism-lab/blob/main/studies/HIST_VNEXT/M02/REPORT.md)、[`spec.json`](https://github.com/swjn2017USTC/hungary-socialist-mechanism-lab/blob/main/studies/HIST_VNEXT/M02/spec.json)。它运行的是**F1/Intermediate-8合成模型**，不是F2匈牙利历史复现；窗口1957Q1—1957Q4，共4个季度；三组seed为1729、1730、1731，每组13个处理臂，总共156个已通过守恒检查的tick。这三组seed只是合成家庭初值变化的稳健性探针，不是三份独立史料。仓库报告记载约261.6万条金融分录腿经审计，没有发现无效分录；本讲没有自行重跑这些数字。[C][S][^1]

原命题可简写为：**软预算约束与投资饥渴足以在不同家庭需求条件下维持系统性短缺。**实验把家庭需求分成原始和缩减两档，把投资强度分成低、高两档，并改变两项政策变量：

- `soft`：预算硬度0.0、信用系数0.5；
- `hard`：预算硬度1.0、信用系数0.0；
- `credit_cut`：预算硬度0.0、信用系数0.0；
- `rescue_cut`：预算硬度1.0、信用系数0.5。

其中`hard`与`soft`差了**两个政策坐标**。如果只比较二者，便会错误地把信用消失造成的经济活动下降当成“预算硬化的纯效应”。好在研究中有可分辨的附加臂，且逐项审查首阶段。[S]

报告记录：在`hard`和`credit_cut`相关臂，信用抽取降为0，说明**信贷通道确实有效**；`rescue_cut`相对于有信用的`soft_high`不改变最终经济输出，因为此处救助未被实际请求，单独改变“救助硬度”不产生有效首阶段。另一方面，在`credit_cut`、仍允许救助的高投资臂，真实救助发生，但它并不能恢复原来有信用条件下的安装产能。因此，整个实验观察到的不是一个干净的“硬预算越强，资源配置越好”的结果。[S]

更重要的是：M02规定的反证标准是**当预算硬度提高并切断信用后，某些可比较短缺指标仍不下降**。研究报告明确记载，多数可读的缺口轴满足这一反证条件：各seed、投资强度下48个可读指标中有45—48个出现相应的非下降；两种家庭需求状态均触发判定。因此该模型内的结构命题判为`REJECTED`，`SUPPORTED`不可达。**不要误读成“研究证明软预算与投资饥渴不可能导致短缺”**：它证明的是原来那个过强的、关于“足以且独立于需求状态”的特定说法不能凭这组模型结果成立。[S][^1]

这是一次很好的“负面结果”示范。哪怕研究者本人更希望看到“削减信用、硬化预算可以消除短缺”，也不能因为产出更低、订单更少就宣布效率改善：生产减少可能让部分需求不再进入交付链，却并未增加能够送到家庭的物资。反过来，部分缺口不降也不必然验证某一种新的社会主义制度理论。每一种结论都必须回到可比较轴、分母、实际物量和金融来源上。[I]

**历史层面仍是`UNIDENTIFIED`**：这个F1合成实验并没有读入真实的匈牙利企业贷款契约、具体企业的预算救助档案或独立短缺测量。宏观历史统计不能简单充当模型中`credit_fraction=0.5`的真实估计。[C][S]

### 6.3 M09：预测误差显著变小，为什么“实际结果一模一样”？

M09的实验材料见[`studies/HIST_VNEXT/M09/REPORT.md`](https://github.com/swjn2017USTC/hungary-socialist-mechanism-lab/blob/main/studies/HIST_VNEXT/M09/REPORT.md)、[`spec.json`](https://github.com/swjn2017USTC/hungary-socialist-mechanism-lab/blob/main/studies/HIST_VNEXT/M09/spec.json)。它在F1/Intermediate-8材料模型内模拟一个地区采购者，比较两个信息延迟设置和两种预测法：延迟0或1季度、用最近一季维持不变的`persistence`或两点线性外推的`linear`。4个方案、4个预测目标、3个seed，共48条实验记录；历史上的计划—执行档案并未进入这次检验。[S][^2]

公开报告给出的合成预测平均绝对误差（**模型原生单位，不是匈牙利历史价格或GDP**）如下：

| 信息延迟／方法 | 合成预测MAE |
|---|---:|
| delay0 + persistence | 108.7503 |
| **delay0 + linear** | **14.7346** |
| delay1 + persistence | 170.4927 |
| delay1 + linear | 71.1815 |

报告同时强调：这组被预测的生产路径在三个seed中相同，所以所谓“三个seed重复了该结果”并不是三个独立预测样本。延迟变化确实改变了可见报告集合，首阶段通过；两点线性外推在这段合成数据上的误差明显更低。**到这里，我们最多能说信息处理方法改变了该模型中的预测精度。**[S]

紧接着发生了决定性的事情：模型把预测量转为采购申请时，使用`requested_quantity=min(100, max(0, prediction))`。四种方案各自的预测虽然不同，但相关非末期预测都高于100，因此采购申请统一被裁剪为**100单位**。下游的生产交付还受资源和运输约束，故同一seed下四个方案的经济结果完全一致。预测误差下降，**不意味着政策行动已经改变，更不意味着居民福利改善**。[C][S]

这可写成一条极短的机制链：

**报告更及时** → **预测更准** → **采购申请撞到100单位上限** → **实际申请相同** → **分配、交付与家庭获得的物资没有产生方案差异**。

但还有第二个重要限制：M09并没有登记合格的**专项预注册负对照臂和对应指标**。因此H6B把该卡列为仅因`negative_control`未通过而`blocked`；虽有真实的null经济结果，却不能“事后把null命名成负对照”来让研究包变complete。[C][S][^4]

如果要让M09继续前进，第一步不是把历史1970年代的投资数字塞进预测模型，而是先完成独立、事前定义的负对照，并设计一个不发生机械饱和的、仍满足会计约束的预测到行动机制；然后才考虑寻找真实的预测报告、发布时点、修订记录和执行数据。即使非饱和实验出现产出改善，也仍然只是条件性结构效应，除非历史资料支持对应制度链。[I]

### 6.4 M01、M04与其他八张卡：研究的“完结”不等于理论的“胜利”

M01的社会契约棘轮实验，在同一冻结状态下比较长期渐进改善与一次突变，部分收入/进口削减杠杆出现条件性的历史参照依赖效应，而福利削减杠杆仍`UNIDENTIFIED`。M04的第二经济实验中，制度容忍度上升能使合成第二经济活动增加，但活动接近容量上限；它并没有证明净福利一定改善。这两张卡的研究包完成，恰好说明**一个研究计划可以完整地得出“部分有效、部分无法判断”**。[S][^4]

M03的劳动制度实现已具技术证据，但尚不具有合格的配对实验、首阶段、逐tick账本和完整复现包；M06缺外债合同准入，M07缺地区指标映射；M05、M08、M10、M11尚未形成完成的专项实验。这些具体缺口应成为后续研究任务，不应该被统一涂成“正在证明中的理论”。[C][S]

### 6.5 最不能混淆的两个“0”

H6B记录：历史`SUPPORTED=0`、已准入**独立**历史序列为0；这与P06已经登记过的14项历史比较目标并不矛盾。前者说的是**针对11张机制卡、足以帮助其行为参数识别的独立证据**仍缺乏；后者说的是P06另有宏观TARGET注册，覆盖14个变量标识，其中2项被做成归一化指数映射、1项因出口支付受限而阻断、11项无合适模型对应量。既有目标数据不足以区分多项行为参数，也不应被当作新的独立机制证据。[C][S][^4][^17]

P06的消费复现依然严重失败：基础F2模型1978年家庭消费指数约42.36，而KSH可比总量指数216，18个有信息年度全部超出预设容差。这使研究者更没有理由直接把M02的合成条件性结果推广为真实匈牙利的主因果解释。[S][H][^17][^18]

## 七、比较苏联、中国与东欧：同一种“模型反应”，跨国为何不等于同一种因果？

### 7.1 匈牙利与南斯拉夫：企业名义自主权相似，财政责任结构未必相同

科尔奈1986年的软预算研究明确把匈牙利、南斯拉夫和中国作为改革社会主义的重要比较对象，但“软预算”并不是某一国独占的制度标签，且不同组织、所有制和救助预期可能形成不同后果。[T][^9] 南斯拉夫企业自主管理体制下，企业工人、地方银行、共和国政治机构和联邦层面之间的责任分配，与匈牙利国营企业—国家主管部门的关系不同。

如果观察两国都存在投资过多或通货膨胀，不能断言它们有同一个程度的软预算；更要看企业亏损最终由谁承担、银行损失如何消化、地区政治实体能否拒绝再融资。这些“谁不能说不”的制度细节，比变量名称是否都叫`bailout`更重要。[T][I]

### 7.2 苏联与匈牙利：相似的短缺，不必具有相同的近因

苏联传统行政计划经济与匈牙利NEM之间，一个关键差异是企业日常经营自主权、价格信号以及政策调整范围。科尔奈的《社会主义制度》提供了一种把经典社会主义与改革社会主义视为相互关联又不同的制度类型的总体解释；但即使接受这套理论，仍不能免除对企业采购、投资审批、运输和外贸的具体史料检验。[T][^19]

在苏联，某种耐用品供给不足，可能更强烈地受到国家长期重工业投资优先、军工任务、产品质量和物资调度影响；在匈牙利，商品市场相对较活跃，问题可能表现为信贷、补贴、进口和企业选择之间的冲突。**同一个宏观结果可以有不同的制度产生路径；反过来，同一种制度机制也可能在不同规模和外部约束下产生不同宏观结果。**

### 7.3 中国改革：所谓“同样搞市场”，并不是同样的实验

中国改革初期的农业家庭承包、乡镇企业、地方财政激励、双轨定价和渐进开放，不能简单看作“匈牙利1968经济机制的中国版本”。初始农业比重、人口规模、地区差异、国际贸易环境、财政金融安排与地方政府发展角色都不同。用同一个HSM参数向量给模型改一个国家名称，不会创造中国的历史。

更严格的比较路径是：先为中国重建企业—地方政府—银行—农村集体—农户—中央部委之间的主体和资金边界，再讨论哪些机制具有可迁移性，哪些需要另建规则与指标。中国的价格双轨及增量改革理论说明某些安排在特定条件下可能降低改革阻力，但这些条件并不自动在匈牙利、苏联成立。[T][^20]

对全书而言，这种比较的最终意义不是挑选“最优社会主义模式”，而是培养一种历史政治经济学能力：**相似结果要寻找不同原因；不同结果也要寻找共同约束；凡是不能由资料支持的同一性，都应暂时保持开放。**

## 八、学界争论、反例与尚未解决的问题：模型究竟需要“拟合多好”才算能解释？

### 8.1 争论一：严苛检验还是“对历史有用就够了”？

模拟方法论传统早已区分**模型验证（verification）**和**模型确认或效度评估（validation）**：前者偏向软件是否正确实现设计，后者偏向模型是否足够适合某一指定用途。Robert Sargent的经典论述还特别强调概念模型、数据与运行有效性分开判断。[T][^21] 这对历史研究尤为重要：一个模型也许完全不适合预测匈牙利1978年家庭消费，却仍可以很好地演示“信用断供如何在供应链上造成连锁阻断”。

因此，不必把每一种探索性模型都要求成国家统计局的替身。但如果研究者的论文标题承诺“解释匈牙利1968改革的历史效果”，或直接声称发现了1973年危机的主导机制，就必须承担更强的历史资料与识别义务。**用途越接近真实世界的因果判断、政策评估和历史定论，审查的证据门槛就应越高。**[T][I]

### 8.2 争论二：模型拟合越好，理论一定越好吗？

不一定。不同参数组合可能产生几乎相同的总量轨迹，这叫**等效性（equifinality）**。Beven与Binley在流域模型研究中便强调，受模型结构、边界条件和观测误差影响，不止一组参数可能成为“足够合适”的解释候选。[T][^22] 对历史经济模型也一样：一套以外债进口填补短缺的模型，和一套以生产率改进缓解短缺的模型，可能都让消费指数上升；但其真实经济机制、社会分配及未来脆弱性可能完全不同。

能削弱“外债缓冲是主要机制”的证据，是发现国内实际消费扩张发生在相关国际融资进入之前，或者外债主要没有购买对应进口投入；能削弱“生产率改进是主要机制”的证据，是发现新增消费依赖进口与财政补贴，而非国内单位投入产出改进。**竞争解释需要不同的可观察预言，而不是多写一段理论评论。**[I]

### 8.3 争论三：历史只有一次，还能做因果研究吗？

能够，但不能假装历史有实验室的随机分组。历史研究可以依赖跨企业、地区、部门、时期的异质性、政策实施差异、同期会议记录、前后连续的资金流与物资流，从中构造相互独立的证据链。其强度来自**机制过程可追踪和竞争解释可以被排除**，而不是单纯来自模型软件运行次数。

例如，若同一时期有几家类似企业，某些企业因特定政策获得额外信贷，另一些企业并没有，而我们又有先前趋势、投入表、贷款审批和实际产出，就可能构造条件更好的准实验或过程追踪。但谁得到贷款不是随机的，政府可能恰恰救助生产更重要或更困难的企业。若忽视这种选择偏差，所谓“救助增加产出”仍可能是伪因果。[T][I]

### 8.4 最困难的反例：报告足够透明，仍可能研究错问题

假设一个模型对20个参数做了敏感性，保存全部hash，执行严谨的负对照，也拟合了年度消费指数。可是其原始目标只是“使GDP曲线接近历史”，完全没有记录地区差距、不同家庭取得商品的渠道、工人劳动过程或政治信息变形，那么它即使技术优秀，仍可能对历史最重要的问题缺少解释力。

这就是ODD规范要明确模型**目的、主体、状态、过程顺序、设计理由和评价指标**的原因。ODD可以改善交流与复现，并不自动证明模型适合某个历史目的。[T][^23] Saltelli等人进一步提醒：用于重要社会决策的模型，应当透明呈现假设、不确定性和建模者的价值选择，不能以数学外观掩盖争议。[T][^24]

全书在这里应该坚持一条判断：**既不把“不能完全拟合”当作取消研究的理由，也不把“能够解释一个故事”当成免于证伪的特权。**

## 九、本讲结论：历史解释究竟怎样获得可信度？

**第一，先划清论断的大小。**“断供信用会改变当前F1合成模型的投资和交付”与“1980年代匈牙利经济危机主要是信用收紧造成”，在证据要求上相差甚远。前者可以由受控运行和守恒账本验证，后者还需要历史档案、统计和排除竞争解释。

**第二，把首阶段当作第一项实质检验。**一个干预若没有改变实际生效的利率、可用信用、到达的报告、批准的投资或交付路径，便不能拿下游数值讲制度故事。M02与M09最有教育意义的地方，就在于它们都迫使我们问：程序声称修改的变量，究竟到达了哪一层？

**第三，允许精心设计的研究得出反面结论。**M02卡片的合成结构`REJECTED`应当作为结果保存；“被驳斥”并不比“被支持”低级。它说明先前某种过强的充分性说法需要修改，但不意味着任何关于软预算的较弱命题都已经被否认。

**第四，别把偶然相同当作预注册的对照。**M09的有效null表明下游通道受到上限约束，非常值得研究；可它不能替代原先缺失的负对照。科学方法的核心不是结果出来以后为它补一个好听的名字，而是在见到结果之前说明怎样判定。

**第五，对不确定性逐项命名。**随机seed差异、未知参数、统计测量、模型结构、政策实施范围、历史外推，是六种不同的问题。用一个标准差、一条置信带或一张残差图把它们吞在一起，只会制造虚假的精确感。

**第六，历史数据不是装饰，而是独立的否决者。**对HSM来说，当前最需要的是与行为块具有明确联系的企业、银行、计划报表和地区资料，首先能够检查某条机制究竟有没有在历史上发生。P06已有的宏观TARGET很有价值，却不能替代这些独立观测；其失败也不能通过事后挑选更漂亮的合成情景抹去。

**第七，最好的计算历史不是给“主义”贴上计算机印章。**一个具有价值立场的历史研究者可以关心社会主义的建设成就与体制矛盾，但必须让真实史料有能力推翻自己偏爱的机制。方法上的严格，恰恰是历史唯物主义能够从抽象立场进入具体因果研究的条件。

下一讲将把视野重新拉回世界历史：既然我们已经学会区分机制、证据与反事实，就可以用一条不预设终局的解释链，重新考察计划经济为何形成、取得哪些成就、积累何种矛盾，以及匈牙利、苏联、东欧和中国为什么走上不同道路。

## 十、概念速查与思考题

### 10.1 核心概念

| 术语 | 简明定义 | 最容易出现的误读 |
|---|---|---|
| **因果识别 causal identification** | 把特定条件的作用与其他共同变化区分开 | 相关或时间先后就等于因果 |
| **首阶段 first stage** | 干预确实改变了所声称的制度或行动通道 | 改了配置文件就必然生效 |
| **反事实 counterfactual** | 相同起点下某一条件不同会怎样 | 对未发生历史任意编故事 |
| **配对对照 paired control** | 保持其他关键条件一致的处理组与对照组 | 同一个seed等于真实历史对照 |
| **参数识别 identifiability** | 独立观测能否区分不同参数值 | 固定参数值等于已估计参数 |
| **敏感性 sensitivity** | 模型输出对输入变化的响应 | 影响大就是真实历史主因 |
| **Morris筛选** | 用多起点基本效应筛选潜在重要因子 | 因素排序等于历史识别 |
| **负对照 negative control** | 事先规定理论上不应产生目标效果的比较 | 任何碰巧为零的结果都是负对照 |
| **安慰剂 placebo** | 实质处理未变的标签、时点或虚拟处理检查 | 只要名称不同就有实验 |
| **ABC** | 不显式求似然而用模拟与距离筛选参数的推断方法 | 算法能运行便算历史校准 |
| **等效性 equifinality** | 不同机制或参数能产生相似观测 | 拟合优良必然机制唯一 |
| **研究包complete** | 已通过指定研究流程及证据文件合同 | 某项历史假说已经SUPPORTED |

### 10.2 研究型思考题（不附标准答案）

1. 设想你在1970年匈牙利一家重型机械企业找到连续三年的贷款、生产、库存与亏损处理记录。请设计一个能够区别“软预算预期导致投资过多”和“投入品短缺导致追加信用”的检验；你还需要哪些对照企业和外部条件资料？
2. 假设某模拟中“计划预测误差下降30%”，但消费供给不变。列出至少三种不同机制，每种给出一种能够区分的中介指标。哪一种可以做成负对照？
3. 给你一张1960—1978年家庭消费指数，外加1978年的外债总量，你能够识别“外债延续了社会契约”这一假说吗？请说明你最需要的两类独立数据，以及为什么单纯增加参数抽样次数没有帮助。
4. 如果HSM未来出现一个消费曲线与KSH高度相符的新版本，什么证据能够确认它不是参数间相互抵消产生的拟合？设计一组不依赖消费总量的外部测试。
5. 请比较M02的结构`REJECTED`与M09的`negative_control`阻断。两者都不是“历史已经支持”的状态，但哪一项属于完成的反证，哪一项属于未完成的研究设计？为什么不能将二者在报告里简单归为“失败”？

## 附录B｜一份可复用的历史机制检验登记表（教学模板，不是新实验）

每次要检验“一个制度机制是否解释历史”，先填写如下内容：

1. **历史命题及竞争解释**：明确主体、时间、区域、现象与至少一个替代理论。
2. **处理和对照**：初始状态、随机种子、时间窗口、唯一改动项与可能干预溢出。
3. **首阶段指标**：政策改变是否进入真实受约束的许可、资金、信息或物资通道；设定最低有效变化。
4. **中介和结果**：按申请—审批—支付—交付—居民获得的链条分别报告，声明单位及分母。
5. **负对照与安慰剂**：在运行前声明应当不变的通道、假设及失败处理办法。
6. **审计与重放**：代码、版本、参数、seed、哈希、核算、输出文件及不可公开材料的权限边界。
7. **历史crosswalk**：每个模型指标对应哪份史料、是什么频率和价格/数量口径，是否用于校准、检查或独立保留检验。
8. **预先判定规则**：`SUPPORTED`、`CONDITIONAL`、`REJECTED`、`UNIDENTIFIED`及`NOT_RUN`的触发条件是什么；不得事后替换。
9. **不确定性分解**：seed变化、参数区间、结构替代、测量误差和制度情景分别呈现；不能只给一个“总置信区间”。
10. **反证路径**：哪种企业账本、档案或统计能够真正推翻我们的主要解释？

## 附录C｜将来用于GitHub Pages的互动教学建议（本讲只提设计，不实施）

为第27讲制作两个独立而直观的互动模块即可：一是**信用×救助政策2×2因果分解**，让读者逐格改变合成数字，查看联合差异、纯效应和交互；二是**信息预测—申请上限—经济交付**，展示“预测误差下降但申请始终被100单位上限裁剪”的机制。两者必须标注`[E]`教学演示，不能声称滑块在浏览器中调用了完整HSM，更不能把实时互动生成值并列为历史`[H]`证据。真正HSM既有实验仍只通过独立、核准的JSON导出供静态可视化，原有报告及反证均应完整保留。
